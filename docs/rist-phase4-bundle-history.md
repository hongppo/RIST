## 업로드 이력(여러 파일)

화면 ID: `rist-phase4-bundle-history`

## 표시 및 동작

묶음의 업로드 일시, 업로드한 사람, 전체 파일 수, 유형 그룹 수와 완료 및 미완료 그룹 수를 표시합니다. 일부 완료를 전체 완료로 표시하지 않습니다. 미완료 및 만료 이력은 업로드 계정만 조회합니다. 완료 데이터는 로그인 사용자에게 기존 완료 이력 권한으로 제공합니다. 다른 계정의 혼합 묶음은 조회 가능한 완료 그룹만 표시하며 미완료 파일 정보, 수량과 링크는 노출하지 않습니다.

2026/10/20과 2026/09/30의 본인 묶음은 정상 파일 8개와 그룹 없는 파일 1개를 포함하여 원래 업로드 총수 9개로 표시합니다. 개별 이력 삭제 후에도 업로드 총수는 유지합니다.
