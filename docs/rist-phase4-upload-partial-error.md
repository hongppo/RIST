## 여러 파일 업로드(일부 처리 불가)

화면 ID: `rist-phase4-upload-partial-error`

## 일부 파일 처리 불가

유형 판별 실패 또는 처리할 수 없는 파일은 사유와 함께 별도 목록에 표시합니다. 처리 불가 파일을 직접 제외하지 않아도 유형별 검토 시작을 선택하면 정상 분류된 CSV-003 5개와 EXCEL-004 3개만 다음 단계에서 검토합니다. 처리 불가 파일은 검토 그룹에 포함하지 않으며, ×를 통한 제외는 선택 사항입니다. 정상적으로 검토할 파일이 없으면 진행할 수 없습니다.

처리 불가 파일을 제외하면 업로드 수는 유지하고 제외 수와 남은 처리 불가 수를 갱신합니다. 정상 그룹의 검토 대상 수는 유지합니다.
