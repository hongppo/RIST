## 그룹 상세(검토 중)

화면 ID: `rist-phase4-history-group-review`

## 표시 및 동작

파일 목록에서 선택한 파일의 결과를 표시합니다. 각 파일 행 우측 버튼으로 해당 원본 파일을 개별 다운로드하며, 그룹 전체 다운로드는 제공하지 않습니다. 다운로드 버튼은 해당 행의 파일 ID에 대응하며, 클릭해도 선택 파일과 결과 화면은 바뀌지 않습니다. 기본 상태는 일부 완료 묶음의 EXCEL-004 3개 파일, 만료일 2026/11/19입니다. 마지막 검토 파일과 1단계 또는 2단계로 복귀하며 3단계 중단은 2단계로 복귀해 그룹 전체를 다시 검사합니다. 서버에 적용된 값만 복원합니다. 미완료 및 만료 이력은 업로드 계정만 조회합니다. 완료 데이터는 로그인 사용자에게 기존 완료 이력 권한으로 제공합니다. 다른 계정의 혼합 묶음은 조회 가능한 완료 그룹만 표시하며 미완료 파일 정보, 수량과 링크는 노출하지 않습니다. 원본은 업로드 당시 파일명과 확장자로 제공합니다. 미완료 원본은 보관 기간 내 업로드 계정만 다운로드합니다. 완료 원본은 해당 이력 조회 권한을 따릅니다. 권한 없음: 이 작업을 볼 수 있는 권한이 없습니다. 저장소 연결 장애: 원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요. 파일 부재: 원본 파일을 찾을 수 없습니다. 만료: 보관 기간이 만료되어 원본을 다운로드할 수 없습니다.

화면 제목은 유형 그룹 상세로 표시하고 유형 코드와 처리 상태는 정보 영역에서 구분합니다. 상단 오른쪽의 묶음 상세로는 상위 업로드 묶음으로 이동합니다. 이어서 검토는 같은 상단 동작 영역에 배치합니다. 파일 목록의 선택 영역과 각 행 우측 원본 파일 다운로드는 분리하며, 선택한 파일의 결과를 오른쪽에 표시합니다.
