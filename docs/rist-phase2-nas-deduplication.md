## 보관 대상과 범위 {#nas-scope}

| 구분 | 정책 |
| --- | --- |
| 비교 대상 | 최종 저장이 완료된 업로드 건의 최종 검토 데이터 전체 |
| 별도 대상 | DB 파일 전체를 보관하는 복구용 백업과 분리 |
| 기존 백업 | 기존 전체 DB 복구 백업은 계속 유지 |
| 동일 판단 단위 | 일부 셀·일부 행이 아닌 업로드 건의 전체 데이터 |
| 생략 범위 | 신규 중복 데이터의 NAS 보관만 생략 |
| 보존 | 업무 DB 삭제·병합, 원본 파일 삭제를 의미하지 않음 |

## 검사 흐름 {#nas-flow}

| 순서 | 판단 |
| --- | --- |
| 1 | 최종 저장 완료 건을 대상으로 확인 |
| 2 | 전체 행 수가 같은 기존 보관본·배치 내 신규 후보 선별 |
| 3 | 행별 분석물질·결과 쌍을 우선 비교 |
| 4 | 필수 항목인 분석물질, 결과, 단위와 선택 항목인 채취일자, 위도, 경도의 전체 행 배열 비교 |
| 5 | 위 6개 비교 항목의 전체 값이 같아도 나머지 선택값이 다르면 자동 생략하지 않고 별도 확인 |
| 6 | 동일한 기존 보관본이 있으면 기존 보관본 유지, 신규 중복 NAS 보관 생략 |
| 7 | 배치 내 신규끼리 같으면 먼저 최종 저장된 건을 유지 |
| 8 | 처리건·유지건·비교 기준·처리 일시·판정 결과를 기록 |

행 순서는 무시하지만 동일한 행이 반복된 횟수는 보존합니다. 단순 집합으로 중복 행을 제거한 뒤 비교하지 않습니다. 위 6개 비교 항목 중 일부 값이 다르거나 일부 행만 겹치는 경우는 전체 중복이 아닙니다.

## 비교 사례 {#nas-examples}

| 사례 | 비교 내용 | 결과 |
| --- | --- | --- |
| 기존 보관본 동일 | 기존 A와 신규 B가 각각 171행. 6개 비교 항목의 전체 행 배열과 나머지 선택값 동일 | A 유지, B의 신규 NAS 보관 생략 |
| 신규 배치끼리 동일 | 신규 C·D가 전체 동일. C가 먼저 최종 저장됨 | C 유지, D의 신규 NAS 보관 생략 |
| 전체 행 수 다름 | A 171행, E 170행 | 전체 중복 아님 |
| 비교 항목 값 일부 다름 | 같은 171행에서 한 행의 단위 또는 좌표가 다름 | 전체 중복 아님 |
| 일부 행만 겹침 | 171행 중 85행만 동일 | 전체 중복 아님 |
| 반복 횟수 다름 | 각 3행: X·X·Y와 X·Y·Y | 전체 중복 아님 |
| 나머지 선택값 다름 | 6개 비교 항목 전체는 같으나 담당자 등 나머지 선택값이 다름 | 자동 생략하지 않고 별도 확인 |
| 비교 실패 | 후보를 읽지 못하거나 비교 처리가 실패 | 중복으로 확정하지 않음. 기록 후 재처리 대상으로 관리 |

## 기록과 실패 처리 {#nas-records}

| 기록 | 내용 |
| --- | --- |
| 처리건 | 보관 판단 대상 업로드 건 |
| 유지건 | 동일 판단 시 보존할 기존 또는 신규 건 |
| 기준 | 비교한 전체 행 수, 6개 비교 항목 및 나머지 선택값 확인 기준 |
| 일시 | 비교·판정 처리 일시 |
| 결과 | 신규 보관, 중복 보관 생략, 별도 확인, 비교 실패와 사유 |

비교 실패는 중복의 증거가 아닙니다. 실패한 건을 중복으로 처리하거나 원본·업무 DB를 삭제하지 않습니다. 재처리 대상과 실패 내용을 남깁니다.

## 확정 전 확인 필요 {#nas-pending}

- 동시에 최종 저장되어 순서가 같은 건의 유지 기준
- 값 표준화·표현 차이를 동일하게 볼지에 대한 기준
- 선택값 차이가 있는 건의 별도 확인 절차
- 비교 실패의 재처리 주기·재시도 운영 기준
