## 그룹 저장 중

화면 ID: `rist-phase4-group-saving`

## 기능 및 적용 범위

CSV-003 그룹의 전체 최종 저장 결과를 기다립니다. 저장 중에는 다음 유형 그룹으로 진행하지 않습니다.

연결 이동 시 실제 유형 그룹과 검토 대상 파일 수 및 전체 행 수를 유지합니다. CSV-003 기본 대상은 5개 파일 855행, 03번 파일 제외 후에는 4개 파일 684행이며 EXCEL-004는 3개 파일 360행입니다.

그룹 전체 저장 성공 시 [그룹 저장 완료](#rist-phase4-group-saved)에서 결과를 확인합니다. 완료 후 다음 그룹 검토 여부는 사용자가 선택하며 자동으로 다음 그룹에 진입하지 않습니다.
