## 로그인 정책 {#login-policy}

- 프로그램 자체 로그인으로 운영합니다.
- SSO 연동은 고도화 범위이며, 로그인 기능은 SSO 연결이 가능한 구조로 설계합니다.
- 로그인 세션은 보안성 검토에서 확정한 세션 관리 기준을 적용합니다. SSO 연동 시에는 SSO의 세션 만료·재인증 기준을 함께 적용합니다.
- 파일 추출·저장 등 처리가 진행 중인 시간은 유휴 시간에 산입하지 않습니다. 사용자 활동이 없는 상태가 정해진 유휴 시간을 초과하면 세션이 만료됩니다.
- 세션 만료 시 사용자에게 안내하고 재로그인을 요구합니다.

## 업로드 이력 정책 {#upload-history-policy}

- 업로드 이력에는 ‘검토 완료 및 저장’으로 최종 저장에 성공한 파일만 표시합니다.
- 저장 일시는 실제 저장 완료 시각을 표시합니다.
- 파일 유형은 확정된 유형만 표시합니다.
- 이력 없음·검색 결과 없음·이력 조회 오류·저장 완료 이력의 원본 다운로드 불가 상태는 구분하여 안내합니다.

## 작업 저장·종료 정책 {#work-save-policy}

- ‘작업 저장’은 현재 로그인 세션의 작업 상태를 저장하며, ‘검토 완료 및 저장’은 검토 결과를 최종 저장합니다.
- 최종 저장 전에 로그아웃하거나 브라우저를 종료한 경우, 또는 유휴 시간 초과로 세션이 만료된 경우에는 진행 중인 작업 상태를 다음 로그인에서 복원하지 않습니다. 다음 로그인은 파일 업로드 화면에서 시작합니다.
- 최종 저장한 결과는 작업 종료 후에도 이력에서 조회할 수 있으며, 보관된 원본 파일을 다운로드할 수 있습니다.
- 진행 중인 작업에서 파일 확인·추출 오류, 저장 실패·저장 응답 미확정 상태를 안내합니다. 발생 단계와 오류에 따라 수정·재시도·저장 상태 확인을 제공합니다.

## 지역(위도·경도) 정책 {#location-policy}

### 지점 등록·연결

‘지점 등록’은 반복 사용할 장소를 목록에 추가하는 것이고, ‘지점 연결’은 목록의 장소를 선택하여 검토 데이터에 지점 ID·지점명·좌표를 반영하는 것입니다. 좌표만 저장하는 경우에는 두 동작이 필수가 아닙니다.

- **신규 지점 등록:** 지점 목록에 추가할 때는 지점명과 유효한 위도·경도가 모두 필수입니다. 예: 매달 같은 장소에서 측정한다면 ‘공장 정문 관측소’라는 이름과 좌표를 등록하여 다음 작업에서도 목록에서 선택할 수 있습니다.
- **검토·결과 데이터 저장:** 지점명은 선택 사항이며, 좌표 저장을 위해 지점을 신규 등록할 필요는 없습니다. 예: 일회성 측정 장소는 지점명을 만들지 않고 유효한 위도·경도만 저장할 수 있습니다. 지점명이 필수인 것은 ‘신규 지점 등록’의 경우입니다.
- **등록 지점 선택:** 사용자가 기존 등록 지점을 선택한 경우에만 해당 지점과 연결합니다. 선택한 지점의 ID·지점명·좌표를 함께 반영하고, 기록 당시의 지점명·좌표를 보존합니다. 예: 목록에서 ‘공장 정문 관측소’를 선택하면 해당 지점 정보가 반영됩니다. 이후 지점 목록의 좌표를 수정하더라도 이미 저장한 과거 결과 좌표는 자동으로 바뀌지 않습니다.
- **등록 지점 없이 좌표 사용:** 지도 선택·허용된 직접 입력·파일 추출로 얻은 좌표로 지점 목록을 자동 생성하거나 수정하지 않습니다. 등록 지점을 연결하지 않은 경우 지점 ID·지점명을 NULL로 두고 좌표만 검토·결과 데이터에 저장할 수 있습니다. 예: 지도에서 일회성 측정 위치를 지정하거나 이동 관측소 파일에서 행마다 다른 좌표를 추출한 경우, 새 지점을 만들지 않고 해당 좌표를 사용합니다.
- **연결한 지점과 다른 좌표로 수정:** 등록 지점을 선택한 뒤 좌표를 수정하여 해당 지점의 좌표와 달라지면 지점 ID·지점명 연결을 해제하고 수정 좌표를 유지합니다. 예: ‘공장 정문 관측소’를 선택한 뒤 실제 측정 위치에 맞춰 좌표를 바꾸면, 해당 검토 데이터의 지점 ID·지점명은 NULL이 되고 수정 좌표만 남습니다. 목록에 등록된 ‘공장 정문 관측소’ 자체는 변경하지 않습니다.

### 좌표 입력·수정

- 원본 파일에서 위도·경도를 추출하며, 값이 없으면 1단계에서 지도 클릭 또는 등록 지점 목록 선택으로 일괄 입력합니다. 2단계 상세 검토에서는 각 행의 좌표를 개별 수정할 수 있습니다.
- 이동 관측소 등 파일에서 추출한 좌표는 등록 지점이나 지점명이 없어도 저장할 수 있습니다. 행마다 위치가 다르면 각 행의 추출 좌표를 각각 보존하며, 지점명 부재를 이유로 유효한 좌표를 삭제하거나 서로 다른 행의 좌표를 동일하게 통일하지 않습니다.
- 위도·경도 중 하나만 추출되면 1단계 지도에 해당 위치의 포인트를 표시하지 않습니다. 해당 좌표 입력란에는 추출된 좌표만 표시하고 해당 필드에만 추출 배지를 표시합니다.
- 한쪽 좌표만 있는 상태에서 지도 또는 등록 지점을 선택하면 선택한 위치의 위도·경도로 둘 다 교체합니다. 최초 추출 여부와 현재 수정 상태는 별도로 관리합니다.
- 파일에서 한쪽 좌표만 추출되어 검토 데이터에 보존된 상태는 작업 저장을 허용합니다. 최종 저장 시에는 위도·경도가 모두 유효하거나 모두 NULL이어야 하며, 유형별 필수값 기준을 함께 적용합니다.

### 변경 범위·저장

- 지점 연결과 좌표 저장 기준은 개별 변경·선택 변경·일괄 변경에 동일하게 적용합니다. 개별 변경은 해당 행, 선택 변경은 지정된 대상, 일괄 변경은 파일 전체 대상에 적용하며, 조회하지 않은 행도 변경 대상 범위에 포함합니다.
- 단순 표시·선택·열람만으로 첫 행의 좌표를 다른 행에 자동 복제하지 않습니다.
- 검토 중 ‘변경’은 작업 데이터에 반영하는 동작이며, 최종 저장 시 결과 데이터로 확정합니다. 지점 목록에 등록하지 않은 좌표도 검토·결과 데이터에 저장합니다.

### 화면 표시

- 1·2단계 모두 도분초 형식으로 표시하며, 초는 소수점 2자리로 표시합니다. 예: `36°01′22.09″N`.
- 초의 소수부는 2자리를 초과하여 입력할 수 있습니다.

### DB 저장·정밀도 보존

- 입력 경로와 관계없이 위도·경도는 십진수 도 단위의 `DECIMAL(13,10)`으로 저장합니다. 저장 전 원래 값이 위도 -90 이상 90 이하, 경도 -180 이상 180 이하인지 검증합니다.
- 십진수 좌표는 소수점 10자리 이하면 값 변경 없이 저장합니다. 10자리를 초과하거나 도분초를 십진수로 변환한 경우에는 소수점 11번째 자리에서 반올림하여 10자리로 저장합니다. 절댓값 기준 5 이상은 올리고 부호를 유지합니다.
- 변환·계산은 십진수 정밀 연산으로 처리하고 최종 저장 직전에 한 번만 반올림합니다. DB의 자동 반올림·절삭에 맡기지 않습니다.
- 화면 표시용 변환·반올림은 저장값에 반영하지 않습니다. 좌표를 수정하지 않고 저장하면 기존 내부 십진수 값을 유지하며, 실제 수정한 필드만 도분초에서 십진수로 변환합니다.
- 파일에서 추출한 최초 좌표 원문은 `source_snapshot`에 변경 없이 보존합니다.

## 추출 스크립트 관리 정책 {#extraction-script-policy}

- 파일 유형별로 추출 스크립트를 분리하여 관리합니다.
- 각 유형에 판별 기준, 추출 규칙, 입력 항목과 적용 스크립트 버전을 연결합니다.
- 자동 분류된 유형의 스크립트로 데이터를 추출하고, 해당 규칙에 따라 입력·검토 화면을 구성합니다.
- 스크립트 변경 시 새 버전과 변경 이력을 남기며, 진행 중인 작업은 시작 시 적용된 버전을 유지합니다.

## 파일 업로드 정책 {#upload-policy}

- 한 번에 파일 1개만 업로드할 수 있습니다. 다중 파일 업로드·대기 목록 관리는 고도화 범위입니다.
- CSV(.csv), PDF(.pdf), Excel(.xlsx) 파일을 업로드할 수 있으며, 확장자의 대소문자는 구분하지 않습니다.
- 파일당 20MB 이하의 파일만 업로드할 수 있습니다.
- 빈 파일(0바이트)은 업로드할 수 없습니다.
