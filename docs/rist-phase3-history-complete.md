## 완료 원본 다운로드

미완료 원본은 보관 기간 내 업로드 계정에게, 완료 원본은 해당 이력 조회 권한자에게 제공합니다. 현재 저장 위치에 따라 운영 서버 또는 NAS 원본을 업로드 당시 파일명과 확장자로 제공하며 엑셀 내보내기는 제공하지 않습니다. 다운로드는 사용자, 시각, 대상 파일을 감사 로그에 기록합니다. 안내 문구: 권한 없음 — 이 작업을 볼 수 있는 권한이 없습니다. / 만료된 작업 재개 — 보관 기간이 만료되어 이어서 검토할 수 없습니다. / NAS 연결 장애 — 원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요. / 파일 부재 — 원본 파일을 찾을 수 없습니다. / 다운로드 만료 — 보관 기간이 만료되어 원본을 다운로드할 수 없습니다. NAS 대기 시간은 10초를 기준으로 운영 환경에 맞춰 조정합니다.
