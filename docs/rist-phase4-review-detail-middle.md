## 2단계(중간 파일)

화면 ID: `rist-phase4-review-detail-middle`

## 기능 및 적용 범위

현재 파일의 결과를 개별 행 또는 일괄 입력으로 변경합니다. 개별 변경은 해당 행에만 적용하고 일괄 변경도 현재 파일 범위에만 적용합니다. 검토 완료 및 저장은 현재 유형 그룹의 모든 파일과 결과 행을 검사합니다.

공통 필수 항목은 분석 물질, 결과, 단위입니다. 채취 일자와 좌표는 선택 항목입니다. 두 날짜가 모두 있을 때 채취 일자와 분석 일자의 선후를 검사합니다.
