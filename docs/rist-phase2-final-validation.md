## 전체 행 검사와 미적용 입력

검토 완료 및 저장을 선택하면 미적용 셀 수정·목록 검색·일괄 입력을 먼저 확인합니다. 입력값을 유지하고 셀의 ✓ 또는 열별 선택 변경·일괄 변경으로 적용하도록 안내합니다. 적용된 전체 171행을 대상으로 필수값·좌표·날짜 형식과 날짜 선후를 함께 검사하며, 숨긴 열과 미표시 행도 포함합니다.

## 오류 팝업과 집계

검사 결과 오류가 있으면 오류 팝업을 표시하고, 오류가 없으면 저장 확인창을 표시합니다. 표 위에는 오류 안내 영역을 상시 표시하지 않습니다. 닫기 또는 Esc는 입력값과 검사 결과를 유지하고 팝업만 닫으며 저장하지 않습니다.

필수값은 분석물질·결과·단위·채취일자·위도·경도 6개입니다. 필수 누락은 필드별 1건, 날짜 선후 오류는 행별 1건으로 계산합니다. 같은 행의 오류는 함께 표시하며 대상 행수는 중복을 제외합니다. 좌표·분석 기간 등 다른 형식 오류는 별도 유형으로 표시합니다. 결과의 0·n.d는 입력값입니다.

예시: 3행 단위 누락 1건, 8행 날짜 오류 1건, 12행 위도·경도 누락 2건으로 총 4건·3개 행입니다.

## 오류 필터와 입력 위치 이동

전체·필수값 누락·날짜 오류·형식 오류로 구분합니다. 긴 목록은 내부에서 스크롤합니다. 입력 위치로 이동 또는 날짜 확인을 선택하면 오류 팝업을 닫고 해당 열을 펼치고 필요한 행까지 불러와 셀에 포커스합니다. 날짜 선후 오류는 채취일자·분석일자 두 셀을 함께 강조합니다. 미적용 입력이 있으면 이동 전에 적용하도록 안내하고 값을 보존합니다.

## 날짜 비교 기준

같은 행의 두 날짜가 유효하고 채취일자가 분석일자보다 늦으면 “채취일자가 분석일자보다 늦습니다. 두 날짜를 확인해 주세요.”를 표시합니다. 8행 예시는 채취일자 2026/10/14, 분석일자 2026/10/13입니다. 두 값을 원본과 대조하여 확인하고 임의 교환·보정하지 않습니다.

날짜 형식과 유효성을 먼저 확인합니다. 채취일자 누락과 날짜 선후 오류를 중복 계산하지 않습니다. 분석일자가 없으면 선택 항목 미입력으로 처리하고 비교를 생략합니다. 날짜만 비교하며 시간 선후 기준은 미확정입니다.

추출 후, 1·2단계 입력 적용 후, 최종 저장 전에 날짜를 검사합니다.

## 수정 후 다시 검사

오류가 있어도 작업 저장과 단계 이동을 허용하며 최종 저장만 차단합니다. 오류를 수정하고 적용하면 재검사를 안내합니다. 검토 완료 및 저장을 선택하면 전체 행을 검사하고, 오류가 있으면 오류 팝업을 다시 표시하고, 오류가 없으면 저장 확인창을 엽니다. 오류를 수정했다는 이유만으로 자동 저장하지 않습니다.

## 검사 통과와 선택 항목

저장 확인창에 전체 171행과 선택 항목 미입력 현황을 표시합니다. 선택 항목 공란은 저장을 차단하지 않습니다. 돌아가서 확인은 데이터·선택을 유지하고 창만 닫습니다. 저장을 선택하면 미적용 입력과 오류를 다시 확인하며, 선택 공란은 NULL로 처리하고 0·n.d는 보존합니다.

## 상태 예시

| 상태 | 표시 |
| --- | --- |
| 오류 있음 | 필수 누락 3건·날짜 오류 1건·총 4건·3개 행 |
| 선택 항목 미입력 | 검사 통과, 담당자 12행·분석 기관 3행 미입력 |
| 검사 통과 | 필수·선택 항목 입력, 검사 통과 |

예시 전환 시 입력과 선택을 초기화합니다. 오류 있음 상태는 오류 팝업을 표시합니다. 다른 상태 전환만으로 저장 확인창을 열거나 저장하지 않습니다.
