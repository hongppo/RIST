## 최종 저장 전 통합 검사

| 항목 | 내용 |
| --- | --- |
| 화면 ID | rist-phase2-final-validation |
| 데이터 | 전체 171행, 3단계 페이지당 최대 50행 |

## 1. 3단계 진입과 단계 이동

검사 전에는 1·2단계만 표시합니다. 검토 완료 및 저장으로 최종 검사를 실행하면 3단계 오류 검토를 생성하고 전환합니다. 오류가 있으면 오류 팝업을 엽니다. 오류가 없으면 저장 확인 절차를 거쳐 최종 저장 및 업로드를 진행합니다. 3단계의 일괄 변경 입력 행은 기본 펼침이며, 일괄 변경 버튼으로 접거나 다시 펼칠 수 있습니다. 사용자가 접거나 펼친 상태는 페이지 이동·화면 갱신에도 유지하며 단계별로 구분합니다. 2단계와 3단계는 같은 작업 데이터와 수정값을 사용합니다. 2단계는 기존 빈 열 보기·행 더보기를 유지합니다.

## 2. 전체 검사와 저장 조건

미적용 셀·목록·일괄 입력은 먼저 적용하도록 안내하며 임의 저장하거나 버리지 않습니다. 최종 검사는 숨긴 열·미표시 행을 포함한 전체 171행을 분할 처리하고 진행 상태를 표시하며 중복 실행을 차단합니다. 필수값은 분석물질·결과·단위·채취일자·위도·경도입니다. 좌표·분석 기간·날짜 형식도 확인하며 0·n.d는 빈 값으로 보지 않습니다.

## 3. 오류 팝업과 위치 이동

분류 필터 없이 오류 전체를 표시하며 긴 목록만 내부 스크롤합니다. 항목은 단위열 전체행, 채취일자 8행, 위도 12행처럼 열 이름과 원본 행을 표시합니다. 같은 항목·유형·사유가 전체 작업 행에 해당할 때만 전체행으로 묶습니다. 위치로 이동은 팝업을 닫고 해당 그룹의 가장 위쪽 원본 행으로 페이지를 전환하여 입력을 활성화합니다. 전체행은 1행으로 이동합니다. 닫기·Esc는 값과 검사 결과를 보존하고 저장하지 않습니다.

단위 누락 171건, 날짜 선후 1건, 좌표 누락 2건으로 총 174건·171개 행입니다.

## 4. 오류 항목만 보기

3단계는 오류 항목만 보기를 기본 체크합니다. 전체 검사 결과의 오류 행과 오류 열 합집합을 표시하고 원본 행 번호를 유지합니다. 페이지를 바꿔도 오류 열 구성은 같으며, 체크 해제 시 전체 작업 데이터를 표시합니다. 어느 경우나 페이지당 최대 50행이며 3단계에는 행 더보기가 없습니다.

## 5. 50행 페이지와 수정 후 갱신

표 아래 오류 셀 수·오류 행 수는 최신 결과입니다. 표시 범위와 페이지 수는 현재 구성된 행 목록 기준입니다. 이전·다음으로 페이지를 이동하며 첫·끝 버튼은 비활성화합니다. 수정 적용 시 오류 수와 테두리는 즉시 갱신하지만 현재 페이지의 해결된 행·열을 유지하고 다른 행을 보충하지 않습니다. 페이지 이동·필터 전환·3단계 재진입·재검사 시 목록을 재구성합니다. 모든 오류가 해소되면 오류 없음 상태와 전체보기 첫 페이지를 표시하고 오류 필터를 해제·비활성화합니다. 자동 저장하지 않습니다.

## 6. 오류 셀 순환 이동

←·→는 전체 오류 셀을 원본 행 번호순, 같은 행에서는 화면 열 순서로 이동합니다. 같은 셀의 여러 오류는 하나로 계산합니다. 첫 오류 이전은 마지막, 마지막 다음은 첫 오류로 순환하며 다른 페이지면 전환 후 입력을 활성화합니다. 필터 해제 상태에도 오류 셀만 이동합니다. 팝업 이동·직접 오류 셀 선택은 현재 위치에 반영합니다. 현재 오류가 해결되면 다음 오류, 없으면 마지막 남은 오류를 기준으로 바꾸되 자동 이동하지 않습니다. 미적용 입력이 있으면 먼저 적용하도록 안내합니다. 오류 0·1개는 양쪽 버튼을 비활성화하고 2단계에서는 도구를 숨깁니다.

## 7. 오류 셀과 열 제목

수정할 셀은 빨간 테두리로 표시합니다. 날짜 선후 오류는 채취일자 셀에만 표시하며 이동 대상도 채취일자입니다. 날짜 형식 오류는 해당 날짜 셀에 표시합니다. 전체 작업 데이터의 모든 행에서 같은 열에 오류가 있으면 열 제목을 빨갛게 표시합니다. 현재 페이지나 필터 행만 기준으로 판단하지 않으며, 정상 행이 하나라도 생기면 제목 표시를 해제합니다. 전체 행이 0개면 적용하지 않습니다.

## 8. 날짜 검사 기준

같은 행의 두 날짜가 유효하고 채취일자가 분석일자보다 늦을 때 선후 오류로 처리합니다. 날짜 형식·유효성을 먼저 확인하며 누락·형식 오류와 선후 오류를 중복 계산하지 않습니다. 분석일자 공란은 비교를 생략합니다. 날짜만 비교하며 시간 선후 기준은 미확정입니다. 두 값은 원본과 대조하고 임의 교환·보정하지 않습니다.

## 9. 검사 통과와 저장 확인

오류가 있어도 작업 저장과 2·3단계 이동은 가능하며 최종 저장만 차단합니다. 검토 완료 및 저장으로 재검사하여 오류가 없으면 전체 171행과 선택 항목 미입력 현황을 저장 확인창에 표시합니다. 선택 공란은 저장을 차단하지 않으며 NULL로 처리하고 0·n.d는 보존합니다. 저장 선택 시 미적용 입력과 오류를 다시 확인합니다. 돌아가서 확인은 값과 선택을 유지하고 창만 닫습니다.
