## 파일 업로드(여러 파일 선택)

화면 ID: `rist-phase4-upload-multiple-selected`

## 파일 선택 및 취소

오른쪽에 CSV-003 5개와 EXCEL-004 3개, 총 8개 파일을 선택한 상태이며 다음 단계로는 유형 분석으로 이동합니다. 오른쪽에서 파일 1개만 선택한 경우에도 같은 경로를 사용합니다.

파일을 선택하거나 드롭하면 해당 영역만 활성 선택 상태로 표시하고 박스 안 우측 상단에 파일 선택 취소 버튼을 제공합니다. 버튼을 선택하면 선택 파일, 파일 입력값과 활성 표시를 초기화하고 첫 업로드 화면으로 돌아갑니다. 여러 파일 영역은 선택한 묶음 전체를 취소하며 개별 파일 제외와 구분합니다. 초기 상태에서 다음 단계로는 비활성화됩니다. 선택 취소 버튼에는 파일 선택 취소 접근성 이름과 도움말을 제공하고, 클릭 시 파일 선택 창을 열지 않습니다.

여러 파일은 접수 전 선택한 전체 파일 수를 기준으로 한 번에 최대 20개까지 업로드하며, 파일당 20MB 이하입니다. 유형 수는 제한하지 않으며 기존 등록 유형을 지원합니다. 미지원 파일은 유형 분석 후 처리 불가 목록에 표시합니다. 선택 또는 드롭한 파일이 20개를 초과하면 일부만 접수하지 않고 다음 단계로 진행을 차단합니다. 나중에 파일을 제외할 예정이어도 초과 접수할 수 없습니다. “파일은 한 번에 최대 20개까지 업로드할 수 있습니다. 20개 이하로 다시 선택해 주세요.”를 안내하고 20개 이하로 다시 선택하도록 합니다.

업로드 전 선택 상태에서는 단일 파일과 여러 파일 모두 “N개 파일 선택됨”으로 상태와 수량만 표시하며, 파일명과 파일명 툴팁은 표시하지 않습니다.

전체 업로드 용량은 최대 400MB를 기준으로 하며, 개발 검토 의견에 따라 조정할 수 있습니다. 파일당 용량과 전체 용량은 동일하게 1MB = 1,024 × 1,024바이트로 계산합니다. 전체 용량이 400MB를 초과하거나 파일당 용량이 20MB를 초과하면 접수 및 다음 단계 진행을 차단하고 기준 이하로 다시 선택하도록 안내합니다.
