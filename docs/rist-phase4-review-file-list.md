## 1단계(파일 목록)

화면 ID: `rist-phase4-review-file-list`

## 기능 및 적용 범위

현재 유형 그룹의 파일명과 파일 위치를 표시합니다. 〈 〉 또는 파일 목록으로 같은 그룹 안에서 이동합니다. 1단계의 값 변경은 현재 파일 전체 행의 해당 열에만 적용하며 다른 파일에는 복제하지 않습니다. 파일별로 적용된 값은 이동 후에도 유지합니다. 미적용 입력은 복원하지 않습니다.

공통 필수 항목은 분석 물질, 결과, 단위입니다. 채취 일자와 좌표는 선택 항목입니다. 두 날짜가 모두 있을 때 채취 일자와 분석 일자의 선후를 검사합니다.
