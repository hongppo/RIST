## 매칭 조건

- 관측 지점 DB 전체를 대상으로, 시료명 또는 지역에 정식 지점명이나 해당 지점의 지역 부분 명칭이 포함되면 연결한다. 텍스트 내 위치와 관계없이 검색하며 원본 시료명은 변경하지 않는다.
- 지역 부분 명칭은 DB 지점명에서 맨 앞 도시명과 그 뒤 공백을 제외한 나머지 명칭이다. 예를 들어 `광양 하동`은 `하동`, `광양 태인`은 `태인`, `광양 중마동`은 `중마동`으로도 연결한다. 여러 단어로 된 명칭은 전체를 유지한다(`포항 동촌 플라자` → `동촌 플라자`). 도시명만으로 연결하거나 임의의 문자 조각·유사어로 확대하지 않는다. 아래 시료명 약자 매칭은 명시된 약자·형식에 한해서만 인정한다.
- 괄호 명칭은 괄호 밖 지역명과 괄호 안 명칭을 각각 인정한다. `여수 묘도(온동)`은 정식 지점명 외에 `여수 묘도`, `묘도`, `온동`으로도 연결한다.
- 같은 지점의 여러 단어가 맞으면 하나의 지점으로 연결한다. 대응이 없거나 서로 다른 지점이 동시에 맞으면 위치값은 `NULL`로 두고 검토 화면에서 보완한다.
- 지점명·위도·경도는 같은 DB 행에서 가져와 해당 시료의 결과에만 적용한다. DB 원본 좌표는 보존하고 저장값은 `DECIMAL(13,10)` 기준으로 한 번만 반올림한다.

### 시료명 약자 매칭 {#sample-region-alias}

정식 지점명·지역 부분 명칭·괄호 명칭 검색과 함께, 아래에 등록된 약자와 시료명 형식이 모두 일치할 때 지역 후보를 만든다. 약자는 지점명의 첫 글자에서 자동 생성하지 않으며, 임의의 한 글자·유사어·문자 조각으로 확대하지 않는다.

| 허용 약자 | 관측 지점명 | 시료명 예시 |
| --- | --- | --- |
| 청 | 포항 청림 | `청#8-1` |
| 태 | 광양 태인 | `태#8-1` |
| 해 | 포항 해도 | `해#9-1` |
| 묘 | 여수 묘도(온동) | `묘#9-5` |

| 조건 | 처리 |
| --- | --- |
| 인식 범위 | 시료명 전체가 `약자#번호-번호` 형식일 때만 약자 후보 생성. 파일명·연도로 제한하지 않음 |
| 공백 | 검사용 사본에서 양 끝과 구분자 주변의 파서 삽입 공백을 허용. 원문 시료명은 변경하지 않음 |
| 번호 | `#` 뒤 번호는 지역 매칭 대상에서 제외. `#8`·`#9`를 월·날짜로 추정하지 않음 |
| 형식 불일치 | 약자 단독, 다른 번호 구조, 다른 접두문자, 미등록 약자는 이 약자 규칙으로 확정하지 않음. 정식명 규칙의 후보가 없으면 위치값 `NULL` 및 검토 |
| 후보 통합 | 정식명 규칙과 약자 규칙의 후보가 같은 지점이면 1개로 취급. 다른 지점이면 우선순위로 덮어쓰지 않고 위치값 `NULL` 및 검토 |
| 연결 범위 | 확정된 DB 행의 지점명·위도·경도를 해당 시료의 결과에만 연결. 다른 시료에 전파하지 않음 |
| 값의 출처 | DB로 연결한 위치값은 직접 추출값이 아닌 `MATCHED`로 구분. 시료명 원문, 문서 내 시료 위치, 적용 약자·규칙과 연결 DB 행을 `source` 근거로 보존 |
| 좌표 정밀도 | DB 원본 좌표를 유지하며 기존 `DECIMAL(13,10)` 저장 정책 적용 |
| 물질 블록 반복 | 같은 보고서에서 유일하게 대응하는 동일 시료의 물질 블록 반복은 PDF-003 연결 원칙에 따라 결과를 연결. 약자 매칭으로 시료를 추가 생성하거나, 약자가 같다는 이유로 서로 다른 시료·동명 시료를 병합하지 않음 |

검사식:

```regex
^\s*(청|태|해|묘)\s*#\s*\d+\s*-\s*\d+\s*$
```

#### 적용·오매칭 방지 예시

| 시료명 또는 입력 조건 | 지역 매칭 결과 |
| --- | --- |
| `청#8-1`, `태#8-1`, `해#9-1`, `묘#9-5` | 각각 포항 청림, 광양 태인, 포항 해도, 여수 묘도(온동) |
| ` 태 # 8 - 1 ` | 광양 태인. 원문 공백은 보존 |
| `청#8-1`과 `청#8-2` | 같은 지점에 연결하되 서로 다른 시료 유지 |
| `태`, `태#8`, `태8-1`, `시료태#8-1`, `동#8-1` | 약자 규칙 후보 없음 |
| `태풍`, `청정` | 단일 글자 포함만으로 약자 매칭하지 않음 |
| `남해` | 정식 지역 부분 명칭 규칙으로 광양 남해. `해`가 포함되어도 포항 해도 후보를 만들지 않음 |
| 시료명 `태#8-1`, 지역 입력 `광양 태인` | 같은 지점 후보이므로 광양 태인 1개로 확정 |
| 시료명 `태#8-1`, 지역 입력 `포항 청림` | 서로 다른 지점 후보이므로 위치값 `NULL` 및 검토 |
| `강하먼지 청림#5`, `강하먼지 해도#7-3` | 정식 지역 부분 명칭 규칙으로 각각 포항 청림, 포항 해도 |
