## 매칭 조건

- 시료명 또는 지역에 위 DB 지점명이나 아래 매칭 단어가 포함되면 해당 관측 지점에 연결한다. 텍스트 내 위치와 관계없이 검색하며 원본 시료명은 변경하지 않는다.
- 같은 지점의 여러 단어가 맞으면 하나의 지점으로 연결한다. 대응이 없거나 서로 다른 지점이 동시에 맞으면 위치값은 `NULL`로 두고 검토 화면에서 보완한다.
- 지점명·위도·경도는 같은 DB 행에서 가져와 해당 시료의 결과에만 적용한다. DB 원본 좌표는 보존하고 저장값은 `DECIMAL(13,10)` 기준으로 한 번만 반올림한다.

### 매칭 단어·예시

각 행의 단어 중 하나가 포함되면 연결한다. 아래에 없는 약칭은 임의로 추가하지 않는다.

| 매칭 단어 | 시료명 또는 지역 예시 | 관측 지점명 |
| --- | --- | --- |
| 포항 청림, 청림 | 중금속_포항 청림_1-1 | 포항 청림 |
| 포항 해도, 해도 | 시료_해도1-1 | 포항 해도 |
| 광양 태인, 태인 | 대기_광양 태인_1-1 | 광양 태인 |
| 여수 묘도(온동), 여수 묘도, 묘도, 온동 | 시료_여수 묘도_1-1 또는 시료_온동1-1 | 여수 묘도(온동) |
