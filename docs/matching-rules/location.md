## 매칭 조건

- 관측 지점 DB 전체를 대상으로, 시료명 또는 지역에 정식 지점명이나 해당 지점의 지역 부분 명칭이 포함되면 연결한다. 텍스트 내 위치와 관계없이 검색하며 원본 시료명은 변경하지 않는다.
- 지역 부분 명칭은 DB 지점명에서 맨 앞 도시명과 그 뒤 공백을 제외한 나머지 명칭이다. 예를 들어 `광양 하동`은 `하동`, `광양 태인`은 `태인`, `광양 중마동`은 `중마동`으로도 연결한다. 여러 단어로 된 명칭은 전체를 유지한다(`포항 동촌 플라자` → `동촌 플라자`). 도시명만으로 연결하거나 임의의 문자 조각·유사어로 확대하지 않는다.
- 괄호 명칭은 괄호 밖 지역명과 괄호 안 명칭을 각각 인정한다. `여수 묘도(온동)`은 정식 지점명 외에 `여수 묘도`, `묘도`, `온동`으로도 연결한다.
- 같은 지점의 여러 단어가 맞으면 하나의 지점으로 연결한다. 대응이 없거나 서로 다른 지점이 동시에 맞으면 위치값은 `NULL`로 두고 검토 화면에서 보완한다.
- 지점명·위도·경도는 같은 DB 행에서 가져와 해당 시료의 결과에만 적용한다. DB 원본 좌표는 보존하고 저장값은 `DECIMAL(13,10)` 기준으로 한 번만 반올림한다.
