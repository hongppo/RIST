## EXCEL-001 및 CSV-003 파일명 조건

EXCEL-001 또는 CSV-003으로 구조 판별된 파일에 한해 원본 파일명에 `VOCs` 또는 `PAHs` 문자열이 포함되는지 확인한다. 지정 문자열 그대로 비교하며 대소문자 변형이나 유사어로 확대하지 않는다. 파일명으로 파일 유형 자체를 판별하지 않는다. 이 파일명 조건은 EXCEL-001과 CSV-003에만 적용한다.

| 원본 파일명 조건 | 처리 |
| --- | --- |
| VOCs만 포함 | 유형별 표의 VOCs 규칙 적용 |
| PAHs만 포함 | 유형별 표의 PAHs 규칙 적용 |
| VOCs와 PAHs 모두 포함 | 이 추가 규칙으로 유일값 확정 불가. 임의 선택하지 않고 기존 값 유지 및 확인 대상 |
| 둘 다 미포함 | 이 추가 규칙으로 유일값 확정 불가. 기존 값 유지 및 확인 대상 |

## EXCEL-004 시트별 조건

첫 번째 시트는 추출에서 제외한다. 대상 시트가 VOCs 계열이면 ES 01804.2a, PAHs 계열이면 ES 01802.1a를 해당 시트의 결과에만 적용한다. 파일 전체에 하나의 분석법을 적용하지 않는다. 중금속, Cr(VI), Aldehyde 등 다른 계열에는 확대하지 않으며 시트 계열이 불명확하면 자동 매칭하지 않는다.

## 매칭 간 우선순위 및 DB 연결

- 명확한 직접 추출값 우선 및 PDF-002 예외는 유지한다.
- 분석물질별 지정악취 매칭은 PDF-002 지정악취에만 적용한다. 다른 유형에는 적용하지 않으므로 유형별 대기 분석법과 경쟁하는 보완 규칙으로 사용하지 않는다.
- 명확한 직접 추출값이 없는 경우에만 유형별 기본 분석법을 MATCHED로 보완하고 최초 원문을 보존한다. 직접 추출값을 매칭값으로 덮어쓰지 않는다.
- 표시값은 시험방법 코드와 DB 분석법명을 함께 제공한다.
- 시험방법 코드·표시명과 실제 DB ID는 구분한다. 실제 동일 항목에 연결되는 경우에만 해당 ID를 사용한다.
- KBSI 내부시험법, XRF 분석, ICP 분석은 현재 [분석법 DB](<../db-lists/analysis-method.md>)에 등록된 동일 명칭 항목으로 연결한다. 시험방법 코드와 고시번호는 공란이며 임의 생성하지 않는다. 실제 동일 항목의 UUID만 사용하고 자체시험법 등 다른 항목과 동일시하지 않는다.
