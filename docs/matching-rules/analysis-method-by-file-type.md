## EXCEL-001 파일명 조건

EXCEL-001로 판별된 파일에 한해 원본 파일명에 `VOCs` 또는 `PAHs` 문자열이 포함되는지 확인한다. 지정 문자열 그대로 비교하며 대소문자 변형이나 유사어로 확대하지 않는다. 파일명으로 파일 유형을 판별하지 않으며 CSV 등 다른 유형에는 적용하지 않는다.

| 원본 파일명 조건 | 처리 |
| --- | --- |
| VOCs만 포함 | 유형별 표의 VOCs 규칙 적용 |
| PAHs만 포함 | 유형별 표의 PAHs 규칙 적용 |
| VOCs와 PAHs 모두 포함 | 이 추가 규칙으로 유일값 확정 불가. 임의 선택하지 않고 기존 값 유지 및 확인 대상 |
| 둘 다 미포함 | 이 추가 규칙으로 유일값 확정 불가. 기존 값 유지 및 확인 대상 |

## 매칭 간 우선순위 및 DB 연결

- 명확한 직접 추출값 우선 및 PDF-002 예외는 유지한다.
- 유형별 기본값과 기존 분석물질별 매칭값이 다를 때 적용 우선순위: **미확정**. 어느 한쪽을 임의 확정하거나 덮어쓰지 않고 확인 대상으로 구분한다.
- 시험방법 코드·표시명과 실제 DB ID는 구분한다. 실제 동일 항목에 연결되는 경우에만 해당 ID를 사용한다.
- KBSI 내부시험법·XRF 분석·ICP 분석은 현재 [분석법 DB](<../db-lists/analysis-method.md>)에 동일 명칭이 없다. 매칭 대상 명칭은 위 표와 같으며 실제 DB 연결은 미확인이다. 자체시험법 등 다른 기존 항목과 임의로 동일시하지 않는다.
