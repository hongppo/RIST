## 그룹 저장 완료

화면 ID: `rist-phase4-group-saved`

## 기능 및 적용 범위

현재 유형 그룹의 전체 최종 저장 성공을 표시합니다. CSV-003 기본 대상은 5개 파일 855행이며, 제외 후 또는 다른 유형 그룹에서 진입하면 실제 저장 대상 파일 수와 결과 행 수를 표시합니다. 완료된 그룹은 재검토 및 미완료 보관 만료 대상에서 제외합니다. 최종 저장 완료와 NAS 전송 완료는 별도로 관리합니다. 같은 화면 아래에 “다음 그룹 검토로 넘어가겠습니까?”와 다음 유형 그룹 및 파일 수를 표시합니다. 다음 그룹 검토를 선택하면 [다음 유형 그룹의 1단계](#rist-phase4-review-next-group)로 이동합니다. 나중에 검토를 선택하면 [해당 업로드 묶음 상세](#rist-phase4-bundle-partial)에서 남은 그룹을 재개할 수 있습니다. 단순 보류로 미완료 그룹의 보관 기간을 갱신하지 않으며 기존 보관 및 권한 기준을 유지합니다. 남은 그룹이 없으면 질문과 다음 그룹 선택 버튼을 표시하지 않고 완료 확인으로 [모든 그룹 완료](#rist-phase4-all-groups-complete)에 연결합니다.
