## 파일 상세(지원하지 않는 파일)

화면 ID: `rist-phase4-history-file-unsupported`

## 표시 및 동작

업로드일 2026/10/20, 만료일 2026/11/19인 미지원 파일입니다. 유형 강제 지정, 재처리 및 재개 버튼은 제공하지 않습니다. 정상 파일 8개와 함께 총 9개인 묶음에 속하며, 묶음 상세의 그룹 없는 파일 목록에서 이 상세로 진입합니다. 원본은 업로드 당시 파일명과 확장자로 제공합니다. 미완료 원본은 보관 기간 내 업로드 계정만 다운로드합니다. 완료 원본은 해당 이력 조회 권한을 따릅니다. 권한 없음: 이 작업을 볼 수 있는 권한이 없습니다. 저장소 연결 장애: 원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요. 파일 부재: 원본 파일을 찾을 수 없습니다. 만료: 보관 기간이 만료되어 원본을 다운로드할 수 없습니다. 단일 파일과 여러 파일 업로드에 동일하게 적용합니다. 추출 실패 또는 지원하지 않는 파일의 이력 상세 하단에 업로드 계정만 이력 삭제를 사용할 수 있습니다. 검토 중, 완료, 만료, 취소됨 이력에는 제공하지 않습니다. 이력 삭제는 사용자 목록과 상세에서 숨기는 동작이며 내부 처리 기록과 업로드일부터 30일의 원본 보관 기준은 유지합니다. 보관 기간은 갱신하지 않으며 원본을 즉시 삭제하지 않습니다. [실패 파일 업로드 이력 삭제 정책](#rist-failed-upload-history-deletion-policy)을 적용합니다. 이력 삭제를 선택하면 [이력 삭제 확인(여러 파일)](#rist-phase4-history-delete-multiple)으로 이동합니다. 삭제 후 해당 묶음 상세로 돌아가며 정상 그룹은 유지합니다.

화면 제목은 업로드 이력 상세로 표시하며 실패 또는 미지원 상태는 작업 상태 항목으로 구분합니다. 파일명, 유형, 작업 상태, 보관 만료일과 업로드 및 저장 정보를 공통 상세 구조로 표시합니다. 상단 오른쪽에 묶음 상세로와 원본 파일 다운로드를 배치하며, 묶음 상세로는 해당 파일의 상위 업로드 묶음으로 이동합니다. 이력 삭제는 상세 하단에 유지합니다.

정보 카드 아래에 중립 색상의 안내 영역 하나를 표시합니다. 추출 실패는 “추출에 실패하여 검토 데이터가 없습니다.”, 미지원은 “지원하지 않는 파일로 검토 데이터가 없습니다.”로 안내하며 위치, 색상과 여백은 동일하게 적용합니다.
