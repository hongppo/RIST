## 적용 범위

총괄표는 분석물질, 단위, 분석법, 채취법, 지역과 좌표의 값 확보 및 매칭 기준을 정의한다. 셀, 행, 시트의 구조와 결과 해석, BASE 및 날짜는 유형별 상세 규칙을 따른다.

## 표 읽는 방법

| 표기 | 의미 |
| --- | --- |
| 직접 추출 | 원본에서 명확하게 읽은 값. EXTRACTED로 기록 |
| 유형 고정값 | PDF-001 및 PDF-001-a 판별 후 적용하는 복합악취와 OU. MATCHED로 기록 |
| 미추출 시 기본값 | 명확한 직접 추출값이 없을 때만 지정 분석법 또는 채취법으로 보완. MATCHED로 기록 |
| 파일명 조건 / 지정악취 매칭 | 지정 조건이 유일하게 충족될 때 적용. PDF-002 지정악취는 직접 분석법보다 우선하는 예외 |
| 자동 보완 없음 | 자동으로 채울 규칙이 없음. 선택 항목은 필요 시 목록 선택 또는 입력, 필수 단위는 최종 저장 전 입력 필요 |
| 공통 지역 매칭 | 등록 지점이 유일하게 대응할 때 해당 시료에만 좌표 연결. 직접 좌표 우선 |

세부 조건은 아래 규칙 선택 순서, 파일명 조건, 지역과 좌표, 유형별 세부 기준을 따른다.

## 유형별 세부 기준

| 유형 | 추출 및 매칭 범위 |
| --- | --- |
| CSV-001 | 결과 구간 물질명 전체와 CAS 원문 유지. 선택한 시작 구간명 마지막 괄호에서 단위 추출. RIST-E-001은 SIFT-MS 테들러백 분석 |
| CSV-002 | 물질 헤더 직접 추출. Total Concentration과 기상 항목 제외. RIST-E-003은 SIFT-MS 고정형 측정. 유지한 측정행 좌표를 같은 행 결과에만 연결 |
| CSV-003 | 해당 배치의 분석물질 열 직접 추출. 시료 열별 지역 매칭. 파일명 조건 불충족 시 분석법을 임의 확정하지 않고 사용자 선택으로 보완 가능 |

| PDF-001-a | 시험방법 셀에서 코드만 확인되면 코드만 유지. 없는 방법명 추정 금지 |
| PDF-002 | 시험항목 물질명과 결과행에 대응하는 단위 병합 셀 직접 추출. 괄호 표기 유지. 지정악취 매칭 미대응 또는 불명확은 사용자 보완 |

| EXCEL-001 | 결과 행렬의 물질명 열 직접 추출. 시료 열별 지역 매칭. VOCs만 포함하거나 파일명 조건이 불충족이면 채취법 자동 보완 없음 |
| EXCEL-002 | Component 물질명 전체와 같은 행 Unit 직접 추출. 산화물의 원소 변환 및 wt% 고정 금지. XRF 분석은 동일 명칭 목록 항목 연결 대상 |
| EXCEL-003 | 실제 물질 헤더와 결과표 단위 라벨 또는 입력칸 직접 추출. 분석 방법 전체 유지. ICP 분석은 동일 명칭 목록 항목 연결 대상. 공장명만으로 임의 좌표 생성 금지 |

| EXCEL-003-b | 실제 물질 결과 헤더와 결과표 명시 단위 직접 추출. 참고 열과 구분. 시험장비(방법) 전체 유지. ES 01803.1은 환경대기 중 알데하이드류 - 고성능액체크로마토그래피법 |

공통 지역 매칭은 각 시료에만 적용한다. 미대응 항목은 자동 보완하지 않으며 필요한 경우 목록 선택 또는 입력으로 보완한다.

## 규칙 선택 순서와 3차 적용 기준

1. 기본 유형과 하위유형의 구체적인 구조 조건을 모두 확인하여 최종 유형 후보를 판별한다.
2. 해당 유형의 추출 위치와 적용 범위에서 명확한 값을 읽는다.
3. 유형 고정값, 미추출 시 기본값 및 조건부 매칭을 아래 적용 기준에 따라 구분한다.
4. 실제 동일한 DB 항목이 유일하게 확인되는 값만 해당 ID에 연결한다.
5. 남은 값과 확인 사유를 표시하고 필수 여부에 따라 사용자 선택 또는 입력으로 보완한다.

| 항목 | 적용 기준 |
| --- | --- |
| 최종 유형 후보 | 기본 유형과 하위유형의 구체적인 판별 조건으로 유일한 후보를 확정. 판별 완료 후 독립적인 최종 후보가 2개 이상이면 중단하고 판별 불가 안내. 첫 매치 선택이나 하위유형 무조건 우선 적용 금지 |
| 일반 우선순위 | 명확한 직접 추출값 우선. 유형별 보완은 직접 추출값이 없는 항목에만 적용. 매칭 실패로 유효한 추출값을 지우지 않음 |
| PDF-001과 PDF-001-a | 유형 판별 후 물질명 복합악취와 단위 OU를 각각의 유형 고정값으로 적용. 직접 추출로 표시하지 않음 |
| PDF-002 지정악취 | 지정악취 22종 표의 시험방법 코드를 PDF 기재 여부와 개정판 차이에 관계없이 적용. 시험방법 전체 원문과 고시정보 별도 유지 |
| 지정악취 적용 한계 | PDF-002 지정악취 이외에는 물질명이 같아도 해당 표를 적용하지 않음. Toluene이라는 이유로 대기 VOCs에 ES 09307.b 적용 금지 |
| 유형별 분석법 | 지정악취 범위 밖에서는 총괄표의 유형별 기본값과 파일명 조건 적용. 포괄적인 ‘분석법 매칭’ 링크를 지정악취 표의 전 유형 적용 근거로 사용하지 않음 |
| CSV-001과 CSV-002 | 각각 RIST-E-001과 RIST-E-003 보완. 추출 단계의 초기 NULL은 유형별 매칭 후에도 반드시 NULL을 유지하라는 의미가 아님 |
| PDF-003과 EXCEL-002 및 EXCEL-003 | 명확한 직접 분석법이 없으면 각각 KBSI 내부시험법, XRF 분석, ICP 분석으로 보완. 물질명이나 장비명에서 임의 유추하는 규칙이 아닌 판별 유형의 지정 기본값 |
| EXCEL-003 복합 분석법 | ‘ICP 분석 및 Fe 적정’처럼 명확한 직접 추출값은 전체 유지. ICP 분석 기본값으로 축약하거나 대체하지 않음 |
| EXCEL-001 | 구조 판별과 파일명 보완은 별개. 지정 파일명 조건이 맞으면 해당 결과의 분석법을 보완하며 물질별 지정악취 표를 적용하지 않음 |

이 총괄표의 3차 적용 기준과 상세 문서의 포괄적인 매칭 설명이 다른 경우, 위 항목별 범위와 우선순위를 적용한다. 추출 셀, 행과 시트의 구조, 결과 해석은 각 유형 상세 규칙을 따른다.

## 파일명 조건 {#filename-conditions}

[파일 유형별 분석법 매칭](<matching-rules/analysis-method-by-file-type.md>)과 [채취법 매칭](<matching-rules/sampling-method.md>)의 지정 문자열을 대소문자 그대로 비교한다. 구조 판별을 통과한 EXCEL-001 및 CSV-003의 원본 파일명에서만 분석법 보완 조건을 확인한다.

| 파일명 조건 | EXCEL-001 분석법 | CSV-003 분석법 | EXCEL-001 채취법 |
| --- | --- | --- | --- |
| VOCs만 포함 | ES 01804.2a | ES 01804.2a | 추가 보완 없음 |
| PAHs만 포함 | ES 01802.1a | ES 01802.1a | ES 01115, 환경대기 시료채취방법(고용량 공기시료채취기법) |
| 둘 다 포함 | 유일값 확정하지 않고 사용자 선택 | 유일값 확정하지 않고 사용자 선택 | 유일값 확정하지 않고 사용자 선택 |
| 둘 다 없음 | 자동 보완 없이 사용자 선택 | 자동 보완 없이 사용자 선택 | 자동 보완 없이 사용자 선택 |

`vocs`, `VOC`, 유사어 등으로 조건을 확대하지 않는다. 파일명 조건에 맞지 않아도 구조가 유효한 파일을 거부하지 않는다. 명확한 직접 추출값이 있으면 파일명 조건보다 우선 유지한다. CSV-003에는 EXCEL-001의 PAHs 채취법 조건을 적용하지 않는다.

시험방법명은 실제 동일한 DB 항목의 이름을 함께 표시한다. ES 01804.2a는 환경대기 중 유해 휘발성 유기화합물(VOCs) 시험방법 - 고체흡착법, ES 01802.1a는 환경대기 중 다환방향족탄화수소류(PAHs) - 기체크로마토그래피/질량분석법이다.

## 지역과 좌표 {#location-coordinates}

| 조건 | 적용 기준 |
| --- | --- |
| 명확한 원본 좌표 | 직접 추출값 우선. 이름이 DB 지점과 일치해도 추출 좌표를 DB 값으로 덮어쓰지 않음 |
| 직접 좌표가 없는 시료 | [지역 매칭](<matching-rules/location.md>)의 정식명, 지역 부분 명칭, 괄호 명칭 및 등록 약자 형식으로 DB 후보 확인 |
| 유일한 DB 지점 | 같은 DB 행의 지점명과 좌표를 해당 시료의 결과에만 MATCHED로 연결 |
| 미대응 또는 서로 다른 후보 | 임의 지점 선택이나 좌표 생성 없이 미확정 항목 NULL 및 사용자 보완. 유효한 직접 추출값은 유지 |
| EXCEL-003 공장 위치 | 공통 규칙으로 등록 지점이 유일하게 확인되면 DB 좌표 연결 가능. ‘시료명에서 좌표를 만들지 않음’은 임의 좌표 생성 금지이며 등록 DB 매칭 금지가 아님. 미등록 공장 위치는 선택 또는 직접 입력 |
| CSV-002 | 유지한 측정행의 좌표를 해당 행 결과에만 연결. 첫 행 좌표 복제 및 제외한 행의 좌표 보완 금지 |
| 원문과 정밀도 | 최초 원본 좌표와 DB 좌표 원문 보존. 저장 시 DECIMAL(13,10) 기준 적용. 표시 반올림을 원래 저장값에 역반영하지 않음 |

등록 약자는 청, 태, 해, 묘이며 지정된 `약자#번호-번호` 형식에만 적용한다. 한 글자 포함이나 도시명만으로 연결하지 않는다. 한쪽 좌표만 있는 경우 직접 추출 좌표와 DB의 다른 쪽 좌표를 섞어 한 쌍으로 만들지 않는다. 유효한 원본 좌표를 유지하고 부분 좌표 상태로 검토한다. 상세 보완 방식은 [지역 정책](<rist-policies.md#location-policy>)을 따른다.

## 단위, 원문 및 DB 연결

| 항목 | 기준 |
| --- | --- |
| 단위 정규화 | ug와 µg를 μg로 표기 정규화하고 최초 원문 보존. 복합단위의 분모와 지수 등 의미 유지. 단위 정규화를 수치 환산으로 사용하지 않음 |
| 단위 적용 범위 | 행, 열, 결과표 또는 병합 셀의 실제 범위에만 적용. 첫 단위를 다른 물질이나 시료 전체로 임의 복제하지 않음 |
| 물질명 | CAS, 화학식, 복합 명칭과 구분 기호 보존. M,P-Xylene을 분할하거나 산화물을 원소로 임의 변환하지 않음 |
| DB 연결 | 실제 같은 항목이 유일하게 확인될 때만 ID 연결. 명칭을 확보했다는 이유로 ID 생성 금지. 다른 분석법 ID 대체 금지 |
| 출처 | 직접 읽은 값은 EXTRACTED, 유형 고정값, 미추출 시 기본값과 조건부 보완은 MATCHED로 구분. 단위 표기 정규화만으로 직접 추출 출처를 매칭값으로 바꾸지 않음 |
| 원본 기록 | source_snapshot에 최초 값과 원본 위치 보존. 매칭 근거, 적용 규칙과 버전, 연결 DB 항목을 출처 정보로 유지 |
| 표시 | 분석법 매칭값은 시험방법 코드와 DB 분석법명 함께 표시. 직접 추출값은 확인된 구성만 유지하며 없는 코드나 이름 추정 금지 |

지정 표시명을 유지하며 실제 DB에서 동일 항목이 확인될 때만 ID를 연결한다. 확인 전에는 ID를 NULL로 둔다. ‘자체시험법’이나 다른 코드의 분석법과 임의로 동일시하지 않는다. 시험방법 코드와 고시번호 등 확인되지 않은 값은 추정하지 않는다. 기준 목록은 [분석법 DB](<db-lists/analysis-method.md>)이다. 내부 ID는 UUID이며 목록 문서에 임의 ID를 부여하지 않는다.

## 확인 대상의 범위와 처리

| 구분 | 조건 예시 | 처리 범위 |
| --- | --- | --- |
| 파일 | 구조 판별 불가, 기본 유형과 하위유형 판별 완료 후 독립적인 최종 후보 2개 이상, 시료와 물질 축 미확정 | 먼저 맞은 유형 선택 금지. 판별 불가 사유를 안내하고 정상 유형으로 추출 진행하지 않음. 파일명 보완 실패와 구분 |
| 시트 또는 보고서 | 해당 처리 단위의 구조 또는 결과 범위 불명확 | 독립성, 경계와 결과 소속이 확인되는 정상 단위만 추출 유지. 실패 단위와 사유 및 일부 실패 안내. 분리 불가 시 파일 전체 중단. 아래 공통 처리 기준 적용 |
| 행 | 시료나 물질 소속 불명확, 원본 행 연결 오류 | 해당 행과 사유 식별. 인접 행에 값 전파 금지. 소속이 확정된 결과는 상세 규칙에 따라 유지 |
| 셀 | 단위 해석 실패, 결과 누락 또는 수치 해석 불가 | 해당 셀 원문, 위치와 확인 사유 유지. 임의 0 대체 금지. 숫자값 NULL과 결과 표시 원문을 구분. EXCEL-004 계산 오류는 아래 명시한 error 저장 예외 적용 |
| 보완 실패 | 파일명 조건 불충족, 지점 미대응, DB 동일 항목 미확인 | 파일 거부 사유로 사용하지 않음. 유효한 추출값 유지, 미확정 값 또는 ID는 NULL로 두고 사용자 보완 |

확인 범위는 문제 위치를 뜻하며 모든 확인 대상을 동일한 오류나 삭제 조건으로 처리하지 않는다. n.d 등 허용된 비수치 결과와 실제 오류의 구분, 빈 행 및 빈 결과 제외 기준은 유형별 상세 규칙을 따른다.

### 시트 및 보고서 일부 실패의 공통 처리

지원되는 Excel 유형의 시트와 PDF 유형의 개별 보고서를 처리 단위로 한다. 여러 보고서가 포함된 PDF는 지원되는 유형에서 독립 보고서의 경계와 결과 소속을 명확하게 식별할 수 있는 경우에 적용한다.

| 조건 | 처리 기준 |
| --- | --- |
| 정상 단위 분리 가능 | 단위의 독립성, 경계와 결과 소속이 명확하고 실패 단위에 대한 데이터 의존성이 없으면 정상 시트 또는 보고서의 추출 결과 유지 |
| 일부 단위 실패 | 실패 시트명 또는 보고서 식별명과 사유 안내. 보고서 식별명이 없으면 페이지 범위 등 확인 가능한 식별값 사용 |
| 파일 결과 표시 | 정상 결과가 있어도 일부 실패를 구분하여 안내하고 파일 전체를 정상 완료로 표시하지 않음. 실패 단위를 조용히 제외하지 않음 |
| 분리 불가 | 경계, 결과 소속 또는 데이터 의존성 때문에 정상 부분을 확실하게 분리할 수 없으면 파일 전체 추출 중단 |
| 모든 단위 실패 | 성공 결과가 없는 것으로 처리하고 각 실패 단위와 사유 안내 |
| 행, 셀 또는 보완 실패 | 개별 행, 셀이나 매칭 보완 실패만으로 시트 또는 보고서 전체 실패로 확대하지 않음. 해당 위치의 원문과 확인 사유 및 유형별 세부 처리 기준 유지 |
| 원본 연결 | 유지한 결과의 원본 시트 또는 보고서와 페이지, 행, 셀 등 출처 연결 유지. 실패 단위의 값을 정상 단위에 전파하지 않음 |

유형별로 명시된 추출 제외 범위와 고유한 행 및 셀 처리 예외는 해당 상세 규칙을 따른다.

### EXCEL-004 추출 및 계산 오류 기준

| 항목 | 기준 |
