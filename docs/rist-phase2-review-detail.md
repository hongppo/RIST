## 도구 배치

왼쪽은 일괄 변경 → 비어있는 열만 보기, 오른쪽은 행 더보기 → 표시 행수·전체 행수 → 표 크기 순서입니다. 항목명 옆에 [필수]를 표시합니다.

## 일괄 입력행 열기·접기

일괄 입력행은 처음에 접혀 있습니다. 일괄 변경 버튼으로 열고 접으며, 셀 클릭·Ctrl/⌘ 또는 Shift 선택·범위 드래그·행 선택으로 편집을 시작하면 자동으로 펼칩니다. 접어도 선택과 미적용 입력은 유지합니다. 펼친 상태에서는 선택 열에 한정하지 않고 모든 표시 열의 입력창을 활성화합니다.

## 입력 열과 선택 행을 따로 지정

셀 선택은 적용할 행을 지정하고, 열별 버튼은 적용할 열을 지정합니다. 선택한 셀의 열과 다른 열에도 선택 변경을 적용할 수 있습니다. 각 버튼은 그 열에 준비한 값만 사용합니다. 일괄 변경은 미표시 행을 포함한 전체 171행에 적용하며 다른 열의 준비값은 유지합니다. 입력만으로 반영하지 않고 빈값으로 지우지 않습니다. 목록 검색은 항목 선택 후 적용하며 대상 셀의 미확정 수정은 먼저 확정하도록 안내합니다.

## 비어있는 열만 보기

기본은 해제입니다. 현재 표시된 행만이 아니라 전체 171행에서 한 행이라도 값이 비어 있으면 해당 열을 표시합니다. 모든 행이 비어 있는 열만 표시한다는 뜻은 아닙니다. 0·n.d는 값으로 취급합니다. 채워진 열은 즉시 숨기지 않고 채워진 열 숨기기로 정리합니다. 숨긴 열의 데이터·미적용 입력·선택·수동 너비는 유지합니다.

## 표 크기와 입력 상태 유지

글자 크기가 크다는 피드백을 반영하여, 2차 개선 2단계 화면은 기존 PoC 2단계 화면 대비 80% 크기를 기본값으로 사용합니다. 이 기본값을 0으로 표시합니다. 크기는 PoC 기준 70-100% 범위에서 5%p씩 조절하며, 가운데 숫자를 누르면 기본값 0으로 돌아갑니다. 조절 중에도 입력값과 선택 상태는 유지됩니다. 사용자가 조절한 열 너비도 기본값 0을 기준으로 비례하여 표시하며, 크기를 0으로 복원해도 직접 지정한 열 너비는 유지됩니다.

## 고정 기본폭·수동 너비·말줄임

기본 열 너비는 일반적인 데이터값, 필수 표시를 포함한 헤더, 한 줄 적용 버튼이 모두 보이는 폭에 최소 여백을 더해 정합니다. 내용이 바뀌어도 자동으로 확장하지 않습니다. 표 크기 0에서 분석물질은 139px, 결과는 123px을 기본 너비로 사용하며, 현재 예시 수준의 물질명·CAS 번호와 소수 결과값은 모두 표시합니다. 이 너비를 넘는 긴 값에만 …을 표시하고, 결과값을 반올림하거나 자릿수를 줄이지 않습니다. 마우스를 올리거나 편집하면 전체 값을 확인할 수 있으며, 열 경계를 드래그해 너비를 조절할 수 있습니다. 행 더보기·필터·일괄 입력 행 열기와 접기 후에도 조절한 너비를 유지합니다.

## 표 아래 작업 상태

선택한 열·행수, 미적용 일괄 입력 열, 미확정 셀 수정 건수를 첫 줄에 구분해 표시합니다. 두 번째 줄에는 적용된 작업 데이터의 저장 전 변경 여부와 최종 저장 대상 전체 행수를 표시합니다. 해당 상태만 최대 두 줄로 요약하며 긴 내용은 마우스를 올리면 확인할 수 있습니다. 일괄 입력 대상 없음을 상시 표시하지 않고, 변경 없음만으로 저장 완료라고 표시하지 않습니다.

상태별 예시

1. 선택만 있는 경우
선택: 시료명 · 3개 행
최종 저장 대상: 전체 171행

2. 개별 셀을 수정하고 적용하기 전
셀 수정: 시료명 1건 · 적용 전

3. 일괄 입력 후 적용하기 전
일괄 입력 중: 단위·분석 기관 · 적용 전

4. 값을 적용했으나 작업 저장하기 전
작업 저장 전 변경사항이 있습니다. / 최종 저장 대상: 전체 171행

각 예시는 해당 상태를 구분하기 위한 문구입니다. 여러 상태가 동시에 있으면 함께 표시하며, 변경이 없다는 이유만으로 저장 완료라고 표시하지 않습니다.

## 지도 적용 범위

1단계와 동일한 지도 모달 구성과 검색·선택·신규 등록 흐름을 사용합니다. 신규 등록 양식은 관측 지점명·유효한 위도와 경도를 필수로, 주소·위치 설명을 선택으로 받으며 등록 후 선택합니다.

개별 행에서 열면 해당 행의 유효한 기존 위경도를 불러오고 실제 위치에 포인트·지도 중심을 맞춥니다. 일괄 입력에서 다시 열면 준비한 좌표를 복원합니다. 여러 행의 좌표가 다르거나 한쪽이 누락·유효하지 않으면 첫 행을 대표로 쓰거나 임의 포인트를 만들지 않습니다. 취소는 원래 값을 유지합니다.

개별 행의 적용은 그 행만 변경합니다. 일괄 입력의 확인은 좌표 준비값만 채우고, 지도 열의 선택 변경·일괄 변경으로 대상 행에 반영합니다. 검색·신규 등록·선택으로 다른 열 입력·선택 상태·수동 열 너비를 초기화하지 않습니다.

## 필수 항목 표시

분석물질·결과·단위·채취일자·위도·경도 6개 열의 항목명 옆에 [필수]를 표시하며 값이 있어도 표시를 유지합니다. 최종 저장 대상인 전체 행에 입력이 필요한 항목입니다. 비어있는 열만 보기 필터는 전체 행의 빈값 여부로 판단하므로 필수 여부와는 별개입니다. 결과의 0·n.d는 입력값으로 취급합니다.

## 지역 신규 추가

지역의 신규 추가를 선택하면 지점명, 주소, 위치 설명, 도분초 좌표를 입력하는 양식을 표시합니다. 지점명과 유효한 위도·경도를 입력하면 등록 후 선택을 활성화합니다. 취소하면 기존 값을 유지합니다. 지역 입력에서 등록하면 해당 입력값으로 선택하고, 지도에서 등록하면 해당 위치를 선택합니다. 변경 적용은 기존 변경 버튼을 사용합니다.
