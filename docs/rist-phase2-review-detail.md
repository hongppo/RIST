## 필수 표시

분석물질·결과·단위·채취일자·위도·경도 항목명에 [필수]를 표시합니다. 값이 채워져도 유지합니다. 기존 별표·범례를 [필수]로 통일합니다. 최종 저장은 전체 행을 검사하고 숨긴 필수 열에 오류가 있으면 해당 열과 오류 행을 표시하여 이동합니다.

## 표 크기

| 설정 | 기존 대비 글자 크기 |
| --- | --- |
| -2 | 70% |
| -1 | 75% |
| 0 | 80%: 13px → 10.4px |
| +1 | 85% |
| +2 | 90% |
| +3 | 95% |
| +4 | 100% |

- 표 바로 위 필터행의 오른쪽 끝에 표 크기 [−] [0] [+]를 배치합니다. 왼쪽에는 열 요약·입력할 열만 보기 체크박스가 있고, 기존 도구행의 일괄 변경·행수·행 추가 위치는 유지합니다.
- 클릭 한 번에 5%p씩 변경합니다. 가운데 숫자를 누르면 0으로 돌아갑니다. 최초 접속·새로고침은 0입니다.
- 기본 좌우 패딩은 4px이며 전체 171행의 표시값과 열 제목·[필수] 글자의 실제 폭을 측정하고 소량의 여백을 더합니다. 로드된 행만으로 계산하거나 고정 열폭·남는 공간 강제 분배를 사용하지 않습니다.
- 현재 편집 열만 입력·확정·드롭다운·날짜 컨트롤의 최소 폭으로 넓힙니다. 일괄 영역은 선택한 열의 컨트롤만 표시하고 비활성 열의 자리는 유지하여 전체 조회 열이 넓어지지 않게 합니다. 입력·확정·표 크기 변경·추가 조회 시 폭을 갱신합니다.
- 글자 크기·간격은 0 기준으로 비례 조절하고 열폭은 해당 글자 크기로 다시 측정합니다. 선택 체크박스·행 번호·조작 버튼은 최소 크기를 유지합니다.
- 표 헤더·셀·입력·일괄 영역만 조절합니다. 제목·단계·도구·저장·지도 모달의 크기는 바꾸지 않습니다.
- 조회값은 말줄임하고 마우스를 올리면 전체 값을 표시합니다. 크기 변경은 선택·미확정 입력을 유지합니다.

## 입력할 열만 보기

- 기본 해제이며 모든 열을 표시합니다. 체크하면 표시된 행만이 아닌 전체 171행의 적용된 작업 값을 검사합니다. 한 행이라도 빈칸이면 열을 표시하고 전체 값이 있으면 숨깁니다. 0·n.d는 빈칸이 아닙니다.
- 선택·행 번호는 항상 유지합니다. 위도 또는 경도 열이 보이면 지도 열도 표시합니다. 필수 여부와 관계없이 같은 기준을 적용하며 기존 열 순서를 유지합니다.
- 필터행 왼쪽에 “입력할 열 N개 · 채워진 열 M개 숨김”과 입력할 열만 보기 체크박스를 표시합니다. 열 개수는 데이터 열 기준이며 선택·행 번호·지도 조작 열을 제외합니다.
- 체크를 해제하면 전체 열을 표시합니다. 다시 켜면 최신 작업 값으로 판단합니다. 별도 모든 열 펼치기 버튼은 제공하지 않습니다.
- 마지막 빈칸을 채워도 입력 중 열을 즉시 숨기지 않습니다. 적용 후 “새로 채워진 열 N개가 있습니다.”와 채워진 열 숨기기를 표시합니다.
- 되돌리기로 숨긴 열에 빈칸이 생기면 다시 표시합니다. 모든 열이 채워지고 숨겨졌으면 빈 표 대신 안내를 표시하며 동일한 체크박스를 해제해 전체 열을 확인합니다.
- 필터는 데이터·저장·선택·미확정 입력과 무관한 표시 기능입니다. 초기 미확정 시료명 예시는 기본 전체 열 상태에서 바로 확인할 수 있습니다.

## 유지 범위

기존 단일·Cmd/Ctrl·Shift·드래그 선택, 선택 변경·일괄 변경, 지도 좌표 쌍 적용, 작업 저장·되돌리기, 최종 검증은 유지합니다. 실제 앱·DB·서버 저장 구현이 아닌 화면 내 임시 상태 목업입니다. 최종 저장 확인 화면은 기존 PoC 예시 연결을 유지하며 이번에 복제하지 않습니다.
