화면 ID: `rist-phase4-upload-duplicates`

## 중복 의심 안내

업로드 및 유형 분석 단계에서는 현재 묶음과 과거 업로드 이력의 파일명 일치 여부만 확인하며 원본 내용의 동일성은 검사하지 않습니다. 같은 파일명이 있어도 자동 제외하거나 업로드를 차단하지 않으며 사용자가 계속 검토하거나 제외할지 결정합니다. VOCs_20261027_01.csv와 VOCs_20261027_03.csv는 각각 같은 파일명의 과거 업로드 이력 1건이 있는 상태입니다. 다른 사용자 검토 중 2건은 같은 파일명을 사용한 미완료 작업 수이며 계정, 업로드 시각, 상세 정보와 링크는 노출하지 않습니다.

## 검토에서 제외

각 행 우측 ×로 현재 묶음의 검토 대상에서 제외합니다. 과거 이력이나 기존 저장 데이터를 삭제하지 않습니다. 제외한 원본의 보관 및 삭제 시점과 제외 취소 제공 여부는 별도 확정합니다.
