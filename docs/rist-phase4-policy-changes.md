## 여러 파일 업로드 정책 요약

| 항목 | 핵심 정책 |
| --- | --- |
| 진입과 이력 | 공통 첫 화면 중앙의 1:1 좌측 단일 및 우측 여러 파일 업로드 영역. 처리 흐름과 이력 분리 |
| 업로드 한도 | 접수 전 선택 파일 총수 최대 20개, 파일당 20MB 이하, 전체 400MB 이하. 전체 용량은 개발 검토 의견에 따라 조정 가능. 용량은 1MB = 1,024 × 1,024바이트로 계산. 등록된 지원 유형 수는 별도 제한 없음. 미지원 파일은 기존 기준 적용 |
| 전체 용량 초과 | 전체 400MB를 초과하면 접수 및 진행을 차단하고 기준 이하로 재선택 안내 |
| 초과 선택 | 20개 초과 시 접수하지 않고 20개 이하로 재선택 안내. 일부 파일만 임의 업로드하지 않음 |
| 그룹 구성 | 같은 업로드 묶음의 동일 추출 유형으로 구성. 서로 다른 묶음은 자동 병합하지 않음 |
| 정렬 | 유형 코드순, 그룹 안 파일명순. 같은 파일명은 업로드 순서로 구분 |
| 중복과 제외 | 단일 및 여러 파일의 업로드와 유형 분석에서는 파일명만 1차 확인. 현재 묶음과 과거 이력 비교, 내용 동일성 검사 및 자동 차단 없음. 사용자가 검토 포함 여부 결정 |
| 파일별 검토 | 유형 그룹 안에서 파일 이동. 원본, 결과, 오류 및 출처의 파일별 구분 유지 |
| 검사와 저장 | 그룹의 모든 대상 파일과 결과 검사. 그룹 전체 저장 완료 확인 후 사용자가 다음 그룹 검토를 선택하면 이동 |
| 부분 실패 | 그룹 전체 완료로 표시하지 않고 실패 범위 안내. 다음 그룹 자동 진행 금지 |
| 임시 보관 | 미완료 그룹별 30일. 실제 값 변경을 서버에 적용한 그룹만 기간 갱신 |
| 만료 | 만료 후 재개, 수정 및 원본 다운로드 차단. 정기 정리로 원본과 검토 데이터 삭제, 이력 유지 |
| 재개 | 마지막 파일과 1단계 또는 2단계로 복귀. 3단계 중단은 2단계 복귀 후 전체 재검사 |
| 권한 | 미완료 그룹은 업로드 계정만 접근. 다른 계정 미완료 정보는 동일 파일명 검토 중 건수 외 비공개 |
| 실패 이력 삭제 | 단일 및 여러 파일의 추출 실패와 미지원 개별 파일 이력만 업로드 계정이 삭제. 사용자 표시를 숨기며 내부 기록과 원본 보관 기간 유지 |
| 원본 보관 | 미완료 원본 NAS 전송 금지. 완료 원본은 NAS 저장 검증 후 서버 사본 삭제 |
| 상태 구분 | 그룹 최종 저장 성공과 NAS 전송 상태 분리. NAS 대기 및 실패로 완료 그룹의 만료 기간을 다시 적용하지 않음 |

## 상세 정책

- [여러 파일 업로드 정책](#rist-phase4-multi-upload-policy)
- [그룹 저장 및 원본 다운로드 정책](#rist-phase4-group-storage-policy)
- [실패 파일 업로드 이력 삭제 정책](#rist-failed-upload-history-deletion-policy)

그룹 전체 최종 저장 성공 시 [그룹 저장 완료](#rist-phase4-group-saved)에서 유형, 파일 수와 결과 행 수를 확인한다. 남은 그룹이 있으면 같은 완료 화면 아래에 다음 그룹 검토 여부와 다음 유형 및 파일 수를 표시하며, 사용자가 다음 그룹 검토를 선택하면 해당 그룹의 1단계로 이동한다. 나중에 검토를 선택하면 해당 업로드 묶음 상세로 이동한다. 단순 보류는 미완료 그룹의 보관 기간을 갱신하지 않으며 기존 권한 기준을 유지한다. 남은 그룹이 없으면 다음 그룹 질문을 표시하지 않고 완료 확인으로 모든 그룹 완료에 연결한다.

추출 실패 및 지원하지 않는 파일은 묶음 상세에 처음부터 그룹 없는 파일로 표시하고 개별 업로드 이력 상세로 연결한다. 업로드 계정만 해당 미완료 파일을 조회하며, 다른 계정에는 해당 파일의 정보와 링크를 표시하지 않는다. 이력을 삭제하면 사용자 목록과 상세에서 숨기되 원래 업로드 총수, 정상 파일과 유형 그룹은 유지한다. 내부 기록과 기존 원본 보관 기간은 변경하지 않는다.

## 미확정 사항

| 항목 | 미확정 내용 |
| --- | --- |
| 제외 파일 | 원본 보관 및 삭제 시점, 검토 시작 전 제외 취소 |
| 추출 중 취소 파일 | 묶음 이력 표시와 재진입 상세 방식 |
| 그룹 저장 실패 | 중복 저장 방지 재시도 및 부분 저장 복구 방식 |
| 운영 정보 | 최종 저장과 삭제 동시 처리 방지, 실사용 시작일 및 NAS_FINAL_SINCE, 환경별 NAS 응답 대기 시간 |
