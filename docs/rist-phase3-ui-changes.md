## UI 변경 사항

| 대상 | 기능 요구 | 상세 화면 |
| --- | --- | --- |
| 2단계 | 표의 위치 영역에 지도 컬럼과 지도 보기 버튼을 제공하고 기존 2차 지도 모달에 연결한다. | [데이터 검토: 2단계](../pages/rist-phase2-review-detail.html) |
| 3단계 | 표의 위치 영역에 지도 컬럼과 지도 보기 버튼을 제공하고 기존 2차 지도 모달에 연결한다. | [최종 저장 전 통합 검사: 3단계 오류 검토](../pages/rist-phase2-final-validation.html) |
| 업로드 이력 목록 | 업로더, 처리 상태와 보관 만료일을 표시하고 상태별 상세 화면으로 연결한다. | [업로드 이력](../pages/rist-phase3-upload-history.html) |
| 이력 상세: 검토 중 | 검토 데이터와 보관 만료 안내를 표시하고 검토 재개 및 원본 다운로드를 제공한다. | [이력 상세(검토 중)](../pages/rist-phase3-history-review.html) |
| 이력 상세: 최종 저장 완료 | 저장된 결과와 원본 다운로드를 제공한다. 검토 재개와 보관 만료 안내는 표시하지 않는다. | [이력 상세(최종 저장 완료)](../pages/rist-phase3-history-complete.html) |
| 이력 상세: 보관 기간 만료 | 이력 정보와 만료 안내를 표시한다. 검토 데이터, 검토 재개 및 원본 다운로드는 제공하지 않는다. | [이력 상세(보관 기간 만료)](../pages/rist-phase3-history-expired.html) |
| 이력 상세: 추출 실패 | 추출 실패, 미지원 및 취소 상태별 안내를 표시하고 보관 기간 내 원본 다운로드를 제공한다. 검토 데이터와 검토 재개는 제공하지 않는다. | [이력 상세(추출 실패)](../pages/rist-phase3-history-failed.html) |

지도 모달의 구성과 동작 기준은 연결된 2차 개선 화면과 설명을 따른다.
