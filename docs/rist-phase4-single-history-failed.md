## 단일 파일 이력 상세(추출 실패)

화면 ID: `rist-phase4-single-history-failed`

## 표시 및 동작

단일 파일과 여러 파일 업로드에 동일하게 적용합니다. 추출 실패 또는 지원하지 않는 파일의 이력 상세 하단에 업로드 계정만 이력 삭제를 사용할 수 있습니다. 검토 중, 완료, 만료, 취소됨 이력에는 제공하지 않습니다. 이력 삭제는 사용자 목록과 상세에서 숨기는 동작이며 내부 처리 기록과 업로드일부터 30일의 원본 보관 기준은 유지합니다. 보관 기간은 갱신하지 않으며 원본을 즉시 삭제하지 않습니다. [실패 파일 업로드 이력 삭제 정책](#rist-failed-upload-history-deletion-policy)을 적용합니다. 해당 파일의 상태, 업로드 계정과 시각, 보관 만료일을 표시합니다. 이력 삭제를 선택하면 [이력 삭제 확인(단일 파일)](#rist-phase4-history-delete-single)으로 이동합니다.

화면 제목은 업로드 이력 상세로 표시하며 실패 또는 미지원 상태는 작업 상태 항목으로 구분합니다. 상단 오른쪽의 목록으로와 원본 파일 다운로드, 하단의 이력 삭제를 유지합니다.

정보 카드 아래에 중립 색상의 안내 영역 하나를 표시합니다. 추출 실패는 “추출에 실패하여 검토 데이터가 없습니다.”, 미지원은 “지원하지 않는 파일로 검토 데이터가 없습니다.”로 안내하며 위치, 색상과 여백은 동일하게 적용합니다.
