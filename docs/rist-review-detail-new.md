## 검토 목적 · 단계 이동

기존 2단계를 유지한 신규 셀 선택안입니다. 최초 5행을 표시하며, 1단계에서 필수값이 비어 있어도 2단계로 이동할 수 있습니다. 최종 저장 시에는 파일 전체 행의 필수값을 검증합니다.

1단계는 첫 행을 표시하므로 첫 행의 값이 바뀔 때만 해당 표시값도 갱신합니다. 단계 이동 시 작업 저장 여부를 확인합니다. 목업의 데이터 변경은 화면 내 임시 상태이며 실제 DB 저장은 연결하지 않습니다.

## 작업 저장 · 되돌리기

파일 정보 영역의 저장은 작업 저장 기준점을 만듭니다. 셀의 ✓ 확정, 일괄 적용, 지도 좌표 적용은 작업 데이터 변경이며 저장 기준점을 만들지 않습니다. 각 적용은 되돌리기 한 단계이고, 마지막 작업 저장 이후 최대 10단계까지 되돌립니다. 작업 저장 이전이나 최종 저장된 데이터로는 되돌리지 않습니다.

현재 목업은 첫 행 시료명을 RIST_Sample에서 RIST_Sample_01로 입력한 미확정 상태입니다. ✓ 버튼으로 확정한 뒤 작업 저장을 할 수 있습니다.

## 조회 · 전체 데이터 범위

최초 5행에서 50행 추가·100행 추가·전체 데이터 보기를 사용합니다. 선택 변경은 직접 지정한 셀 범위에, 일괄 변경은 표시 여부와 관계없이 해당 열 전체 171행에 적용합니다. 추가 조회해도 선택과 변경 상태를 유지합니다.

표 내부 가로·세로 스크롤을 사용하며 열 제목·일괄 영역·행 번호를 고정합니다. 하단 최종 저장은 전체 데이터를 대상으로 합니다.

## 같은 열의 셀 선택 · 일괄 변경

단일 셀을 클릭하면 그 셀만 편집합니다. Windows Ctrl 또는 Mac Cmd+클릭은 비연속 선택, Shift+클릭은 기준 셀부터 연속 선택이며 같은 열에서만 허용합니다. 다른 열을 선택하면 이전 선택을 해제하고 새 열에서 시작합니다. 데이터 셀에서 마우스로 위아래 드래그하면 시작한 열의 연속 범위를 선택하며, 옆 열로 벗어나도 선택 열은 유지합니다. 드래그는 기존 선택을 새 범위로 바꿉니다. 입력창·콤보박스·버튼에서는 드래그 선택을 시작하지 않습니다. 표 스크롤은 가능하지만 가장자리 자동 스크롤은 지원하지 않으므로 필요한 행을 먼저 조회·스크롤한 뒤 선택합니다. 행 왼쪽 체크박스는 현재 선택 열의 해당 셀이 선택됐음을 표시합니다. 단일·Cmd/Ctrl·Shift·드래그 선택과 체크 상태를 동기화합니다. 체크박스를 직접 조작해도 현재 열의 해당 셀만 선택·해제하며 다른 열은 선택하지 않습니다. 활성 열이 없으면 체크박스를 비활성화합니다. 셀 안의 ✓는 변경 확정 버튼이며 왼쪽 선택 체크박스와 역할이 다릅니다.

복수 선택 시 상단 일괄 변경 영역이 자동으로 열립니다. 선택한 열의 입력만 활성화합니다. 기존 2단계처럼 일괄 입력 바로 아래 변경 적용 행에 선택 변경 / 일괄 변경 버튼을 같은 순서와 간격으로 배치하며, 선택 변경은 직접 선택한 셀만 바꾸고 일괄 변경은 해당 열 전체 171행을 바꿉니다. 전체 선택·선택 해제 도구는 제공하지 않습니다. 선택이 없으면 적용하지 않습니다. 접기는 선택을 유지하며 데이터에 적용하지 않습니다.

## 개별 편집 · DB 입력 · 확정

셀 내부 우측 ✓는 행 선택용 체크박스가 아니라 변경 확정 버튼입니다. 편집 전에는 비활성, 값이 달라지면 배경색과 버튼을 활성화하고 원복하거나 확정하면 비활성화합니다. 개별 변경은 해당 셀에만 적용하며 다른 선택 셀로 자동 전파하지 않습니다.

구분·매체·담당자·분석 기관·BASE·채취법·분석법·단위와 지역명은 검색 혹은 선택합니다. 목록의 신규 추가로 임시 항목을 선택할 수 있으나 실제 DB 등록은 연결하지 않습니다. 검색 문자열은 선택 전까지 확정하지 않습니다. 시료명·분석물질·결과는 직접 입력하고 날짜·시간·분석 기간·도분초 좌표는 해당 양식을 사용합니다. 표·뷰어 스크롤 시 목록을 닫고 목록 내부 스크롤은 유지합니다.

일반 개별·일괄 편집은 선택한 열만 바꿉니다. 지도 적용은 위도·경도를 함께 바꾸는 예외이며 다른 필드는 유지합니다.

## 지도 보기 · 좌표 적용

경도 오른쪽 지도 열의 지도 보기는 해당 행의 좌표를 표시하며 그 행에만 적용합니다. 위도·경도 또는 지도 열의 셀을 세로로 선택한 뒤 상단 지도 보기 또는 선택 변경을 누르면 선택 범위를 대상으로 엽니다. 지도 열의 일괄 변경은 전체 행을 대상으로 열고 모달에 전체 N개 행을 명시합니다. 지도 버튼에서 Ctrl/Shift+클릭은 셀 범위 선택으로 동작합니다.

모달 제목은 위치 선택이며 적용 대상에 해당 행 / 선택한 N개 행 / 전체 N개 행을 표시합니다. 서로 다른 좌표를 선택하면 여러 위치로 표시하고 단일 좌표로 채우지 않습니다. 지도에서 선택하거나 위도·경도를 입력하면 좌표 적용이 활성화됩니다. 취소는 변경하지 않습니다.

좌표 적용은 위도·경도를 항상 쌍으로 변경하며 지점명과 다른 필드는 바꾸지 않습니다. 지점 검색은 좌표를 찾는 선택 기능으로, 새 지점 등록을 요구하지 않습니다. 별도 신규 지점 등록을 진행할 때만 지점명과 좌표가 필수입니다. 목업 지도는 1단계의 지도 그림과 도분초 표기를 재사용했으며 실제 지도 SDK는 연결하지 않았습니다.

## 필수값 · 최종 검토 완료 및 저장

필수 항목은 분석물질·결과·단위·채취일자·위도·경도입니다. 최종 저장 전에 표시·선택 여부와 관계없이 전체 데이터 행을 검증합니다. 실제 0과 n.d는 공란으로 취급하지 않습니다.

누락 셀은 테두리로 표시하고 전체 누락 개수를 안내합니다. 첫 누락 위치는 행 순서, 같은 행에서는 열 순서로 정합니다. 아직 조회하지 않은 행이면 해당 행까지 불러와 가로·세로 위치를 이동하고 셀을 편집 가능하게 표시합니다. 미확정 셀 변경은 먼저 확정하도록 안내합니다.

검토 완료 및 저장은 최종 저장 확인으로 연결합니다. 저장 중 중복 실행을 막고 성공 시 결과를 표시하며 실패 시 변경값과 작업 이력을 유지합니다.
