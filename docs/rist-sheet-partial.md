## 시트 확인(일부 추출)

- 페이지 ID: `rist-sheet-partial`
- 위치: 오류 화면 다음, 화면 기획서 8페이지

### 진입 조건

Excel 파일에서 추출된 시트가 1개 이상이고 다른 시트가 추출 불가 또는 데이터 없음인 경우 진입합니다. 전체 시트 정상은 기존 검토 흐름, 추출 성공 0개는 기존 오류 화면으로 연결합니다. 파일 전체 실패 상태가 아닙니다.

### 시트별 처리 결과

추출 완료는 검토 가능한 결과가 있는 상태입니다. 추출 불가는 구조 미충족·유형 불확정·읽기 실패 등을 구분해 확인된 사유만 안내합니다. 데이터 없음은 양식은 확인했으나 결과가 없는 상태로, 추출 불가와 구분합니다. 파일명과 100개 시트는 중립 예시이며, 추출 완료 80개(각 24건, 총 1,920건)·추출 불가 10개·데이터 없음 10개로 구성합니다. 시트 목록 내부만 세로 스크롤하며 표 헤더는 고정합니다. 검토 범위 안내와 버튼은 스크롤 영역 밖에 유지합니다.

### 검토·저장 범위

추출 완료 시트의 데이터만 검토·저장 대상입니다. 추출되지 않은 시트는 이번 저장에서 제외되며 원본 시트를 삭제하지 않습니다. 일부 시트 제외 정보는 검토 중·최종 저장 확인·업로드 이력에도 보존해야 합니다. 해당 후속 화면 연결은 이번 목업에 포함하지 않습니다.

### 버튼 이동

다시 업로드는 [파일 업로드](#rist-upload)로 이동합니다. 추출된 시트로 검토는 현재 추출된 데이터만 대상으로 [1단계 초기 상태](#rist-review-preparation-initial)로 이동합니다. 추가 승인 모달 없이 진행하며 시트 선택·실패 시트 재시도·유형 수동 선택은 제공하지 않습니다.
