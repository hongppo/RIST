## 동일 파일명 확인 정책

| 항목 | 기준 |
| --- | --- |
| 화면 ID | rist-phase2-duplicate-filename |
| 화면 기반 | PoC 파일 업로드 화면의 별도 복사본 |
| 검사 순서 | 기존 기본 파일 검사 후 동일 파일명 이력 확인 |
| 범위 | 기존 업로드 이력 전체. 다른 사용자의 이력도 포함 |
| 비교값 | 확장자를 포함한 원본 파일명이 같은지 확인 |
| 의미 | 이름이 같다는 이유만으로 내용이 같은 파일이라고 판단하지 않음 |
| 처리 | 동일명 없음: 진행. 동일명 있음: 경고 확인 후 계속 가능. 업로드 차단 기준 아님 |

## 기본 파일 검사

기존 정책의 파일 1개, CSV·PDF·XLSX, 파일당 20MB 이하, 0바이트 불가 기준을 그대로 사용합니다. 확장자 검사에서는 기존의 대소문자 비구분을 유지합니다. 이 확장자 허용 검사는 동일 파일명 비교의 대소문자 규칙 확정을 뜻하지 않습니다.

목업은 파일 선택 시 기본 검사를 하고 업로드 및 추출을 누르면 기본 검사를 다시 확인한 뒤 동일명 예시 이력을 조회합니다. 파일 내용은 읽거나 전송하지 않습니다.

## 경고 확인

| 항목 | 표시·동작 |
| --- | --- |
| 문구 | 같은 이름의 파일이 업로드된 이력이 있습니다. |
| 정보 | 원본 파일명, 동일명 N건, 최근 업로드 일시 |
| 안내 | 같은 이름이라도 파일 내용은 다를 수 있습니다. |
| 일치 이력 펼침 | 업로드 일시·업로더·처리 상태. 요약 개수와 실제 목록 개수 일치 |
| 취소 | 파일 선택과 업로드 화면을 유지하고 처리를 시작하지 않음 |
| 계속 업로드 | 별도 신규 처리로 시작. 기존 이력·데이터·파일을 덮어쓰지 않음 |

## 예시와 확인 필요사항

예시 SIFT-MS offline.csv의 동일명 이력은 3건이며 업로더 박보검·김희진·김민수가 각각 포함됩니다. 화면의 최근 일시와 목록은 같은 예시 배열에서 계산합니다. 실제 이력 조회·파일 업로드·API·DB 호출은 하지 않습니다.

파일명 정규화, 대소문자 취급, 경로·공백 처리의 별도 규칙은 미확정입니다. 이번 목업은 전달된 원본 이름 문자열의 일치만 예시로 구현하며, 임의 정규화·대소문자 변환을 적용하지 않습니다.
