## 검사 흐름

1. 검토 완료 및 저장을 선택하면 미확정 셀·목록 검색·일괄 입력을 확인합니다. 입력은 유지하고 기존 확정 버튼으로 먼저 적용하도록 안내하며 임의 반영하지 않습니다.
2. 전체 행의 분석물질·결과·단위·채취일자·위도·경도 6개 필수값과 기존 입력 형식을 검사합니다. 좌표는 도분초 형식·범위, 날짜는 실제 존재하는 날짜, 분석 기간은 기존 최소값 1일을 확인합니다.
3. 분석일자가 입력된 경우 채취일자보다 빠른 날짜인지 검사합니다. 비교는 날짜 단위로 하며 시간 선후 기준은 확정하지 않습니다. 값은 임의 보정하지 않습니다.
4. 오류가 있으면 저장 확인창 대신 표 위에 유지되는 오류 영역을 표시합니다. 수정·확정 후에도 자동 저장하지 않고 다시 검사하도록 안내합니다.
5. 검사 통과 시에만 저장 확인창을 표시합니다. 선택 항목 공란은 저장을 차단하지 않습니다.

0·n.d·기존 부등호 결과값은 공란으로 취급하지 않습니다. 현재 표시·선택 행과 관계없이 파일 전체를 검사합니다.

## 기획용 예시 상태

화면 맨 위의 예시 전환은 제품 영역과 구분합니다. 전환하면 임시 입력과 선택을 초기화합니다. 기본 화면은 검토 완료 및 저장을 눌러 오류가 확인된 상태입니다.

| 상태 | 데이터와 표시 |
| --- | --- |
| 필수 누락·날짜 오류 | 단위 3·8행 누락, 위도·경도 12행 누락, 분석일자 20행이 채취일자보다 빠름. 총 4개 행·5개 오류. 담당자 12행과 분석 기관 3행도 비어 있으나 선택 항목이므로 오류 개수에서 제외 |
| 검사 통과·선택 미입력 | 필수·형식·날짜 검사 통과. 담당자 12행·분석 기관 3행, 총 2개 선택 셀만 미입력 |
| 모두 입력·검사 통과 | 필수·형식·날짜 검사 통과. 선택 항목도 모두 입력 |

오류 예시의 20행은 채취일자 2025/05/16, 분석일자 2025/05/15입니다. 예시 결과 1행은 0, 2행은 n.d로 유지합니다.

## 오류 영역과 위치 이동

- 요약에 검사 대상 전체 171행, 오류가 있는 행 수, 오류 개수를 표시합니다.
- 항목별 버튼에는 대상 행을 표시합니다. 여러 행은 앞의 3개 행과 나머지 건수를 요약하고 전체 오류 목록에서 모든 항목·행·사유·입력 위치로 이동을 제공합니다.
- 이전·다음 오류는 행 순서, 같은 행에서는 기존 열 순서로 이동합니다.
- 이동 시 숨긴 열을 펼치고 필요한 행까지 조회한 뒤 가로·세로 스크롤과 셀 편집 위치를 맞춥니다. 좌표가 표시되면 지도 열도 표시합니다.
- 오류 셀은 붉은 테두리, 현재 오류는 더 굵은 테두리로 구분합니다. 검사 결과는 다시 검사할 때 갱신합니다.
- 미확정 입력이 있으면 오류 위치 이동 전에 확정을 요청하여 입력 손실을 막습니다. 입력할 열만 보기는 기본 해제이며 모든 열을 표시합니다. 필터행 왼쪽 체크박스만으로 켜고 끄며 별도 모든 열 펼치기 버튼은 두지 않습니다. 표 크기는 같은 행 오른쪽 끝에 배치합니다.
- 열폭은 전체 171행의 표시값·제목·[필수] 글자 폭과 소량의 여백으로 계산하며 현재 편집 열에만 컨트롤 최소 폭을 확보합니다. 일괄 영역은 선택한 열의 컨트롤만 표시합니다. 크기 변경·입력·확정·추가 조회 시 폭을 갱신하고 검사 오류 이동 기능은 유지합니다.
