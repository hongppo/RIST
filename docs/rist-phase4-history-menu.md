## 이력 진입 메뉴

화면 ID: `rist-phase4-history-menu`

## 표시 및 동작

프로필 메뉴는 파일 업로드로 돌아가기, 업로드 이력(단일 파일), 업로드 이력(여러 파일), 로그아웃 순서로 제공합니다. 파일 업로드로 돌아가기는 공통 첫 화면으로, 각 이력은 해당 목록으로 이동합니다. 로그아웃은 로그인 화면으로 이동합니다. 각 이력에서 데이터별 조회 권한을 적용합니다. 프로필 버튼 바로 아래에 오른쪽을 맞춰 메뉴를 표시합니다. 배경은 단일 파일과 여러 파일을 좌우 같은 크기로 제공하는 공통 초기 업로드 화면입니다. 단일 영역에는 파일당 20MB 이하, 여러 파일 영역에는 최대 20개 / 파일당 20MB 이하를 안내합니다. 두 영역 아래 공통 동작 영역의 맨 오른쪽에 다음 단계로 버튼을 배치하며, 파일 선택 전에는 비활성화합니다.

업로드 이력(단일 파일)은 [단일 파일 이력 목록](#rist-phase4-single-upload-history)으로 연결하며 실패 및 미지원 이력의 상세와 삭제 후 복귀도 같은 목록을 사용합니다.
