## 조회 범위와 상태

미완료 작업은 업로드 계정만 조회하고, 완료 작업은 이력 조회 권한이 있는 사용자에게 표시합니다. 소유자는 업로드 당시 로그인 계정이며 공용 계정은 같은 계정 사용자끼리 공유하고 SSO 도입 후 개인 계정으로 구분합니다. 마지막 실제 값 변경 적용일, 변경이 없으면 업로드일부터 30일을 계산합니다. 조회, 다운로드, 변경 없는 저장은 연장하지 않습니다. 추출 실패, 미지원, 추출 중 취소는 업로드일부터 계산합니다. 만료 예정은 만료일 7일 전 한국 시간 00:00부터 기본 상태와 함께 표시합니다. 만료일 다음 날 00:00부터 데이터 정리 실행 여부와 무관하게 재개, 수정, 원본 다운로드와 직접 주소 및 API 접근을 차단합니다.
