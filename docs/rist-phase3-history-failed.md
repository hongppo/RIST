## 이력 상세(추출 실패)

화면 ID: `rist-phase3-history-failed`

## 실패와 취소 상태

추출 실패, 지원하지 않는 파일, 취소됨은 목록에서 선택한 상태와 파일정보를 표시합니다. 검토 데이터와 이어서 검토는 제공하지 않으며 보관 기간 내 본인 원본 다운로드를 허용합니다. 미완료 작업은 업로드 계정만 조회하고, 완료 작업은 이력 조회 권한이 있는 사용자에게 표시합니다. 소유자는 업로드 당시 로그인 계정이며 공용 계정은 같은 계정 사용자끼리 공유하고 SSO 도입 후 개인 계정으로 구분합니다. 마지막 실제 값 변경 적용일, 변경이 없으면 업로드일부터 30일을 계산합니다. 조회, 다운로드, 변경 없는 저장은 연장하지 않습니다. 추출 실패, 미지원, 추출 중 취소는 업로드일부터 계산합니다.

## 원본 다운로드 안내

미완료 원본은 보관 기간 내 업로드 계정에게, 완료 원본은 해당 이력 조회 권한자에게 제공합니다. 현재 저장 위치에 따라 운영 서버 또는 NAS 원본을 업로드 당시 파일명과 확장자로 제공하며 엑셀 내보내기는 제공하지 않습니다. 다운로드는 사용자, 시각, 대상 파일을 감사 로그에 기록합니다. 안내 문구: 권한 없음 — 이 작업을 볼 수 있는 권한이 없습니다. / 만료된 작업 재개 — 보관 기간이 만료되어 이어서 검토할 수 없습니다. / NAS 연결 장애 — 원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요. / 파일 부재 — 원본 파일을 찾을 수 없습니다. / 다운로드 만료 — 보관 기간이 만료되어 원본을 다운로드할 수 없습니다. NAS 대기 시간은 10초를 기준으로 운영 환경에 맞춰 조정합니다.
