## 추출 실패 안내(Excel 일부 실패)

## 표시 조건과 적용 범위

추출 처리 후 검토 화면 진입 전에 표시합니다. 팝업 바깥 클릭과 Esc로 닫지 않으며 하단 버튼으로 이동합니다. 실패 목록만 내부 스크롤하고 제목, 안내, 요약과 하단 버튼은 고정합니다. 독립성, 경계와 결과 소속이 명확하고 실패 단위에 데이터 의존성이 없는 정상 결과만 검토를 계속합니다.

지원되는 Excel 유형의 시트와 PDF 유형의 개별 보고서를 처리 단위로 합니다. PDF는 지원 유형에서 독립 보고서의 경계와 결과 소속을 명확하게 식별할 수 있을 때 적용합니다. 집계는 실제 독립적으로 식별되어 추출 대상이 된 처리 단위만 포함합니다. 유형 규칙에 따라 정상적으로 제외되는 단위는 집계와 실패 목록에서 제외합니다. 빈 단위, 매칭 실패 또는 개별 셀 오류만으로 시트나 보고서 전체 실패로 확대하지 않으며 유형별 처리 기준을 적용합니다.

[총괄 규칙](<rist-phase3-type-rule-overview.md>)

정상 추출 결과가 없거나 정상 부분을 분리할 수 없으면 기존 추출 실패 처리로 전환하고 확인 가능한 실패 내역과 사유를 안내합니다. [기존 추출 실패 화면](<../pages/rist-error.html>)

## 요약 및 실패 항목

요약: 전체 5개 시트 중 3개 추출 완료, 2개 추출 실패

실패 시트명 또는 보고서 식별명과 사유를 표시합니다. 보고서명이 불명확하면 “보고서 2 (7-9페이지)”처럼 순번과 확인 가능한 페이지 범위로 식별합니다. 내부 오류 코드, 스택 추적과 원문 오류 메시지는 노출하지 않습니다.

## 사유 문구

| 구분 | 사용자 안내 |
| --- | --- |
| 구조 확인 불가 | 추출에 필요한 표 구조를 확인할 수 없습니다. |
| 결과 영역 확인 불가 | 결과 영역을 확인할 수 없습니다. |
| 시료 연결 확인 불가 | 시료와 결과값의 연결 관계를 확인할 수 없습니다. |
| 분석물질 연결 확인 불가 | 분석물질과 결과값의 연결 관계를 확인할 수 없습니다. |
| 읽기 실패 | 내용을 읽을 수 없습니다. 파일 상태를 확인해 주세요. |
| 처리 오류 | 추출 중 오류가 발생했습니다. 다시 업로드해 주세요. |

## 하단 동작

업로드 화면으로 돌아가기는 파일 업로드 화면으로 이동합니다. 정상 항목 검토하기는 성공한 단위의 결과만 검토 1단계로 전달하며 실패한 단위의 값은 포함하지 않습니다. 유지한 결과의 시트, 보고서와 페이지, 행, 셀 출처 연결을 보존합니다.
