## 이력 상세(검토 중)

화면 ID: `rist-phase3-history-review`

## 검토 중과 만료 안내

미완료 작업은 업로드 계정만 조회하고, 완료 작업은 이력 조회 권한이 있는 사용자에게 표시합니다. 소유자는 업로드 당시 로그인 계정이며 공용 계정은 같은 계정 사용자끼리 공유하고 SSO 도입 후 개인 계정으로 구분합니다. 마지막 실제 값 변경 적용일, 변경이 없으면 업로드일부터 30일을 계산합니다. 조회, 다운로드, 변경 없는 저장은 연장하지 않습니다. 추출 실패, 미지원, 추출 중 취소는 업로드일부터 계산합니다. 만료 예정은 만료일 7일 전 한국 시간 00:00부터 기본 상태와 함께 표시합니다. 만료일 다음 날 00:00부터 데이터 정리 실행 여부와 무관하게 재개, 수정, 원본 다운로드와 직접 주소 및 API 접근을 차단합니다.

## 이어서 검토

마지막으로 저장된 1단계 또는 2단계로 복귀합니다. 3단계에서 종료했으면 2단계로 복귀하고 재검사합니다. 서버에 적용된 값만 복원하며 미적용 입력은 복원하지 않습니다. 이 화면의 이어서 검토는 [2차 2단계](#rist-phase2-review-detail)로 연결됩니다.

## 원본 파일 다운로드

미완료 원본은 보관 기간 내 업로드 계정에게, 완료 원본은 해당 이력 조회 권한자에게 제공합니다. 현재 저장 위치에 따라 운영 서버 또는 NAS 원본을 업로드 당시 파일명과 확장자로 제공하며 엑셀 내보내기는 제공하지 않습니다. 다운로드는 사용자, 시각, 대상 파일을 감사 로그에 기록합니다. 안내 문구: 권한 없음 — 이 작업을 볼 수 있는 권한이 없습니다. / 만료된 작업 재개 — 보관 기간이 만료되어 이어서 검토할 수 없습니다. / NAS 연결 장애 — 원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요. / 파일 부재 — 원본 파일을 찾을 수 없습니다. / 다운로드 만료 — 보관 기간이 만료되어 원본을 다운로드할 수 없습니다. NAS 대기 시간은 10초를 기준으로 운영 환경에 맞춰 조정합니다.
