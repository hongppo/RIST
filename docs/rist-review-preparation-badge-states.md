## 페이지

데이터 검토: 1단계(배지 상태) · rist-review-preparation-badge-states

기존 초기 상태 바로 다음에 배치합니다. 기존 페이지는 보존합니다.

## 추출됨

해당 항목의 파일 전체 대상 값이 직접 추출된 상태입니다. 1단계에서는 비활성화하며 수정은 2단계에서 합니다.

## 미추출

해당 항목에서 직접 추출 또는 DB 매칭으로 확보한 값이 전혀 없는 상태입니다. 이 상태만 1단계 입력을 활성화합니다. 배지는 자동 처리 결과이며 사용자가 입력·변경한 상태를 표시하는 배지가 아닙니다.

## 매칭

DB 매칭만으로 전체 값이 확보됐거나 직접 추출값과 매칭값이 혼합되어 전체 값이 확보된 상태입니다. 전체가 직접 추출된 경우에는 추출됨을 사용합니다. 1단계에서는 비활성화하며 수정은 2단계에서 합니다.

## 일부 매칭

직접 추출 또는 DB 매칭으로 일부 대상 값만 확보됐고 나머지는 NULL인 상태입니다. 일부 직접 추출+NULL, 일부 DB 매칭+NULL, 추출·매칭 혼합+NULL을 모두 포함합니다. 화면에 보이는 첫 행의 값만으로 상태를 판정하지 않습니다.

1단계에서는 비활성화하며 NULL 보완도 2단계에서 합니다. 일부 값이 비어 있어도 2단계로 이동할 수 있습니다. 추출/매칭 완료·일부 추출/매칭이라는 별도 배지는 사용하지 않습니다.

이 페이지의 값은 배지 상태 비교를 위한 목업 예시이며 특정 파일의 실제 추출 결과를 변경한 것이 아닙니다.
