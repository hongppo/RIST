## 문서 개요

| 항목 | 내용 |
| --- | --- |
| 원본 파일 | RIST_목록_정리_양식_20260922_1차_rist.xlsx |
| 목록 범위 | 기준 데이터 목록 9개, 데이터 행 143개 (보류 단위 2건 별도) |
| 문서 상태 | 개발용 기준 데이터 표. 보류 단위는 확인사항에 별도 기재하며, 활성 DB 등록 확정판 아님 |
| 보존 기준 | 승인된 수정 외에는 원본 작성 행·빈 칸·문자를 보존. 좌표는 십진수 도로 통일하며 도분초 변환값만 소수점 이하 10자리로 반올림하고 기존 십진수 정밀도는 유지. 빈 양식 행·입력 안내 문구 제외. 중복처럼 보이는 행도 임의 병합하지 않음 |
| 채취법 시트 선택 | 채취법 시트는 작성 데이터가 없고 채취법_rist수정에는 10행이 작성되어 있어 수정 시트를 사용 |
| 컬럼 구성 | 개별 문서는 실제 데이터 행과 스키마 대응을 제공. 주 데이터 표는 실제 스키마 컬럼명 사용. 고시번호·시험방법 코드·설명은 해당 마스터 필드에 대응하며, 확인·보류 내용은 별도로 구분 |
| 등록 보류 | μg·mg는 데이터 목록에서 제외하고 단위 문서 확인사항에 보존. 등록 여부 확인 후 추가 |
