## 3단계(첫 오류 파일)

화면 ID: `rist-phase4-review-error-first`

## 기능 및 적용 범위

오류 파일 이동과 현재 파일 안의 오류 항목 이동을 구분합니다. 오류 팝업은 파일명, 행, 열과 사유를 표시합니다. 위치로 이동하면 팝업을 닫고 해당 셀을 입력 가능한 상태로 표시합니다. 일괄 입력은 기본 펼침, 오류 항목만 보기는 기본 선택입니다. 전체 행에 같은 열 오류가 있으면 해당 열 머리글도 강조하고 오류 항목은 좌우로 순환합니다.

공통 필수 항목은 분석 물질, 결과, 단위입니다. 채취 일자와 좌표는 선택 항목입니다. 두 날짜가 모두 있을 때 채취 일자와 분석 일자의 선후를 검사합니다.

단계를 전환한 뒤 파일을 이동해도 선택한 단계를 유지합니다. 현재 파일의 오류가 모두 해결되어도 다른 파일에 오류가 남아 있으면 다음 오류 파일로 이동할 수 있습니다.
