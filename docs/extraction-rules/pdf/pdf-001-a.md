## 파일 읽기 및 유형 판별

### 필수 구성과 열 관계

| 구성요소 | 판별 조건 |
| --- | --- |
| 파일 | 실제 PDF로 읽을 수 있음. 텍스트·단어 좌표·표 선과 셀 경계를 함께 확인 |
| 제목·기본정보 | `시험성적서` 또는 `TEST REPORT` 제목에 `시료명`, `채취일자`, `시험기간` 라벨이 연결됨. 성적서번호는 식별 보조값으로 보존 |
| 상세 시험표 | `시험결과` 아래 `판정요원`, `희석배수`, `판정원의 감지값`, `최대·최소 제외`, `시험방법`의 열 관계가 있음 |
| 최종 요약표 | 상세표 뒤 `Sample No.`, `Odor exhaust permission standard`, `Sensory detection threshold (Dilution ratio)`, `판정결과` 열과 시료별 결과 행이 연결됨 |
| 확정 | 보고서 전체 범위에서 필수 구성과 결과 열의 대응을 모두 확인. 구성요소가 여러 페이지에 걸쳐 있어도 소속이 확인되면 연결 |
| 기존 유형과 구분 | 최종 결과 열이 `Dilution multiple`이면 이 규칙의 대상이 아님. 다른 규칙의 헤더를 동의어로 자동 수용하지 않음 |
| 주석 구분 | `※ Sensory detection threshold`라는 독립 주석만으로 판별하지 않음. `(Dilution ratio)`를 포함하는 실제 열 제목과 그 아래 결과 셀의 관계가 필요 |
| 중복·불확실 | 서로 다른 최종 결과 헤더가 병존하여 적용 유형·결과 열이 유일하지 않으면 확인 필요. 먼저 찾은 값이나 등록 순서로 확정하지 않음 |

## 보고서 구분 및 추출 구간

| 단계·상황 | 규칙 |
| --- | --- |
| 시작 | 제목과 기본정보가 연결된 영역에서 보고서 후보 생성 |
| 식별값 | 채취일자, 시험기간의 시작·종료, 시료명 전체, 성적서번호 전체를 원문과 함께 보존. 비교용 공백만 정리하고 시료명 속 시각·번호는 유지 |
| 새 보고서 | 비교 가능한 채취일자·시험기간·시료명이 하나 이상 다르거나 성적서번호가 다르면 분리. 동일 성적서번호에 다른 기본정보가 있으면 충돌 정보도 보존 |
| 반복 정보·연속 페이지 | 식별값 충돌이 없고 미완결 표의 열 대응·인쇄 페이지 연속 등의 근거가 있을 때만 같은 보고서로 연결. 반복 제목만으로 새 보고서를 만들지 않음 |
| 번호 반복 | 파일 전체에서 성적서번호가 같다는 이유로 떨어진 보고서를 합치지 않음. 직전 영역과 시료·기본정보를 함께 비교 |
| 누락 | 누락된 식별값을 동일 또는 변경으로 간주하지 않음. 소속을 확정할 수 없는 결과는 임의 배정하지 않고 확인 필요 |
| 같은 값의 완결 양식 재등장 | 중복·재발행·별도 출현을 확인할 수 없으면 별도 후보로 보존. 자동 삭제·병합 금지 |
| 종료 | 다음 별도 보고서 시작 직전 또는 파일 끝. 페이지 수·인쇄 총 페이지 수로 보고서 수를 고정하지 않음 |
| 시료 연결 | 최종표 Sample No.와 기본정보 시료명을 연결. 비교용 공백 외 문자·시각 차이는 유지. 연결이 유일하지 않으면 확인 필요 |
| Blank 시료 | 정상 보고서의 시료명에 Blank가 있어도 보존. 이름만으로 공시료 제외 또는 다른 시료 보정 계산을 하지 않음 |
| 순서 | 보고서 출현 순서로 record_order, 최종표 안의 결과 행 순서로 result_order 부여 |

### 추출 예시 및 컬럼 매핑

| 항목 | 매핑 컬럼 | 샘플 원본 위치·값 | 실제 추출·매칭 예시 | 추출·매칭 규칙 |

| 시험방법 코드 | `analysis_method_test_code` | `ES 09301.d` | `ES 09301.d` | 실제 셀에서 유일하게 식별된 코드 |
| 고시번호 | `analysis_method_notice_number` | `제 2024 - 65호` | `제 2024 - 65호` | 고시명·고시일 제외, 번호 원문 보존 |
| 결과 원문·표시 | `result_raw`, `result_text` | 1페이지 최종표 결과 열 `67` | `67` | 연결된 시료와 결과 열 교차 셀만 추출 |
| 숫자 결과 | `result_value` | `67` | Decimal `67` | 전체 문자열이 유효 숫자일 때만 수치화. JSON 정밀 소수는 문자열로 전달 |
| 공백 구분 결과 | `result_raw`, `result_text`, `result_value` | TLC 대수리 14페이지 `2 080`, 19페이지 `3 000 000` | 원문·표시 `2 080`, `3 000 000` / 수치 `2080`, `3000000` | 같은 결과 셀 안의 명확한 세 자리 공백 구분만 숫자로 변환. 최초 원문은 공백 포함 보존 |

| 항목 | 값 처리 |
| --- | --- |
| 결과 제외 | 요원별 감지값·최대/최소·O/X·허용기준·판정·주석·서명·연락처를 최종 결과로 사용하지 않음. 감지값에서 결과 재계산 금지 |
| 원문·정밀도 | 최초 숫자 원문의 공백·자릿수·부호·기호를 그대로 보존. 임의 반올림 금지 |
| 공백 구분 숫자 | 최종 결과 셀 전체가 첫 1-3자리와 이후 공백으로 구분된 3자리 숫자 그룹이면 숫자로 변환. `2 080 → 2080`, `3 000 000 → 3000000`. 다른 셀의 숫자를 연결하지 않음 |
| 숫자 변환 예외 | 임의 공백 전체 제거 금지. 잘못된 자리수·문자 혼합 등 불명확한 값은 강제 수치화하지 않음. 원문 보존, 수치 NULL, 확인 필요 처리 |
| 0·빈값·비수치 | 실제 0은 정상 수치. 소속이 확정된 빈 결과 행도 유지하고 수치는 NULL. 부등호·n.d 등은 원문 유지·수치 NULL |
| 결과 행 | 같은 시료에 속하는 원본 결과 행은 각각 보존. 값이 같다는 이유로 중복 제거·합산·평균하지 않음 |
| 분석법 누락 | 확인된 코드·방법명만 보존. 없는 방법명·고시번호는 추정하지 않음. 지정악취용 물질별 시험방법 매칭표를 이 유형에 자동 적용하지 않음 |
| 목록 연결 | 실제 적용한 분석법과 동일한 목록 항목일 때만 ID 연결. 코드가 보인다는 이유로 다른 방법의 ID·명칭을 붙이지 않음 |
| 시험방법 원문 | 고시명·고시일·고시번호·물질·코드를 포함한 시험방법 셀 전체를 원본 스냅샷에 보존. 고시일을 채취/분석일자로 사용하지 않음 |

## 반환·저장·오류 처리

| 항목 | 규칙 |
| --- | --- |
| 파서 반환 | 보고서별 records[].basic + results[]와 issues. 파일·페이지·셀 좌표·원문 라벨·시료 대응·제외 영역을 source_snapshot에 보존 |
| 분석물질 매칭 | 공통 매칭 계층에서 PDF-001-a의 모든 결과에 복합악취 적용. 규칙 코드·버전·매칭 근거 보존. 물질 ID는 실제 목록 항목이 확인될 때만 연결하고 미확인 시 ID만 NULL. 가상의 원본 셀 위치를 만들지 않음 |
| 단위 매칭 | 공통 매칭 계층에서 `unit=OU` 적용. 단위 목록의 `option_group=UNIT`, `option_name=OU` 항목이 실제로 확인될 때만 `unit_option_id` 연결. 미확인 시 ID만 NULL, OU는 유지. 임의 ID·목록 항목 생성 금지. 규칙 코드·버전·목록 연결 근거 보존. 결과 숫자 환산·재계산 금지 |
| 공통 저장 | 파서 record_order를 source_record_order로 보존. 저장 계층에서 결과마다 독립 기본 기록/결과 1:1 쌍과 순서를 생성. 파서가 DB를 직접 수정하지 않음 |
| 출처 | 직접 읽은 값 EXTRACTED, 날짜 정밀도·기간·순서 SYSTEM, 분석물질·단위 유형 규칙 및 실제 목록 연결값 MATCHED를 구분 |
| 원본 보존 | 최초 추출 원문·값·출처를 수정값으로 덮어쓰지 않음. 실제 목록 연결 근거가 없는 ID는 NULL |
| 미지원·읽기 실패 | 필수 구성 불일치와 OCR/표 복원 필요를 구분. 불명확한 결과를 0 또는 정상 추출로 반환하지 않음 |
| 부분 범위 | 확정 보고서와 소속 불명 구간을 분리해 반환. 파일 일부만 해당하면 전체 파일 정상 완료로 표시하지 않음 |
