## 핵심 규칙 요약표

| 구분 | 핵심 적용 기준 |
| --- | --- |
| 유형 판별 | `시험성적서/TEST REPORT`·성적서번호·시료명·채취일자·시험기간과 `시험항목 / 단위 / 결과값 / 시험방법` 열을 연결. 결과값의 시료 하위 헤더와 물질 결과 행이 필요하며 `n.d`도 결과 행. 페이지 수·물질 수·좌표는 고정하지 않고 필수 구조 미확인 시 확정하지 않음 |
| 추출 시작·연속 | 기본 정보에 연결된 결과표에서 시작. 다음 페이지의 시료 하위 헤더·열 구조·연번 연속을 확인하고 반복 식별값이 있으면 대조. 충돌·소속 불명 시 임의 연결하지 않음 |
| 종료·제외 | 비고·확인·발행 등 마감 영역 뒤 연속 결과가 없고 파일 끝이거나 시험조건·장비표로 바뀌면 종료. 시험조건·첨부의 숫자는 제외. 인쇄 총 페이지 수나 특정 항목 연번으로 자르지 않음 |
| 공통 항목 | 기본 정보 시료명·채취일자·시험기간 시작일과 하단 기관명 추출. 종료일 - 시작일 + 1로 기간 계산. 날짜만 있으면 DATE와 일시 NULL, 시료명 속 시각은 전용하지 않음 |
| 물질·결과·단위 | 시험항목 물질명과 같은 행의 해당 시료 결과를 연결. 단위는 실제 병합 셀이 덮는 행에만 적용하며 괄호 속 표기까지 보존. 반복 헤더 제외, 물질명이 있는 빈 결과 행은 유지 |
| 값·정밀도 | 0·`n.d`·공란을 구분. `n.d`는 원문·표시값 유지 및 수치 NULL, 0으로 치환하지 않음. 소수 자릿수·원문을 보존하고 Decimal 사용 |
| 지역 매칭 | 시료명·지역 입력값 → [지역 매칭](<../../matching-rules/location.md>) → 지점·DB 좌표. 등록 단어의 유일한 대응만 사용하며 미매칭·복수 지점은 NULL. 기관 주소로 좌표를 추정하지 않음 |
| 분석법 매칭 | 시험항목 추출·입력값 → [분석법 매칭](<../../matching-rules/analysis-method.md>) → 시험방법 코드 + DB 분석법명. PDF 기재 여부·개정판 차이와 관계없이 정해진 매칭값 적용. 미대응·불명확은 NULL, 시험방법 원문·고시번호는 별도 보존 |
| 인터페이스 입력 | 추출·계산·매칭 후 남은 구분·매체·담당자·위치·BASE·채취법·분석법 등을 보완. 가이드 예시·파일명으로 자동 생성하지 않음 |
| 행 전개·출처 | 연결 보고서별 기본 기록 + 시험항목별 결과 N건. 다음 페이지에서도 결과 순서를 이어 저장 시 독립 1:1 쌍으로 전개. 직접 추출·계산·매칭을 구분하고 제외 구간·병합 셀 적용 범위·원문 위치 보존 |

## 파일 읽기 및 유형 판별

### 파일 읽기

| 항목 | 처리 기준 |
| --- | --- |
| 파일 형식 | 확장자 대소문자를 구분하지 않는 `.pdf`. PDF 파서로 문서 구조를 읽을 수 있어야 함 |
| 추출 방식 | pdfplumber 등의 페이지별 텍스트·단어 좌표·표 선·셀 경계를 사용. 전체 문자열의 줄 순서만으로 열을 연결하지 않음 |
| 페이지·좌표 | 파일 첫 페이지를 물리적 1페이지로 계산. 회전·페이지 크기를 반영한 `x0, top, x1, bottom` 보존. 인쇄 페이지 번호는 별도 기록 |
| 중복 후보 | 페이지 테두리처럼 결과 헤더·행이 없는 표 후보는 제외. 같은 셀 좌표를 중복 탐지한 경우만 한 번 처리 |
| 읽기 실패 | 텍스트가 없거나 깨져 필수 구조를 식별할 수 없으면 OCR·수동 확인 필요 반환. 빈 문자열을 정상 추출로 처리하지 않음 |
| 라벨 정규화 | 한글 라벨은 비교용으로 공백·줄바꿈 제거. 영문 라벨은 공백 정리·대소문자 무시. 값 원문에는 적용하지 않음 |

### 양식 구성에 따른 판별

| 구성요소 | 판별 조건 |
| --- | --- |
| 제목 | 보고서 시작 영역에 `시험성적서` 또는 `TEST REPORT` |
| 기본 정보 | `성적서번호`, `시료명`, `채취일자`, `시험기간` 라벨이 같은 보고서 영역에 있음 |
| 결과 제목 | `시험결과` 아래에 항목별 결과표가 있음 |
| 표 헤더 | `시험항목`, `단위`, `결과값`, `시험방법`을 열 구조로 식별. 시험항목은 연번·물질명 하위 열, 결과값은 시료명 하위 헤더로 구성 |
| 데이터 구조 | 물질명마다 해당 시료의 결과 셀이 존재. 단위·시험방법은 여러 물질 행에 걸친 병합 셀일 수 있음 |
| 유형 확정 | 제목·기본 정보와 위 결과표 구조가 연결되고, 하나 이상의 물질 결과 행을 식별할 수 있음. 결과가 `n.d`여도 데이터 행으로 인정 |
| PDF-001과 구분 | 판정요원별 감지값·희석배수 표와 `Dilution multiple` 요약표를 추출하는 구조가 아님. 기관명·제목만으로 PDF-001과 혼동하지 않음 |
| 고정하지 않는 값 | 파일명, 기관명, 성적서번호, 시료명, 고시·방법 코드, 물질명 목록·개수, 페이지 수, 열 좌표는 유형 확정 조건으로 고정하지 않음 |

## 보고서 구분 및 추출 구간

### 시작·연속·종료 판정

| 단계 | 판정 근거 | 처리 |
| --- | --- | --- |
| 시작 | 보고서 제목·기본 정보와 시험결과표 구조가 함께 확인됨 | 기본 정보와 보고서 식별값을 보존하고 결과표 읽기 시작 |
| 다음 결과 페이지 | 같은 열 구조, 결과값 하위 시료명, 앞 페이지와 이어지는 항목 연번·배치가 확인됨 | 기존 보고서의 결과표로 연결. 페이지가 바뀌어도 `result_order`를 초기화하지 않음 |
| 식별값 대조 | 반복되는 성적서번호·시료명·채취일자·시험기간이 있으면 앞 보고서와 대조 | 충돌 시 자동 연결 금지. 누락을 일치나 변경으로 간주하지 않음 |
| 연속 근거 | 다음 페이지에 기본 정보가 반복되지 않아도 결과값 하위 시료명 일치와 동일 표 구조·연번 연속으로 연결 가능 | 머리글·제목·전체 페이지 수만으로 연결하지 않음. 연번의 누락·중복·역행은 원문을 보존하고 검증 항목 기록 |
| 결과표 끝 | 결과표 뒤 `비고`, `확인`, 시험자·기술책임자, 발행일·발행기관 등 마감 영역으로 전환 | 마감 영역의 숫자·성명을 결과 행으로 만들지 않음. 서명 유무만으로 종료를 단정하지 않고 다음 영역 확인 |
| 종료 확정 | 마감 영역 뒤 연속 결과표가 없고 파일 끝이거나, 다음 영역이 `시험조건` 제목과 장비·조건표로 전환 | 직전 연속 결과표까지 추출. 이후 페이지의 시험조건·첨부 자료는 추출 대상에서 제외 |
| 종료 근거 부족 | 다음 영역이 결과표인지 첨부인지 식별되지 않거나 서로 충돌하는 보고서가 등장 | 확정된 행과 불명확 구간을 구분해 반환. 임의의 페이지 번호·행 개수로 자르지 않음 |

- 시험조건표의 `GC/MS`, `HPLC`, `GC/FPD`, `UV-vis`, `GC/NPD`, `GC/FID`, `Column`, `Temperature`, `Flow Rate` 등은 장비·조건 구조를 확인하는 보조 근거다. 키워드 하나가 결과표 안에 있다고 종료하지 않는다.
- 같은 성적서번호·시험성적서 제목이 반복되어도 시험조건 영역이면 결과 연속 페이지로 연결하지 않는다.
- 인쇄된 `페이지 (p) / (총 n)`은 첨부까지 포함할 수 있다. 총 n을 결과 페이지 수로 사용하지 않는다.
- 표가 페이지 하단에서 끝났거나 특정 연번에 도달했다는 이유만으로 종료하지 않는다. 결과 영역 뒤 제외 영역이 확인되면 이후 페이지에서 결과 수치를 다시 찾지 않는다.
- 별도 보고서의 시작처럼 보이는 영역을 앞 보고서에 합치지 않는다. 소속·경계가 불명확한 구간은 확인 대상으로 보존한다.

### 샘플 경계 대조

| 물리적 페이지 | 관찰된 구성 | 처리 |
| --- | --- | --- |
| 1 | 기본 정보, 시료 `TLC 10시30분`, 시험결과 연번 1-16 | 기본 기록 시작 및 결과 16건 |
| 2 | 같은 시료 하위 헤더·열 구조, 연번 17-22, 뒤이어 비고·확인·발행 영역 | 같은 기본 기록에 결과 6건 추가 |
| 3 | `＊ 시험조건`, GC/MS·HPLC·GC/FPD 장비·조건표 | 결과 보고서 종료 뒤 자료로 제외 |

## 공통 항목 추출

### 라벨 및 날짜 해석

| 항목 | 처리 기준 |
| --- | --- |
| 라벨과 값 | 같은 기본 정보 영역에서 라벨에 연결된 오른쪽 값을 읽음. 다음 라벨·다른 열로 넘지 않고 같은 값 영역의 줄바꿈만 결합 |
| 시료명 | 기본 정보의 시료명을 추출하고 결과값 하위 시료명과 대조. 앞뒤 공백 제거·연속 공백 정리 외 숫자·시각·기호는 유지 |
| 시료 일치 | 비교용 공백 정리 후 일치 여부 확인. 유사 문자열로 자동 보정하지 않음. 복수 결과 열·복수 시료로 대응이 유일하지 않으면 확인 필요 |
| 분석기관 | 보고서 하단 기관명 바닥글에서 추출. 의뢰기관의 기관명·주소, 발행기관장 직함과 구분 |
| 날짜 | 연·월·일이 명시된 점·슬래시·하이픈·한글 날짜 표기를 유효한 날짜로 해석. 의뢰일·발행일로 채취일·시험 시작일을 대체하지 않음 |
| 기간 | 시험기간의 시작·종료 날짜를 각각 해석. `(종료일 - 시작일).days + 1` 계산. 명시된 단일 날짜는 1일 |
| 기간 오류 | 종료일 누락·해석 실패·역전이면 기간 NULL과 검증 정보 보존. 유효한 시작일은 유지. 잘못된 시작일을 종료일로 추정하지 않음 |
| 시각 | 날짜 필드에 실제 시각이 있을 때만 일시 저장. 날짜만 있으면 DATE, 일시는 NULL. 시료명 안의 `10시30분`을 날짜 필드의 시각으로 사용하지 않음 |
| 원본 보조값 | 성적서번호·시험기간 전체·종료일·결과표 하위 시료명은 `source_snapshot`에 위치와 함께 보존. 성적서번호를 DB 기본키로 사용하지 않음 |

NULL은 DB의 실제 NULL이며, 문자열 `NULL`·입력 예시값으로 채우지 않는다. 가이드의 인터페이스 입력 예시는 파일 추출값에 포함하지 않는다. 분석법 NULL은 기존 검토 인터페이스에서 목록 선택·신규 등록으로 보완한다.

## 오류 처리

| 구분 | 조건 | 처리 |
| --- | --- | --- |
| 파일 오류 | 암호화·PDF 파싱 실패 | 추출 중단, 원본과 오류 보존 |
| 유형 불일치 | 필수 제목·기본 정보·시험항목별 결과 구조를 확인하지 못함 | PDF-002로 확정하지 않음 |

| 연속·경계 확인 | 시료·성적서번호 충돌, 연번 누락·중복, 종료 영역 불명 | 확인된 결과와 미확정 구간을 분리. 자동 연결·누락 행 생성 금지 |

| 분석법 확인 | 확정 매칭표에 대응 없음·복수 후보 등 대응 불명확 | 해당 분석법·확정 불가 세부 필드 NULL. 원문·적용 범위 보존, 결과 행 유지 |
| 결과 없음 | 확정할 수 있는 물질 결과 행 0건 | 정상 추출 완료로 반환하지 않음 |

문제가 있는 필드·영역에 오류 범위를 한정하고, 확정된 결과는 보존한다. 의도적으로 제외한 시험조건과 읽기 실패로 누락된 구간을 구별한다.
