## 핵심 규칙 요약표

| 구분 | 핵심 적용 기준 |
| --- | --- |
| 유형 판별 | 첫 논리 행은 시료 헤더, 다음 행부터 분석물질과 결과가 반복되는 행렬. 순번 열이 있으면 B열이 분석물질이고 C열부터 시료, 순번 열이 없으면 A열이 분석물질이고 B열부터 시료 |
| 추출 범위 | 유효한 시료 헤더가 있는 열과 분석물질명이 있는 행의 교차점. 시료 수와 분석물질 수는 가변 |
| 결과값 | CSV 셀 문자열을 원문으로 보존하고 Decimal로 해석. 임의 반올림과 이진 부동소수점 변환 금지. 실제 0 유지 |
| 미추출 및 매칭 | 날짜, 단위, 방법 등 파일에 없는 항목은 초기 NULL. 지역 및 분석법은 공통 매칭 규칙으로 보완 |
| 원본 및 순서 | 시료 열의 왼쪽부터 기본 기록을 생성하고 각 시료에서 분석물질 행의 위쪽부터 결과 생성. 원문, 논리 행 및 열 위치 보존 |

## 파일 읽기 및 유형 판별

| 항목 | 처리 기준 |
| --- | --- |
| 확장자 | 대소문자를 구분하지 않는 `.csv` |
| 인코딩 | UTF-8, BOM 유무 모두 허용. 디코딩 실패 시 읽기 오류. 깨진 문자로 대체하지 않음 |
| CSV 해석 | 쉼표 구분과 큰따옴표 인용, 이스케이프된 큰따옴표 및 인용 필드 안 줄바꿈을 처리하는 CSV 파서 사용 |
| 행 번호 | CSV 파서의 논리 행 기준으로 1부터 부여. 인용 필드 안 줄바꿈은 별도 행으로 세지 않음 |
| 열 번호 | CSV 필드 순서로 A열부터 부여. 문자열의 쉼표 개수로 열을 계산하지 않음 |
| 비교 문자열 | 구조 판별과 표시값에는 앞뒤 공백 제거값 사용. 최초 필드 문자열은 별도 보존 |
| 제외 정보 | 파일명, 폴더명, 특정 물질 조합, 고정 시료 수로 유형을 확정하지 않음 |

### 지원하는 두 가지 배치

| 구분 | 1행 구조 | 2행 이후 구조 | 결과 시작 열 |
| --- | --- | --- | --- |
| 순번 열 있음 | A1 `NO.`, B1 `시험항목`, C1 이후 시료명 | A열 양의 정수 순번, B열 분석물질명, C열 이후 결과 | C |
| 순번 열 없음 | A1 공란 또는 `시험항목`, B1 이후 시료명 | A열 분석물질명, B열 이후 결과 | B |

- 순번 열은 분석물질 또는 결과로 추출하지 않는다. 원본 정보에는 보존한다.
- 분석물질명은 비어 있지 않은 비수치 문자열이며, 시료 헤더가 1개 이상이고 분석물질 행이 1개 이상 있어야 한다. 결과는 수치, 공란 또는 비수치 표현을 포함할 수 있다.
- 위 두 배치 중 하나를 유일하게 확인할 수 있어야 한다. 여러 유형과 중복되거나 행과 열의 역할을 확정할 수 없으면 확인 대상으로 구분한다.
- 표의 임의 위치 이동, 전치, 여러 표의 자동 결합, 헤더 추측 또는 열의 자동 이동은 수행하지 않는다.
- 첫 행을 임의로 건너뛰어 새 헤더를 찾지 않는다. 데이터 구간의 완전히 빈 행은 제외하되 최초 논리 행 번호는 유지한다.

## 추출 구간 및 행 처리

| 대상 | 처리 규칙 |
| --- | --- |
| 시료 열 | 결과 시작 열부터 첫 행의 시료명을 읽고 각 열을 독립 시료로 처리 |
| 분석물질 행 | 2행부터 파일 끝까지 해당 배치의 분석물질 열을 읽고 시료 열의 같은 행 결과와 연결 |
| 유효 시료의 0 | 결과가 0이면 유효 수치로 유지. 한 시료 열의 모든 결과가 0이어도 제외하지 않음 |
| 빈 결과 | 시료명과 분석물질명이 있으면 결과 행 유지. 수치와 표시값 NULL, 검증 항목 기록 |
| 빈 헤더 | 헤더와 아래 필드가 모두 빈 열은 제외. 헤더는 없지만 데이터가 있는 열은 시료를 확정할 수 없어 구조 확인 대상으로 구분 |
| 빈 물질명 | 행 전체가 비어 있으면 제외. 결과나 순번이 있는데 물질명이 없으면 구조 확인 대상으로 구분 |
| 반복 이름 | 시료명 또는 물질명이 반복되어도 원본 열과 행별로 독립 유지. 합산하거나 중복 제거하지 않음 |
| 열 개수 불일치 | 짧은 행의 없는 필드는 NULL 원문으로 구분하고 누락 기록. 헤더 범위 밖에 데이터가 있으면 구조 확인 대상. 자동 열 이동 금지 |
| 순번 이상 | 순번 열 배치에서 순번이 없거나 정수로 해석되지 않으면 확인 대상. 결과 순서는 순번 값으로 재정렬하지 않음 |

### 숫자 및 비수치 해석

| 항목 | 처리 기준 |
| --- | --- |
| 숫자 형식 | 부호가 있는 정수, 소수, 지수 표기. 아래 정규식에 전체 문자열이 일치할 때만 수치로 변환 |
| 정밀도 | Decimal 사용. 이진 부동소수점 경유, 임의 반올림 및 절삭 금지. JSON의 정밀 수치는 문자열로 전달 |
| 원문 | 소수 자릿수와 지수 표기를 포함한 최초 셀 문자열 보존. CSV에는 엑셀 셀 표시 형식을 적용하지 않음 |
| 실제 0 | `0`, `0.0` 등은 수치 0으로 유지하고 원문 표기도 보존 |
| 비수치 | `ND`, `n.d.`, 부등호, 단위가 붙은 값, 쉼표를 포함한 수, NaN 및 무한대는 수치로 강제 변환하지 않음. 원문과 표시값 유지, 수치 NULL 및 확인 사유 기록 |
| 빈 셀과 없는 필드 | 존재하는 빈 셀의 원문은 빈 문자열, 없는 필드의 원문은 NULL. 두 경우 모두 표시값과 수치는 NULL |

```regex
[+-]?(?:[0-9]+(?:\.[0-9]*)?|\.[0-9]+)(?:[eE][+-]?[0-9]+)?
```

## 미추출 항목 및 목록 연결

| 구분 | 항목 | 초기 처리 | 보완 |
| --- | --- | --- | --- |
| 기본 정보 | 구분, 매체, 담당자, 분석 기관 | 표시값과 ID NULL | 목록 선택 또는 입력 |
| 날짜 및 기간 | 채취일자, 분석일자, 일시, 분석 기간 | 날짜, 일시, 기간 NULL. 날짜 정밀도 UNKNOWN | 목록 선택 또는 입력 |
| 위치 | 위치명, 위치 ID, 위도, 경도 | NULL | 지역 매칭 후 목록 선택 또는 입력 |
| 단위 | `unit`, `unit_option_id` | NULL | 목록 선택 또는 입력 |
| 방법 | BASE, 채취법, 분석법 및 관련 ID | NULL | 공통 매칭 후 목록 선택 또는 입력 |
| 분석법 세부 | 고시번호, 시험방법 코드 | NULL | 분석법 매칭 후 목록 선택 또는 입력 |

- [지역 매칭](<../../matching-rules/location.md>)에 따라 각 시료명을 DB 지점과 대조한다. 유일한 대응이 있는 경우 같은 DB 행의 지점과 좌표를 MATCHED로 보완한다. 대응 없음 또는 모호한 경우 NULL과 확인 사유를 유지한다.
- [분석법 매칭](<../../matching-rules/analysis-method.md>)에 따라 분석물질별로 DB 보완을 수행한다. 명확한 직접 추출 분석법 우선 원칙을 유지하며, 이 배치의 초기 분석법은 NULL이다. 대응이 없거나 모호하면 NULL과 확인 사유를 유지한다.
- [파일 유형별 분석법 매칭](<../../matching-rules/analysis-method-by-file-type.md>)과 [채취법 매칭](<../../matching-rules/sampling-method.md>)에서 CSV-003에 지정된 추가 기본값은 없다. EXCEL-001의 VOCs 및 PAHs 파일명 조건을 CSV-003에 적용하지 않는다.
- 물질명은 원문을 유지한 채 목록과 연결한다. `M,P-Xylene` 등을 임의 분할하거나 다른 물질과 동일시하지 않는다. 매칭 이름 보정이 허용되는 경우에도 최초 추출 원문을 덮어쓰지 않는다.
- 파일명이나 물질명으로 날짜, 단위, 매체, 기관을 추정하지 않는다. SQL NULL을 사용하며 문자열 `NULL`이나 예시값을 저장하지 않는다.

## 원본 위치 및 추출 상태

| 항목 | 기록 기준 |
| --- | --- |
| 기본 기록 위치 | 시료 헤더 셀과 해당 시료의 결과 열 범위 |
| 결과 위치 | 시료 헤더 셀, 해당 분석물질 셀, 결과 셀의 논리 행 및 열. 예: PAHs `C1; B2; C2`, VOCs `B1; A2; B2` |
| 원본 스냅샷 | 최초 필드 문자열, 원본 위치, 해석값 및 오류를 `source_snapshot`에 보존. 순번 열도 원본 정보로 유지 |
| CSV 원문 | 파일 원문과 인코딩, 인용 기호를 포함한 원본을 보존. 파싱한 필드 문자열과 CSV 구문을 구분 |
| 직접 추출 | 유의미한 파일 값은 `value_source=EXTRACTED`, `was_extracted=true` |
| 미추출 및 매칭 | 빈 셀과 없는 필드는 추출 완료로 표시하지 않음. DB 보완값은 MATCHED, `was_extracted=false` |
| 시스템 값 | 순서 등 계산값은 SYSTEM, `was_extracted=false` |
| 최초 상태 | `is_modified=false`. 문제는 대상 항목 및 원본 위치와 함께 `validation_issues`에 기록 |

## 오류 처리

| 조건 | 처리 |
| --- | --- |
| 인코딩 또는 CSV 구문 오류 | 추출 중단, 읽기 오류 반환 |
| 배치 불명확, 유형 중복, 시료 또는 분석물질 축 미확정 | 정상 유형으로 확정하지 않고 확인 대상 반환. 임의 복구 금지 |
| 유효 시료 또는 분석물질 없음 | 결과 없음 오류 |
| 개별 결과 누락 또는 비수치 | 축이 확정된 결과 행 유지. 수치 NULL, 원문 및 확인 사유 반환 |
| 날짜, 단위 또는 목록 연결 미확정 | NULL 및 공통 검증 기준 적용. 다른 정상 결과는 유지 |

| 파서 반환 | 시료 열마다 `records[].basic`과 해당 열의 `results[]`를 반환 |
| 원본 기록 순서 | 파서 `record_order`를 DB `source_record_order`로 매핑 |
| 저장 전개 | 시료 열 순서, 각 시료의 결과 행 순서로 펼쳐 결과마다 독립 `review_record`와 `review_result` 1:1 쌍 생성 |
| DB 순서 | 전체 결과의 `record_order`는 1부터 연속 부여. `result_order`는 시료 안의 파서 결과 순서를 유지 |
| ID 및 출처 | 최초 검토 행 생성 시 ID 발급. 최종 저장에도 ID, 최초 순서, 원문 및 원본 위치 유지 |
| 역할 | 파서는 원본 추출과 검증 정보 반환. DB 매칭과 최종 저장은 공통 처리 계층에서 수행 |

샘플 결과 수는 각 파일의 유효 시료 열 수와 분석물질 행 수의 곱이다.
