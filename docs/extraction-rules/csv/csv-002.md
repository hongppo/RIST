## 핵심 규칙 요약표

| 구분 | 적용 기준 |
| --- | --- |
| 입력 파일 | 실제 측정 CSV. XLSX 항목 설명자료의 색상·입력 예시는 자동 추출 근거로 사용하지 않음 |
| 표 구조 | `Measured Time`, C열부터 `Wind Speed` 직전의 물질명, `Latitude`, `Longitude` 헤더와 표 전체 구조 확인 |
| 행 선별 | 연월일·시·분이 같으면 원본 순서상 첫 행 전체만 유지. 나머지 행의 농도·좌표도 제외. 시간 재정렬 금지 |
| 날짜·시간 | 유지 행의 Measured Time을 채취일시와 분석일시에 동일하게 적용. 원문 초 보존, 없는 초 추정 금지 |
| 좌표 | 유지 행의 위도·경도를 쌍으로 연결. 첫 행 좌표 전체 복제·지역 DB 좌표 덮어쓰기 금지 |
| 결과 | 유지 행과 물질 열의 교차값을 전개. 원문 정밀도·0 보존, 빈값 NULL |
| 인터페이스 입력 | 구분·매체·시료명·담당자·분석기관·BASE·채취법·분석법·단위는 목록 선택 또는 입력 |

## 파일 읽기 및 유형 판별

| 항목 | 규칙 |
| --- | --- |
| 실제 입력 | `.csv` 측정 파일을 CSV 파서로 읽고 최초 셀 문자열과 원본 행 순서를 보존 |
| 설명자료 | XLSX 설명자료를 측정 CSV로 대체하지 않음. 색상은 판별 조건이 아님 |
| 헤더 관계 | Measured Time과 물질 열 구간, Wind Speed 경계, Latitude·Longitude를 함께 확인 |
| 물질 범위 | 헤더 C열부터 Wind Speed 직전까지. 실제 물질명 전체를 사용하며 끝 열 AP·40개를 고정하지 않음 |
| 제외 열 | Total Concentration은 물질별 결과에 포함하지 않음. Wind Speed부터의 기상 항목도 물질별 결과가 아님. Latitude·Longitude는 공통 좌표로 읽음 |
| 위치 | 위도·경도는 헤더로 찾으며 AW·AX로 고정하지 않음 |

## 측정행 선별 및 추출 구간

| 순서 | 규칙 |
| --- | --- |
| 1 | 원본 측정행 순서를 유지한 채 Measured Time의 연월일·시·분을 비교 |
| 2 | 해당 연월일시분이 처음 나타난 행 전체를 유지 |
| 3 | 같은 연월일시분이 다시 나타나면 그 행의 농도·좌표를 포함한 전체 추출을 제외 |
| 4 | 연월일·시·분 중 하나라도 다르면 다른 그룹으로 처리하고 그 그룹의 첫 행 유지 |
| 5 | 유지한 행의 시간·위도·경도를 같은 행의 모든 물질 결과에 연결 |

시간순 재정렬 후 첫 행을 선택하지 않는다. 초는 그룹 비교에서만 제외하며, 유지 행의 추출 시간에서는 삭제하거나 00으로 바꾸지 않는다.

## 공통 항목 추출

### 추출 예시 및 컬럼 매핑

| 항목 | 매핑 컬럼 | 샘플 원본 위치·값 | 실제 추출 예시 | 추출 규칙 |
| --- | --- | --- | --- | --- |
| 채취일시 | `collected_date`, `collected_at` | A2 Measured Time `2025-12-02 13:26:33` | `2025/12/02 13:26:33` | 해당 분의 원본 순서 첫 행. 원문과 시간 정밀도 보존 |
| 분석일시 | `analyzed_date`, `analyzed_at` | 같은 행 Measured Time | `2025/12/02 13:26:33` | 채취일시와 동일하게 적용. 실행시간·파일 수정시간 사용 금지 |
| 위도 | `latitude` | AW2 Latitude `34.942309` | `34.942309` | 유지 행 좌표. 공통 저장 정밀도 적용 시에도 최초 원문 별도 보존 |
| 경도 | `longitude` | AX2 Longitude `127.724085` | `127.724085` | 같은 행 위도와 쌍으로 연결. 시료명 지역 DB 좌표로 덮어쓰지 않음 |

샘플 3행의 `2025-12-02 13:26:49`는 2행과 같은 분이므로 제외한다. 3행의 위도 `34.942287`, 경도 `127.724078`도 추출에 사용하지 않는다.

## 물질별 결과 추출

### 추출 예시 및 컬럼 매핑

| 항목 | 매핑 컬럼 | 샘플 원본 위치·값 | 실제 추출 예시 | 추출 규칙 |
| --- | --- | --- | --- | --- |
| 분석물질 | `substance_name` | C1 `methanol` | `methanol` | C열부터 Wind Speed 직전의 물질명 전체 보존 |
| 결과 원문·표시 | `result_raw`, `result_text` | C2 `6.60` | `6.60` | 유지한 행의 해당 물질 교차값. 원문 정밀도 보존 |
| 숫자 결과 | `result_value` | C2 `6.60` | 정밀 소수 `6.60` | 임의 반올림 없이 원문 정밀도 유지. 실제 0 보존, 빈값 NULL |

| 항목 | 규칙 |
| --- | --- |
| 물질명 | 혼합명·`[R]`·슬래시·플러스 기호를 임의 분리하지 않음 |
| 결과 전개 | 유지 측정행마다 물질 열 전체의 교차값을 결과로 전개 |
| 연결 | 각 결과는 자신이 속한 유지 행의 시간·위도·경도와 연결 |
| 제외 행 | 제외한 행에서 농도나 좌표를 가져와 유지 행을 보완하지 않음 |

담당자를 파일명의 인명으로 자동 입력하지 않는다. 분석법의 코드·고시번호는 실제 선택한 목록 항목에 연결하고 예시를 자동 적용하지 않는다. BASE 미입력은 NULL이다. 인터페이스 입력 예시를 파일 추출값으로 저장하지 않는다.
