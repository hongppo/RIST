## 핵심 규칙 요약표

| 구분 | 핵심 적용 기준 |
| --- | --- |
| 유형 판별 | **1행 C열부터 시료명, B열 2행부터 분석물질, C2부터 교차 결과**라는 고정 구조 자체로 판별. 특정 물질 조합·표식은 요구하지 않음. 시료·물질 수와 마지막 행·열은 가변. 이동·전치 구조나 유형 중복·범위 미확정은 임의 확정하지 않고 미지원 안내·종료 |
| 추출 범위 | 고정 시작 위치에서 같은 시료 헤더 행·물질명 열에 대응하는 결과 범위를 확인. 축 끊김 뒤 내용이나 주석·별도 표를 임의 연결하지 않음. A열·B1의 공란은 필수조건이 아니며 서식 끝·첫 빈 결과만으로 종료하지 않음 |
| 빈 양식 열 제외 | 위치와 관계없이 **시료명 헤더가 숫자 0이고 모든 물질 행 결과도 숫자 0인 열**만 제외. 정상 시료명의 결과는 전부 0이어도 보존. CY·제외 열 개수는 샘플 예시 |
| 항목별 추출 | 1행 시료명과 B열 물질명을 전체 보존하고 교차 셀을 해당 시료·물질 결과에 연결. `M,P-Xylene`을 분리하거나 `O-Xylene`과 병합하지 않음. 날짜·단위는 파일에 없으므로 추정하지 않음 |
| 값·정밀도 | XLSX 내부 숫자 `<v>` 문자열을 원문으로 보존하고 Decimal로 해석. Excel 화면 표시나 이진 부동소수점 값으로 대체하지 않음. 실제 0 보존, 비수치는 원문 유지·수치 NULL, 빈 결과는 NULL. 임의 반올림 금지 |
| 지역 매칭 | 시료명·지역 입력값 → [지역 매칭](<../../matching-rules/location.md>) → 같은 DB 행의 지점·좌표. 각 시료의 결과에만 적용하고 없음·복수 지점은 NULL. 첫 시료 좌표를 전체에 복제하지 않음 |
| 분석법 매칭 | 명확한 직접 추출 분석법이 없는 이 유형에서는 DB 매칭으로 보완. 물질 추출·입력값 → [분석법 매칭](<../../matching-rules/analysis-method.md>) → 코드·DB 분석법명. 없음·불명확은 NULL. VOCs 전체에 한 분석법을 일괄 적용하거나 두 Xylene 표기를 임의 통합하지 않음 |
| 인터페이스 입력 | 구분·매체·담당자·기관·채취일자·분석일자·BASE·채취법·단위와 매칭 후 비는 위치·분석법을 보완. 날짜가 없는데 기간 1일을 만들지 않으며 가이드 입력 예시는 자동값이 아님 |
| 행 전개·출처 | 시료 열마다 기본 기록, 위→아래 물질 행마다 결과 생성. 시료 열 순서→물질 행 순서로 독립 1:1 저장 쌍 전개. 셀 주소·유형·숫자 원문·표시 형식과 매칭 근거 보존 |

### 식별 절차 및 확정 조건

| 순서 | 확인 내용 | 판정 |
| --- | --- | --- |
| 1. 파일 읽기 | XLSX의 시트·셀 주소·셀 유형·공유 문자열·숫자 원문·표시 형식을 함께 읽음. 원본 파일은 수정하지 않음 | 읽기 실패는 정상 추출 완료로 처리하지 않음 |
| 2. 고정 위치 확인 | 1행 C열부터의 비어 있지 않은 문자열을 시료명, B열 2행부터의 비어 있지 않은 문자열을 분석물질명으로 읽음. 숫자 0 헤더는 빈 양식 열 판정으로 분리 | 표의 시작 위치가 이동하거나 행·열이 뒤바뀌면 이 규칙으로 보정·확정하지 않음 |
| 3. 축·결과 대응 검증 | 같은 시료 헤더 행·물질명 열에 연결된 범위인지 확인. 각 결과 셀이 하나의 시료와 하나의 물질에 대응해야 함 | 이름 없는 값·다른 표의 혼입·축 끊김으로 범위가 불명확하면 자동 확정하지 않음 |
| 4. 결과 구조 검증 | 결과 영역은 C2부터 시작하며, 시료 헤더와 물질 축의 교차 셀에 숫자·비수치 결과 또는 빈 셀이 배치되어야 함. 분석물질과 시료를 각각 확보해야 함 | 숫자·비수치·빈 셀은 아래 결과 해석 규칙을 적용. 시료 축이나 물질 축이 없으면 판별 실패 |
| 5. 유형 확정 | 위 고정 위치·행열 관계·결과 범위를 충족하면 EXCEL-001로 판별. 같은 구조이면 물질명 조합·지역명·별도 표식과 관계없이 적용 | 구조 불일치·범위 미확정 또는 등록된 다른 규칙과의 중복으로 한 유형을 확정할 수 없으면 미지원 유형으로 안내하고 종료. 사용자 유형 선택으로 우회하지 않음 |

### 구조 판별의 적용 범위

| 항목 | 처리 기준 |
| --- | --- |
| 구조 기준 | 고정된 시료 행·물질 열·교차 결과 구조 자체를 판별 기준으로 사용. VOCs 여부나 특정 물질군을 별도로 판정하지 않음 |
| 이름·개수 조건 | 특정 물질명·물질 조합·지역명·파일명·시트명·숫자 비율을 필수조건으로 사용하지 않음. 시료 100개·물질 18개로 고정하지 않음 |
| XRF 샘플 대조 | 1행 C열 이후에 시료명이 없고, `Sample name`의 단일 시료 정보와 `Component`, `Result`, `Unit` 등 역할별 열로 구성되어 고정 구조를 충족하지 않음. 역할별 열을 시료명으로 바꾸어 적용하지 않음 |
| 이동·전치 | 시료명은 1행, 물질명은 B열, 결과 시작은 C2로 고정. 임의 위치 이동·행열 전치 복원을 지원 조건으로 포함하지 않음 |
| 복수 시트·표·병합 | 샘플은 병합 없는 단일 시트·단일 행렬. 복수 시트·별도 표의 자동 연결, 병합 헤더의 시료별 복제는 별도 기준 없이 적용하지 않음 |

## 추출 구간 및 빈 양식 열 구분

| 구분 | 판정 및 처리 |
| --- | --- |
| 시작 | 1행 C열부터 시료 헤더를, B열 2행부터 물질 축을 확인하고 C2부터 교차 결과 범위를 구성 |
| 오른쪽 범위 | 1행 시료명 셀과 그 아래 동일한 물질 행 집합의 결과를 함께 확인. 시료명 없이 값만 있는 열은 인접 시료에 연결하지 않음 |
| 아래쪽 범위 | B열 물질명 셀과 오른쪽 동일한 시료 열 집합의 결과를 함께 확인. 물질명 없이 값만 있는 행은 직전 물질에 연결하지 않음 |
| 빈 양식 열 | 시료명 헤더가 숫자 `0`이고 물질 행의 결과도 모두 숫자 `0`인 열은 제외. 제외 열의 개수와 시작 위치는 고정하지 않음 |
| 실제 0 | 유효한 시료명 아래의 `0`은 정상 결과. 해당 열의 결과가 모두 0이어도 포함 |
| 결과의 공란 | 유효한 두 축 사이의 빈 결과 셀은 NULL. 첫 빈 결과를 행·열의 끝으로 판단하거나 다음 값을 당기지 않음 |
| 축의 공란·끊김 | 시료명 또는 물질명 축이 끊긴 뒤 별도 내용이 있으면 같은 표로 건너뛰어 연결하지 않음. 이어지는 내용의 역할·경계를 확인할 수 없으면 범위 미확정으로 반환 |
| 주석·별도 표 | 새 역할별 헤더·별도 제목·메모 등 기존 시료/물질/결과 대응에 속하지 않는 영역은 결과에서 제외. 주석과 물질명의 구분 근거가 없으면 임의 제외·포함하지 않고 범위 미확정 처리 |
| 종료 확인 | 마지막 유효 시료 열·물질 행 뒤에 같은 축에 연결될 데이터가 없는지 확인. 서식이 있는 마지막 셀이나 첫 빈 셀만으로 종료하지 않음 |
| 경계 미확정 | 주석·별도 표·이름 없는 값과 결과 범위를 구분하지 못하면 일부 범위를 임의 확정해 정상 추출로 반환하지 않음 |
| 반복 시료 | 같은 이름의 별도 열은 위치·출현 순서를 보존. 임의 병합·평균·중복 제거하지 않음 |

### 지역·관측 지점 및 좌표 매칭

시료명이나 지역에 [지역 매칭](<../../matching-rules/location.md>)의 매칭 단어가 포함되면 해당 관측 지점에 연결하고 [지역 DB](<../../db-lists/location.md>)의 위도·경도를 사용한다. 매칭 단어가 시료명 앞부분에 있어야 한다는 조건은 두지 않는다.

| 시료명·지역에 포함된 단어 | 관측 지점명 |
| --- | --- |
| 청림 | 포항 청림 |
| 해도 | 포항 해도 |
| 묘도, 온동 | 여수 묘도(온동) |
| 태인 | 광양 태인 |

- 관측 지점 DB 전체의 정식 지점명 또는 도시명 뒤 지역 부분을 대조한다. 위 표는 샘플의 연결 예시이며 허용 목록이 아니다. 하동·태인·중마동 등 다른 DB 지점의 지역 부분도 같은 기준으로 적용하고 세부 조건은 지역 매칭 문서를 따른다. 도시명만·임의 문자 조각·유사어로는 매칭하지 않는다.
- 같은 지점에 해당하는 후보는 하나로 처리. 서로 다른 지점이 겹치거나 대응이 없으면 위치값은 NULL로 두고 확인 처리한다.
- 지점명·위도·경도는 같은 DB 행에서 가져와 MATCHED로 기록한다. 첫 시료의 좌표를 모든 시료에 적용하지 않는다.
- `location_id`는 실제 목록 연결이 확인될 때만 설정. DB 원본 좌표는 보존하고 저장값은 `DECIMAL(13,10)` 기준으로 한 번만 반올림한다.

| 항목 | 매핑 컬럼 | 샘플 원본·DB 값 | 실제 매칭 예시 |
| --- | --- | --- | --- |
| 관측 지점 | `location_name` | 시료명 `청림 1-1` | `포항 청림` |
| 위도·경도 | `latitude`, `longitude` | DB `35.9973660373914`, `129.405711966399` | `35.9973660374`, `129.4057119664` |

| 결과 셀 | 유효 시료 열과 물질 행이 교차하는 셀 하나를 결과 1건으로 생성 |

| 단위 | 샘플에는 단위가 없으므로 NULL. 물질명·파일명·숫자 크기에서 단위를 추정하지 않음 |

| 숫자 결과 | `result_value` | 같은 셀의 저장 숫자 | 정밀 소수 `0.54499999999999993` | Decimal 변환. 임의 반올림 금지 |
| 실제 0 | `result_raw`, `result_text`, `result_value` | Sheet1 · N3 `0` | 원문·표시 `0`, 수치 `0` | 유효 시료 열의 실제 결과 |

### 원문 정밀도 및 셀 유형

| 구분 | 처리 기준 |
| --- | --- |
| 저장 숫자 | XLSX worksheet XML의 숫자 `<v>` 문자열을 원문으로 확보하고 Decimal로 해석. 셀 표시 형식·화면의 반올림값·이진 부동소수점 변환값으로 원문을 대체하지 않음 |
| 정밀도 전달 | JSON 등에서 정밀 소수를 문자열로 전달. 저장 컬럼이 원문 정밀도를 수용하지 못하면 원문을 보존하고 검증 오류로 반환하며 자동 절삭·반올림하지 않음 |
| 문자형 숫자 | 부호·소수·지수 표기를 포함한 전체 문자열이 유효한 숫자인지 검증 후 Decimal 변환. 원래 셀 유형·문자열은 보존 |
| 비수치 | `ND`, `n.d`, 부등호 등을 원문·표시값에 보존하고 `result_value`는 NULL. 0이나 검출한계로 대체하지 않음 |
| 빈 셀 | 식별한 빈 셀의 원문은 빈 문자열, 업무값은 NULL. 위치 자체를 식별하지 못하면 원문도 NULL과 확인 정보 기록 |
| 오류·수식 | 오류값은 원문 보존 후 수치 NULL. 수식은 수식과 캐시 결과를 구분해 보존하고 유효한 캐시만 해석. 캐시가 없거나 오류이면 확인 처리하며 외부 연결·매크로 실행으로 보완하지 않음 |

### 분석법 DB 매칭

명확하게 추출한 분석법을 우선 적용하고, 없을 때 분석물질의 DB 매칭값으로 보완한다. 명확한 추출값은 DB 값이 다르거나 매칭되지 않아도 덮어쓰거나 NULL로 바꾸지 않는다. 불명확한 원문은 스냅샷과 확인 사유를 보존하되 확정 추출값으로 사용하지 않는다. DB 보완도 대응이 없거나 불명확하면 미확정 업무값은 NULL로 유지한다. 분석법 표시값·시험방법 코드는 같은 방법에 대응해야 하며, 분석법 ID는 실제 적용한 방법과 일치하는 DB 항목에만 연결한다. 다른 방법의 ID를 붙이지 않는다. 직접 추출은 EXTRACTED, DB 보완은 MATCHED로 구분하고 원문·위치·매칭 근거를 보존한다.

분석물질이 [분석법 매칭](<../../matching-rules/analysis-method.md>)의 항목에 대응하면 파일 유형과 관계없이 해당 [분석법 DB](<../../db-lists/analysis-method.md>)를 연결한다. 매칭값은 파일 직접 추출값과 구분한다.

| 분석물질 | 시험방법 코드 | 분석법 표시값 |
| --- | --- | --- |
| Toluene | `ES 09307.b` | `ES 09307.b 휘발성유기화합물 - 저온 농축 - 기체크로마토그래피` |
| Styrene | `ES 09306.1b` | `ES 09306.1b 스타이렌 - 저온 농축 - 기체크로마토그래피` |

- 매칭표에 없는 물질은 분석법 NULL로 유지하고 검토 화면에서 보완한다. VOCs 파일이라는 이유만으로 전체 물질에 `ES 01804.2a`를 일괄 적용하지 않는다.
- `M,P-Xylene`, `O-Xylene`을 `Xylene`과 연결하는 별도 대응이 없으면 임의로 동일시하지 않는다. 명백한 오타도 대응이 유일할 때만 연결한다.
- 표시값은 제공된 고시번호·시험방법 코드·분석법명을 연결한다. 비어 있는 고시번호를 ES 코드로 채우지 않으며 분석법 ID는 실제 목록 연결이 확인될 때만 설정한다.
- 같은 시험방법 코드의 DB 행이 중복되면 분석물질 대응과 실제 항목을 확인한다. 코드만 보고 임의의 행 ID를 선택하지 않는다.

## 원본 보존·오류 처리

| 항목 | 처리 기준 |
| --- | --- |
| 원본 위치 | 시트명·블록 식별·시료 헤더 주소·물질 헤더 주소·결과 셀 주소를 보존 |
| 원본 스냅샷 | 셀 유형·원문 문자열·숫자 저장 문자열·표시 형식·수식/캐시 구분과 매칭 근거를 보존 |
| 직접 추출 | 시료명·분석물질·결과는 `was_extracted=true`, `value_source=EXTRACTED` |
| 매칭·계산 | DB에서 보완한 지역·좌표·분석법은 MATCHED, 순서는 SYSTEM. 미추출 필드를 매칭해도 `was_extracted=false` 유지 |
| 최초 상태 | 최초 `is_modified=false`. 정상 값은 `validation_issues=[]`, 오류 범위는 원문과 확인 사유를 함께 반환 |
| 파일·구조 오류 | 암호화·손상·필수 축 식별 실패는 정상 완료로 처리하지 않음. 오류 영역 때문에 확인된 다른 결과를 삭제하지 않음 |

## 공통 처리 연결

| 대상 | 처리 기준 |
| --- | --- |
| 파서 반환 | 시료별 `records[].basic` + `records[].results[]` 1:N. 샘플은 기본 기록 100건, 각 결과 18건 |
| 매칭 계층 | 지역·분석법·목록 연결은 공통 계층에서 수행. 파서는 원문·위치·관계를 반환하며 DB 조회·ID 발급을 수행하지 않음 |
| 저장 변환 | 결과마다 basic을 복사한 독립 `review_record`·`review_result` 1:1 쌍 생성. 샘플은 1,800쌍 |
| 순서 | 파서 순서를 `source_record_order`에 보존하고 시료 열 순서→물질 행 순서로 펼쳐 DB `record_order` 부여 |
| 최종 저장 | 검토·검증 후 `analysis_record`·`analysis_result` 반영. 원문 정밀도와 원본 스냅샷 유지 |
