| 값·정밀도 | XLSX 숫자 원문을 Decimal로 해석. 실제 0은 보존, 빈 결과는 NULL, 비수치는 원문 유지·수치 NULL. 임의 반올림·백분율 변환 금지 |

## 파일 읽기 및 유형 판별

### 양식 구성과 고정 위치

| 구성요소 | 위치·역할 | 처리 기준 |
| --- | --- | --- |
| 파일 식별 문자열 | A1 `File name`, B1 값 | 담당자 분리의 원문. 실제 파일명이나 시트명으로 대체하지 않음 |
| 시료명 | A2 `Sample name`, B2 값 | 해당 시트의 물질 결과에 공통 적용 |
| 분석일시 | A3 `Date analyzed`, B3 값 | 해당 시트의 실제 날짜·시간 추출 |
| 물질 표 헤더 | A10 `Component`, B10 `Result`, C10 `Unit` | 각 열의 역할을 확인하고 헤더 자체는 결과에서 제외 |
| 물질 데이터 | A11부터 아래로 | 같은 행 A·B·C열 연결. 마지막 행은 실제 내용으로 확인 |
| 보조 정보·열 | Sample type, Component type, D열 이후 항목 | 시료명·분석법·결과·단위로 임의 대체하지 않음 |

### 식별 및 시트 순회

| 순서 | 처리 기준 |
| --- | --- |
| 1. 파일 읽기 | XLSX의 시트 목록·순서·셀 유형·공유 문자열·숫자 원문·표시 형식·날짜 체계를 읽음. 원본은 수정하지 않음 |
| 2. 모든 시트 확인 | 첫 시트만 처리하거나 시트명을 숫자로 제한하지 않음. 숨김 여부와 관계없이 모든 워크시트를 확인하고 시트별 처리 상태를 남김 |
| 3. 양식 확인 | 위 라벨과 고정 셀 배치를 함께 검증. 비교 시 앞뒤 공백·줄바꿈은 정리하되 원문 보존. 임의 이동·전치나 다른 열의 자동 대체는 적용하지 않음 |
| 4. 기본 정보·결과 연결 | 양식이 확인된 시트마다 기본 기록을 만들고 그 시트의 결과만 연결. 같은 시료명이 다른 시트에 있어도 합치지 않음 |
| 5. 오류 구분 | 구조 불일치·표지·빈 시트는 처리 상태와 확인 사유를 기록하고 조용히 누락하지 않음. 미지원 구조를 정상 추출로 확정하지 않으며 확인된 다른 시트의 결과는 보존 |

- 시트 수·시트명·물질명 조합·단위·마지막 행은 샘플과 같아야 하는 조건이 아니다.
- EXCEL-001의 가로 시료 행렬과 구분한다. 이 유형은 시트별 단일 시료와 Component·Result·Unit 역할별 열을 사용한다.
- 샘플은 병합 없는 양식이다. 병합 범위가 필수 셀·물질 행의 대응을 흐리면 임의 값 복제 없이 확인한다.

## 추출 구간 및 행 처리

| 구분 | 처리 기준 |
| --- | --- |
| 시작 | A10:C10 헤더 확인 후 11행부터 물질 데이터 후보 확인 |
| 물질 데이터 | A열 물질명과 같은 행 B열 결과·C열 단위를 연결. 물질명이 식별되면 결과·단위가 비어 있어도 해당 물질을 유지하고 빈 업무값은 NULL |
| 빈 행 | 실제 내용이 없는 행은 결과를 생성하지 않음. 첫 빈 행에서 종료하지 않고 뒤쪽 데이터 존재 여부와 같은 표의 연속성을 확인 |
| 이름 없는 값 | 물질명 없이 결과·단위만 있는 행은 직전·다음 물질에 붙이지 않음. 원문과 확인 사유 보존 |
| 합계·주석·별도 표 | 물질 데이터 여부가 불명확하면 임의 추출·제외하지 않고 확인. 단순히 A열에 문자열이 있다는 이유로 물질로 확정하지 않음 |
| 종료 | 마지막 물질 행 뒤의 실제 셀 내용까지 확인. 서식이 있는 마지막 행·샘플 끝 위치를 결과 범위로 사용하지 않음 |
| 보조 결과 | B열이 비어 있거나 오류여도 D열 Det. limit, F열 Intensity, G열 w/o normal 등으로 채우지 않음 |
| 반복 물질 | 같은 물질명이 반복되어도 원래 행·순서를 유지. 임의 합산·평균·중복 제거하지 않음 |

## 물질별 결과 추출

### 물질·결과·단위 해석

| 항목 | 처리 기준 |
| --- | --- |
| 분석물질 | A열의 전체 물질명 보존. `Na2O`, `Fe2O3` 등 화학식을 원소명으로 분리·변환하지 않음 |
| 결과 원문 | 같은 행 B열 셀의 저장 숫자 문자열 또는 문자 원문을 보존. XLSX XML 숫자 `<v>`를 Decimal로 해석하고 화면 반올림값으로 대체하지 않음 |
| 정밀도 | 임의 반올림·절삭 금지. 정밀 소수는 전송 시 문자열로 보존. 저장 정밀도를 초과하면 원문을 남기고 검증 오류 반환 |
| 실제 0·빈 값 | 0은 실제 결과로 유지. 물질이 있는 행의 빈 B열은 NULL. 빈 값이나 비수치를 0으로 바꾸지 않음 |
| 비수치·오류 | ND·부등호·오류 등은 원문과 표시값을 보존하고 수치값은 NULL. 다른 열의 값으로 대체하지 않음 |
| 단위 | 같은 행 C열 원문을 추출. `wt%`는 샘플 값이며 고정하지 않음. 단위가 비어 있으면 NULL, 앞 행의 단위를 복제하지 않음 |
| 수치·단위 관계 | `3.1186 wt%`는 결과 `3.1186`과 단위 `wt%`로 분리. 결과를 100으로 나누거나 단위 환산·정규화하지 않음 |
| 수식 | 수식과 캐시값을 구분해 보존. 유효한 캐시만 해석하고 캐시 부재·오류는 확인. 외부 연결·매크로 실행으로 보완하지 않음 |

| 다른 결과 열 | 결과 매핑 제외 | 시트 `1` G11 `3.1059` | 추출 결과로 사용하지 않음 | G열 w/o normal은 B열 Result 대체값이 아님 |

### 분석법 DB 매칭

명확하게 추출한 분석법을 우선 적용한다. 없으면 분석물질을 [분석법 매칭](<../../matching-rules/analysis-method.md>)과 대조하여 [분석법 DB](<../../db-lists/analysis-method.md>)의 해당 방법으로 보완한다.

| 구분 | 처리 기준 |
| --- | --- |
| 명확한 파일값 | 시험방법 코드·방법명 및 해당 결과에 대한 적용 범위가 명확해야 함. 원문·위치를 보존하고 DB 값이 다르거나 매칭되지 않아도 덮어쓰거나 NULL로 바꾸지 않음 |
| 원문 불명확 | 원문·확인 사유는 보존하되 확정 추출 분석법으로 사용하지 않음. 미추출 필드는 공통 DB 매칭으로 보완하고 미대응·불명확이면 NULL |
| 샘플 | 명확한 분석법 기재가 없음. 파일명의 XRF, Sample type의 Metal & Alloy, Component type의 Oxide를 분석법으로 입력하지 않음 |
| 물질 대응 | 물질명 그대로 공통 매칭 조건 적용. 산화물·원소를 임의로 같은 물질로 연결하거나 전체 물질에 동일 분석법을 부여하지 않음 |
| 표시값·ID | 표시값·시험방법 코드는 실제 적용한 같은 방법에 대응해야 함. ID는 해당 방법의 DB 항목이 확인될 때만 연결하며 다른 방법의 ID를 붙이지 않음 |
| 출처·예외 | 직접 추출은 EXTRACTED, DB 보완은 MATCHED로 구분. PDF-002의 별도 DB 우선 규칙은 이 유형에 확대하지 않음 |

## 미추출 항목 및 사용자 보완

| 항목 | 처리 기준 |
| --- | --- |
| 구분·매체·분석기관 | 초기 NULL. 인터페이스에서 입력·선택한 값 적용. 파일명·장비명·가이드 예시로 추정하지 않음 |
| 채취일자 | 초기 NULL·UNKNOWN. 입력한 유효 날짜 적용, 미입력은 NULL. B1·B3 날짜로 대체하지 않음 |
| 위치·위도·경도 | 파일 직접 추출값 없음. 지도 선택 또는 기존 지점 목록에서 선택한 동일 지점의 좌표를 함께 적용. 공통 지역 매칭이 적용되는 경우에도 등록된 근거가 있을 때만 MATCHED로 구분 |
| BASE·채취법 | 미입력 NULL. 목록 정리 전 임의 값을 생성하지 않으며 `??`, `LIST UP 예정` 등의 기획 표기를 저장하지 않음 |
| 분석법 | 파일값·공통 DB 매칭으로 확정되지 않은 경우 NULL. 검토 인터페이스에서 보완 |
| 목록 ID | 담당자·물질·분석법·단위 등 실제 목록 연결이 확인된 경우에만 설정. 미매칭이어도 명확한 추출 표시값 유지 |

## 원본 보존·오류 처리

| 항목 | 처리 기준 |
| --- | --- |
| 원본 위치 | 워크북·시트명·시트 순서·B1:B3·물질/결과/단위 셀 주소·결과 행 번호 보존 |
| 원본 스냅샷 | 셀 유형·문자열·숫자 저장 문자열·날짜 체계·표시 형식·수식/캐시 및 매칭 근거 보존. 앞뒤 공백 정리 전 값도 유지 |
| 값 출처 | 직접 추출은 `was_extracted=true`, `value_source=EXTRACTED`. DB 보완은 MATCHED, 계산·순서는 SYSTEM. 미추출 필드는 매칭·입력 후에도 최초 추출 여부 false 유지 |
| 최초 상태 | 최초 `is_modified=false`. 정상 값은 `validation_issues=[]`, 오류는 원문과 확인 사유 반환 |
| 누락 방지 | 시트별 확인·처리 상태와 결과 건수를 남김. 오류·불명확 행을 정상 추출로 확정하거나 확인된 다른 결과를 삭제하지 않음 |

## 공통 처리 연결

| 대상 | 처리 기준 |
| --- | --- |
| 파서 반환 | 시트별 `records[].basic` + `records[].results[]` 1:N. 샘플은 기본 기록 31건과 결과 751건 |
| 공통 매칭 | 분석법·지역·목록 연결은 공통 계층에서 수행. 파서는 원문·위치·관계를 반환하며 DB 조회·ID 발급을 수행하지 않음 |
| 저장 변환 | 결과마다 basic을 복사한 독립 `review_record`·`review_result` 1:1 쌍 생성. 샘플은 751쌍 |
| 순서 | 원본 시트 순서를 `source_record_order`로 보존. 시트 순서→행 순서로 저장 `record_order` 부여 |
| 최종 저장 | 검토·검증 후 `analysis_record`·`analysis_result` 반영. 원문 정밀도와 원본 스냅샷 유지 |
