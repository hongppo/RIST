## 파일 읽기 및 유형 판별

| 항목 | 규칙 |
| --- | --- |
| 입력 | XLSX 전체 시트에서 결과표 확인. 시트명·개수·파일명은 판별 조건으로 고정하지 않음 |
| 일부 시트 일치 | 일치 시트가 있으면 유형을 식별하되 일치·불일치 시트와 사유를 함께 표시. 일치 시트의 실제 결과만 추출하며 전체 시트 정상 추출로 표시하지 않음 |
| 성적서 구성 | 시험결과서 제목, 보고일자, 시료 NO와 구분되는 시료명, 분석 시험 결과, 단위, 하단 시험장비(방법)·시험자 영역 연결 |
| 서브유형 구성 | 물질 결과 열 옆에 참고·비고 역할의 열이 존재하고 시료별 결과와 보조값이 구분됨 |
| 기본형과 경계 | EXCEL-003 계열 구조를 확인한 뒤 상세 서브조건을 먼저 평가. 충족 시 EXCEL-003-a만 적용. 상세조건의 대응이 불명확하면 기본형으로 강제 처리하지 않고 확인 필요 |
| 중복 | 둘 이상의 상세 규칙이 동시에 성립하면 등록 순서로 확정하지 않고 확인 필요 |
| 라벨 비교 | 공백·줄바꿈·콜론 차이를 비교용으로 정규화. 추출 원문은 보존 |
| 병합 셀 | 좌상단 값과 실제 병합 범위를 읽고 해당 라벨에만 적용. 병합 제목 폭 전체를 물질 결과 열로 간주하지 않음 |
| 고정 금지 | Cr6+라는 물질명, 시료명, 셀 주소, 시트 수, 시료 수, 날짜·수치값으로 유형을 고정하지 않음 |

## 결과표 및 추출 범위

| 영역 | 처리 |
| --- | --- |
| 시료 행 | 시료명 컬럼 아래 실제 시료 행을 확인하고 결과 헤더와 연결. 시료 NO는 순번이며 시료명으로 대체하지 않음 |
| 물질 열 | 분석 시험 결과 영역에서 실제 물질 헤더 열만 선택. 참고·비고·단위·순번은 물질이 아님 |
| 참고 값 | 결과가 N.D여도 같은 행 참고 수치를 결과로 대체하지 않음 |
| 비고·검출한계 | N.D 정의·검출한계는 보조 원문으로 보존. 결과 수치로 변환하지 않음 |
| 우측 보조 정보 | Filter blank·DW blank·표준물질·전처리·용출액 설명은 결과에서 제외 |
| 종료·빈 영역 | 실제 시료·결과 영역과 이하 여백·하단 시험정보를 구분. 여러 셀에 나뉜 이하 여백도 안내문으로 처리. 첫 빈 행이나 샘플 마지막 행을 종료값으로 고정하지 않음 |
| 보조 계산·집계 | 결과표 밖 계산식, 시료수·성분수, 온도·습도, 서명·결재 정보는 결과에서 제외 |
| 반복 | 같은 시료명이 다시 나타나도 파일·시트·행 출처로 구분. 이름만으로 결과를 합치거나 제거하지 않음 |

### 시료별 지역 매칭

기존 지역 매칭 규칙에 따라 시료명을 관측 지점 DB와 대조한다. 정식 지점명·지역 부분·등록된 괄호 명칭을 사용하며 도시명만으로 지점을 확정하지 않는다. 대응 없음·서로 다른 지점 후보가 겹침은 NULL·확인 필요로 처리한다. 첫 시료 좌표를 전체 시료에 복제하지 않는다.

| 샘플 시료 지역 | 매칭 지점 |
| --- | --- |
| 해도 | 포항 해도 |
| 청림 | 포항 청림 |
| 묘도 | 여수 묘도(온동) |
| 태인 | 광양 태인 |

시트명에 광양이 있어도 묘도를 광양 지점으로 덮어쓰지 않는다. DB 원본 좌표와 매칭 근거를 보존하고 공통 좌표 저장 정밀도를 적용한다.

## 물질별 결과 추출

### 결과값과 원본 정보

결과값은 엑셀 표시값, 원문은 원본 정보에 보존

| 구분 | 처리 기준 |
| --- | --- |
| 공통 적용 | EXCEL-001·002·003과 엑셀 서브 유형에 동일 적용. XRF·ICP도 같은 기준 사용. CSV에는 적용하지 않음 |
| 사용자 결과값 | 원본 셀의 엑셀 표시값을 기준으로 `result_text`를 구성하고, 유효한 숫자는 그 값에 대응하는 `result_value`로 해석. 내부 숫자 문자열을 화면 결과값으로 그대로 대체하지 않음 |
| 셀 서식 | 결과 셀에 적용된 표시 형식을 반영. 예를 들어 내부값 `29.115000000000002`가 `0.00` 서식으로 `29.12`로 표시되면 결과값은 `29.12`. 표시값이 `29.115`이면 결과값은 `29.115`. 별도의 고정 소수 자릿수·유효숫자 수·추가 반올림 기준을 만들지 않음 |
| 일반 소수 표기 | clean_number는 유효 숫자의 지수 표기를 일반 소수 표기(평문)로 출력. `4.82E-2 → 0.0482`, `1E-7 → 0.0000001`. 표시값에서 생략된 내부 자릿수를 다시 붙이지 않음 |
| 원본 정보 | `result_raw`와 `source_snapshot`에 파일 내부 숫자 문자열을 그대로 보존. 셀 유형·주소·표시 형식·정규화 전 표시 문자열·수식/캐시도 구분하여 보존. 화면 결과값으로 원문을 덮어쓰지 않음 |
| 비수치·조건부 결과 | n.d·N.D·부등호 등은 원문·표시 및 기존 의미를 유지하고 수치값은 기존 규칙대로 NULL. 0·검출한계로 대체하거나 숫자 부분만 떼어 확정값으로 만들지 않음 |
| 변환 불가 | 표시값을 신뢰성 있게 확인·해석할 수 없으면 원문과 확인 사유 보존. 내부값을 표시값인 것처럼 대신 사용하거나 임의 서식을 적용하지 않음 |
| CSV 제외 | CSV에는 엑셀 정밀도 정리를 적용하지 않음. offline의 `4.627399605208463` 등 16자리 이상 값은 측정기 원본 정밀도로 보존 |

| 항목 | 규칙 |
| --- | --- |
| 정밀도 | 사용자 결과값은 셀 표시값 기준, 내부 숫자는 result_raw·source_snapshot에 원문 그대로 보존. 표시 형식 외 추가 반올림·절삭·고정 자릿수 적용 금지 |
| N.D·검출한계 | N.D는 수치 NULL. `0.001 이하`를 0.001 또는 0으로 확정하지 않음 |
| 분석법 우선순위 | 명확한 파일 분석법을 우선 사용. 없는 코드·고시번호를 추정하지 않음. 직접값이 없을 때만 공통 DB 매칭 조건 적용 |
| 출처 | 파일·시트·원본 셀·원문 라벨·값을 보존. 참고값과 검출한계는 최종 결과와 구분 |
