## 파일 읽기 및 유형 판별

| 항목 | 처리 기준 |
| --- | --- |
| 시트 순회 | 이 유형으로 판별된 워크북은 첫 번째 시트를 시트명과 관계없이 추출에서 제외하고 제외 상태를 기록. 두 번째 시트부터 대상 구조를 확인. 나머지 시트 수와 이름은 고정하지 않음 |
| 헤더 탐지 | 시료명과 채취일 등 시간 하위 헤더, 물질 헤더와 농도 단위의 상하 관계를 함께 확인. VOCs처럼 헤더가 한 행 아래인 배치도 허용 |
| 결과 블록 | 물질 헤더, 병합 범위와 보조열의 역할로 마지막 최종 농도 블록을 식별. ng/m3로 한정하지 않으며 단순히 가장 오른쪽 숫자 열이나 단위 블록을 선택하지 않음. Aldehyde 오른쪽 ppb 보조 블록 제외 |
| 병합 | 병합 헤더는 좌상단 값과 실제 적용 물질 범위를 함께 해석. 병합 끝을 곧바로 결과 끝으로 사용하지 않음 |
| 참고자료 범례 | 항목구분 참고자료에만 해당. 주황은 시료명, 초록은 채취일, 진한 남색은 물질, 연한 파랑은 결과, 연한 주황은 단위. 참고자료 해석 시 RGB 또는 테마색과 tint를 구분하며 원본에 범례가 있다고 간주하지 않음 |
| 유형 판별 근거 | 헤더 역할, 시료 축, 물질 축과 최종 농도 블록의 관계로 판별. 참고자료의 색상 범례는 원본 판별 조건이 아니며 색상이나 특정 셀 주소를 필수 조건으로 삼지 않음. 관계가 불명확하면 확인 처리 |
| 판별 불가 | 시료 축과 물질 축 또는 최종 결과 블록을 유일하게 식별하지 못하면 추측 추출하지 않음 |

## 최종 결과 블록

아래 주소는 기준 샘플의 결과 블록 대응 예시다. 파서는 헤더 역할과 열 관계로 마지막 최종 농도 블록을 찾는다. 단위는 헤더 원문에서 추출한 뒤 기존 정규화를 적용한다(ug/m3 → μg/m3). ng/m3만 허용하는 조건은 사용하지 않는다. Aldehyde의 오른쪽 ppb 보조 블록은 최종 결과로 대체하지 않는다.

| 계열 | 최종 결과 예시 | 단위 원문 | 포함과 제외 |
| --- | --- | --- | --- |
| 중금속 | BU:CI, 15개 물질 | ng/m3 | 병합 밖 Co 포함. 금속합과 금속합/PM10 비율 및 별도 PM10 수치 제외 |
| Cr(VI) | 청림 X열, 나머지 W열 | ng/m3 | 최종 Cr(VI) 농도. 중간 ug/mL와 총량 및 blank 제외 |
| PAHs 일반 | AA:AP, 16개 물질 | ng/m3 | NaP부터 IND. SUM 제외 |
| 온동PAHs | AB:AQ, 16개 물질 | ng/m3 | AA 채취가스량 제외. 같은 열의 정상 헤더에 직접 연결 |
| VOCs | BU:CL, 18개 물질 | ug/m3 | 병합 밖 마지막 3개 물질 포함. WD, WS, 강수량 제외 |
| Aldehyde | AI:AJ, 2개 물질 | ug/m3 | Formaldehyde와 Acetaldehyde. 오른쪽 AK:AL ppb 제외 |

### 날짜 기준

- B열의 채취일 기재 여부로 결과행을 선별하며 날짜 파싱 성공 여부와 구분한다. 연도가 없는 날짜 문자열도 기재된 행으로 유지하고 날짜값은 확정하지 않으며 원문과 확인 사유를 남긴다. B열이 공란인 행은 제외한다.
- 채취일은 원문에 포함된 연도를 사용한다. 현재 연도, 파일명, 다른 시트 날짜로 보완하지 않는다.
- Excel 날짜 직렬값은 워크북 날짜 체계와 표시 형식으로 해석한다. 월일만 표시되어도 내부 날짜의 연도가 확인되면 사용한다.
- `01월 05일`처럼 연도가 없는 문자열은 원문과 확인 사유를 남기고 날짜를 확정하지 않는다.
- 분석일은 채취일이나 채취종료일로 생성하지 않는다.

## 결과 행과 값 처리

| 항목 | 규칙 |
| --- | --- |
| 데이터 행 | B열에 채취일이 기재된 시료 데이터 행만 추출. 마지막 기재행까지의 모든 행을 포함하지 않음. B열 공란은 시료명이나 결과가 있어도 제외. 통계 및 집계행 제외 유지 |
| 미측정 입력 | 빈 결과 교차 셀은 결과를 생성하지 않음. 모든 최종 결과가 빈 행은 결과 기록을 생성하지 않음. 원입력 공란으로 결과 0의 미측정을 추정하지 않음 |
| 실제 0 | 결과 범위 내 0과 0.00은 원래 표시대로 추출하고 수치는 0으로 유지. 0의 개수나 크기로 행을 제외하지 않음 |
| 수식 0 | 수식의 저장된 결과가 0이면 표시 형식을 유지하여 추출. 원입력이 비어 있어도 제외하거나 미측정으로 판정하지 않음 |
| 오류 | #DIV/0!, #VALUE! 등 계산 오류는 result_text='error', result_value=NULL로 기록하고 결과 행 유지. result_raw와 source_snapshot에 원본 오류 및 수식 보존. error는 결과 누락이 아니며 계산 오류만으로 저장 차단하지 않음. 다른 필수 항목과 날짜 조건을 충족하면 저장 가능 |
| 비수치 | n.d, N.D 및 부등호는 원문과 의미 유지, 수치 NULL. 결과 없음으로 오인하거나 검출한계 또는 0으로 대체하지 않음 |
| 종료 | 시료 데이터 영역과 AM, Min, Max, GM, 월별 통계 영역을 구분. 첫 빈 행만으로 종료하지 않으며 집계행을 시료로 생성하지 않음 |
| 수식 | 저장된 계산 결과와 표시 형식 사용. 수식과 캐시 별도 보존. 캐시 부재는 확인 대상으로 유지하며 계산 오류 또는 error로 임의 치환하지 않음. 외부 연결 및 재계산으로 보완하지 않음 |
| 결과 표시 | 숫자는 엑셀 표시값을 유지하며 0과 0.00 및 수식 0의 표시를 그대로 추출. 추가 반올림 금지. 계산 오류의 표시값만 error로 기록하며 원본 오류는 별도 보존 |
| 원문 | 내부 숫자 문자열, 수식, 캐시, 셀 유형, 원래 표시 문자열과 서식을 원본 정보에 보존. 결과 표시값으로 덮어쓰지 않음 |
| 단위 | ug/m3 등 복합단위는 [단위 목록](<../../db-lists/unit.md>)과 공통 단위 정규화 정책을 적용. ug 단독 표기와 혼동하지 않음. 원문 보존, 미확정 동등성이나 ID 추정 금지. 임의 수치 환산 금지 |

## 미추출 항목 및 매칭

| 항목 | 처리 |
| --- | --- |
| 구분, 매체, 담당자, 분석기관 | 파일 직접 추출값 없음. 목록 선택 또는 입력 |
| 분석일자 | 직접 추출값 없음. 필요한 경우 입력 |
| 위치와 좌표 | 파일 직접 추출값 없음. [지역 매칭](<../../matching-rules/location.md>)의 실제 대응 근거가 있을 때만 매칭하고 그 외 목록 선택 또는 입력 |
| BASE, 채취법 | 목록 선택 또는 입력. 안내에 적힌 값이나 공란, x를 고정 업무값으로 사용하지 않음 |
| 분석법 | 명확한 직접 추출값 우선. 없으면 VOCs 시트 결과에 ES 01804.2a, PAHs 시트 결과에 ES 01802.1a를 MATCHED로 보완. 파일 전체 적용 및 지정악취 물질별 매칭 금지. 다른 계열 또는 불명확한 시트는 자동 매칭하지 않음 |
| 목록 ID | 실제 목록 항목이 유일하게 확인될 때만 연결. 임의 ID 생성 금지 |

분석법은 [파일 유형별 분석법 매칭](<../../matching-rules/analysis-method-by-file-type.md>)을 따른다. 첫 시트 제외 기준을 유지하며 원문을 보존한다. 실제 동일한 DB 항목이 확인될 때만 ID를 연결하고 코드와 DB 분석법명을 함께 표시한다. 자동추출 불가 안내의 예시 코드는 직접 추출값으로 간주하지 않는다.
