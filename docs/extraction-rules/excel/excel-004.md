## 파일 읽기 및 유형 판별

| 항목 | 처리 기준 |
| --- | --- |
| 시트 순회 | 이 유형으로 판별된 워크북은 첫 번째 시트를 시트명과 관계없이 추출에서 제외하고 제외 상태를 기록. 두 번째 시트부터 대상 구조를 확인. 나머지 시트 수와 이름은 고정하지 않음 |
| 헤더 탐지 | 시료명과 채취일 등 시간 하위 헤더, 물질 헤더와 농도 단위의 상하 관계를 함께 확인. VOCs처럼 헤더가 한 행 아래인 배치도 허용 |
| 결과 블록 | 지정 최종 농도 블록을 식별. 단순히 가장 오른쪽 숫자 열이나 마지막 단위 블록을 선택하지 않음 |
| 병합 | 병합 헤더는 좌상단 값과 실제 적용 물질 범위를 함께 해석. 병합 끝을 곧바로 결과 끝으로 사용하지 않음 |
| 참고자료 범례 | 항목구분 참고자료에만 해당. 주황은 시료명, 초록은 채취일, 진한 남색은 물질, 연한 파랑은 결과, 연한 주황은 단위. 참고자료 해석 시 RGB 또는 테마색과 tint를 구분하며 원본에 범례가 있다고 간주하지 않음 |
| 유형 판별 근거 | 헤더 역할, 시료 축, 물질 축과 최종 농도 블록의 관계로 판별. 참고자료의 색상 범례는 원본 판별 조건이 아니며 색상이나 특정 셀 주소를 필수 조건으로 삼지 않음. 관계가 불명확하면 확인 처리 |
| 판별 불가 | 시료 축과 물질 축 또는 최종 결과 블록을 유일하게 식별하지 못하면 추측 추출하지 않음 |

### 원본 값, 추출 예시 및 컬럼 매핑

| 항목 | 컬럼 | 샘플 원본 | 적용 예시 | 규칙 |
| --- | --- | --- | --- | --- |
| 시료명 | `sample_name` | 청림중금속 A3 `청림1-1` | `청림1-1` | 왼쪽 시료명 전체. 원문을 남기고 표시값의 앞뒤 공백만 정리 |
| 채취일 | `collected_date` | 청림중금속 B3 날짜값 | `2026/01/05` | 왼쪽 채취일의 원문 연도 사용 |
| 채취 정밀도 | `collected_precision`, `collected_at` | 채취일은 날짜 | DATE, 일시 NULL | 채취시작과 종료는 보조 원문으로 구분. 채취일에 시각을 임의 결합하지 않음 |
| 분석물질 | `substance_name` | 청림중금속 BU2 `Pb` | `Pb` | 선택한 최종 블록의 물질명. 약어를 근거 없이 확장하지 않음 |
| 결과 | `result_raw`, `result_text`, `result_value` | 청림중금속 BU3 수식과 저장 오류 `#DIV/0!` | 오류 원문 유지, 수치 NULL | 해당 시료와 물질의 교차 셀. 0이나 중간 결과로 대체하지 않음 |
| 단위 | `unit` | 청림중금속 BU1 `농도(ng/m3)` | `ng/m3` | 헤더에서 단위를 분리하여 대응 물질에 적용 |

### 날짜 기준

- 채취일은 원문에 포함된 연도를 사용한다. 현재 연도, 파일명, 다른 시트 날짜로 보완하지 않는다.
- Excel 날짜 직렬값은 워크북 날짜 체계와 표시 형식으로 해석한다. 월일만 표시되어도 내부 날짜의 연도가 확인되면 사용한다.
- `01월 05일`처럼 연도가 없는 문자열은 원문과 확인 사유를 남기고 날짜를 확정하지 않는다.
- 분석일은 채취일이나 채취종료일로 생성하지 않는다.

## 결과 행과 값 처리

| 항목 | 규칙 |
| --- | --- |
| 데이터 행 | 왼쪽 시료명과 채취일 아래의 시료 행을 최종 농도에 연결. 동일 이름의 별도 행도 출처를 유지 |
| 미측정 입력 | 미측정 결과는 최종 농도 셀을 빈칸으로 제공. 빈 교차 셀은 결과를 생성하지 않음. 모든 최종 결과가 빈 행은 결과 기록을 생성하지 않음 |
| 실제 0 | 측정 결과 0은 정상 결과로 유지. 0의 개수나 크기로 행을 제외하지 않음 |
| 수식 0 예외 | 원측정 입력이 비어 있으나 계산식이 0을 반환하는 미정비 파일은 실제 0 또는 미측정으로 단정하지 않음. 원문, 수식, 캐시와 확인 사유를 남기며 정상 측정 결과로 확정하지 않음 |
| 오류 | #DIV/0!, #VALUE! 등은 오류 상태와 원문을 유지하고 숫자 결과는 NULL. 오류가 있는 시료를 정상 완료로 표시하지 않음 |
| 비수치 | n.d, N.D 및 부등호는 원문과 의미 유지, 수치 NULL. 결과 없음으로 오인하거나 검출한계 또는 0으로 대체하지 않음 |
| 종료 | 시료 데이터 영역과 AM, Min, Max, GM, 월별 통계 영역을 구분. 첫 빈 행만으로 종료하지 않으며 집계행을 시료로 생성하지 않음 |
| 수식 | 저장된 유효 계산 결과와 표시 형식을 사용. 수식과 캐시를 별도 보존. 캐시 부재 또는 오류는 확인 처리. 외부 연결 및 재계산으로 보완하지 않음 |
| 결과 표시 | 엑셀 표시값을 결과로 사용. clean_number는 지수 대신 일반 소수 표기로 출력. 추가 고정 소수 자릿수나 반올림 기준 없음 |
| 원문 | 내부 숫자 문자열, 수식, 캐시, 셀 유형, 원래 표시 문자열과 서식을 원본 정보에 보존. 결과 표시값으로 덮어쓰지 않음 |
| 단위 | ug/m3 등 복합단위는 [단위 목록](<../../db-lists/unit.md>)과 공통 단위 정규화 정책을 적용. ug 단독 표기와 혼동하지 않음. 원문 보존, 미확정 동등성이나 ID 추정 금지. 임의 수치 환산 금지 |

## 미추출 항목 및 매칭

| 항목 | 처리 |
| --- | --- |
| 구분, 매체, 담당자, 분석기관 | 파일 직접 추출값 없음. 목록 선택 또는 입력 |
