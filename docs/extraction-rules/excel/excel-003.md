| 공통 항목 | 복수 담당자와 복합 분석법은 라벨 뒤 전체 원문을 해당 표의 모든 결과에 적용. 물질별로 임의 분배하지 않음 |
| 분석일자 | 보고일자를 분석 날짜로 매핑하되 원문 라벨·값 보존. 채취일자는 별도 직접 입력하며 시료명의 날짜를 자동 추출하지 않음 |
| 결과·단위 | 숫자 저장 원문과 표시 형식을 보존. `< 0.005`는 원문·표시 유지, 수치 NULL. 실제 0 보존, 빈 교차값 NULL. `%`를 이유로 100으로 나누지 않음 |
| 분석법 매칭 | 명확한 파일 분석법 우선 → 없으면 [분석법 매칭](<../../matching-rules/analysis-method.md>)으로 보완 → 미매칭은 NULL·인터페이스 입력. 다른 양식·시트의 분석법을 복사하지 않음 |
| 미추출·입력 | 구분·매체·기관·채취일자·채취법·공장 좌표는 입력값 적용. BASE 미입력은 NULL. 입력 예시·기관명·시료명에서 상수·좌표를 만들지 않음 |
| 빈 양식·출처 | 양식 식별과 결과 존재를 구분. 빈 양식·작성안의 안내용 값은 결과 0건. 파일·시트·셀·원문 라벨·병합 범위·매칭 출처 보존 |

## 파일 읽기 및 유형 판별

### 양식별 라벨 대응

| 구성요소 | 성적서 예시 양식 | 시험결과서 표준 양식 | 판별·추출 기준 |
| --- | --- | --- | --- |
| 문서 제목 | 분석시험성적서 | 시험결과서 | 표의 상단 제목과 아래 구조를 함께 확인. 제목만으로 확정하지 않음 |
| 시료 행 축 | 시료명 | 시료명 | 시료 NO와 다른 열. 숫자·문자 시료명 모두 가능 |
| 물질 열 축 | 분석 시험 결과 아래 물질명 | 분석 시험 결과 아래, 시료명 우측 물질명 | 실제 헤더가 있는 결과 열만 연결 |
| 분석일자 원천 | 보고일자 우측 | 보고일자 우측 | 예시는 C4, 표준은 C2. 셀 주소가 아니라 라벨과 입력칸 관계로 탐색 |
| 담당자 | 하단 분석자: | 하단 시험자: | 라벨 뒤 값 전체. 상단 결재·담당·시험자 서명란과 구분 |
| 분석법 | 하단 분석 방법: | 하단 시험장비(방법): | 라벨 뒤 값 전체를 해당 표에 적용 |
| 단위 | 단위: 뒤 값 | 단위: 뒤 값 또는 대응 입력칸 | 물질 표에 대응하는 단위 영역만 사용 |

### 라벨·병합 셀 읽기

| 항목 | 처리 기준 |
| --- | --- |
| 시트 순회 | 전체 워크시트를 원래 순서로 확인하고 시트별 유형·결과 유무·확인 사항 기록. 첫 시트만 처리하거나 특정 시트명으로 제한하지 않음 |
| 비교용 라벨 | 공백·줄바꿈·콜론 차이를 정규화하여 비교. 원문 라벨과 추출값은 별도로 보존하고 이름·분석법 내부 공백·기호를 비교 규칙으로 훼손하지 않음 |
| 같은 셀의 값 | 라벨 뒤의 전체 값을 읽음. 예: `분석 방법: ICP 분석 및 Fe 적정`에서 라벨만 분리 |
| 분리된 입력칸 | 라벨 뒤 값이 비면 동일 항목의 대응 입력칸만 확인. 임의로 다음 비어 있지 않은 셀을 가져오지 않음 |
| 병합 영역 | 좌상단 실제 값과 병합 범위를 읽어 해당 라벨·입력칸·표 제목의 영역으로 해석. 병합을 해제해 모든 결과 셀에 값을 채우지 않음 |
| 중복·누락 | 중복 라벨은 같은 결과표의 적용 범위로 구분. 후보·입력칸·범위가 불명확하면 원문과 확인 사유 반환. 인접 표의 값을 대신 사용하지 않음 |
| 유형 확정 | 양식 라벨과 시료 행·물질 열 관계로 판별. 시트명·의뢰번호·물질 조합·예시의 행열 수로 유형을 분리하거나 고정하지 않음 |

## 추출 구간 및 표 범위

| 구분 | 처리 기준 |
| --- | --- |
| 표 시작 | 시료명 열과 분석 시험 결과 제목을 식별하고 그 아래의 실제 물질 헤더 행 확인. 물질 헤더 아래의 유효 시료 행부터 결과 연결 |
| 물질 열 | 시료명 우측의 실제 물질명을 기준으로 구성. 시료 NO·비고·단위는 물질에서 제외. 예시의 N7 `K`처럼 병합 제목 폭 밖에 있어도 구조상 물질 헤더·결과에 해당하면 포함 |
| 시료 행 | 시료명 아래의 식별자를 읽고 같은 행의 결과 연결. 시료 NO 순번이나 시료수로 시료명을 대체하지 않음 |
| 숫자 시료명 | `2`, `6`, `7` 등은 유효한 시료명. 문자열 식별자로 보존하며 순번·날짜·결과값으로 해석하지 않음 |
| 빈 결과 | 유효한 시료·물질 교차칸이 비면 해당 결과를 NULL로 유지. 다음 행·열의 값을 당겨 채우지 않음 |
| 빈 여유 행 | 시료명·결과가 없는 행은 생성하지 않음. 첫 빈 행에서 종료하지 않고 동일 표 뒤쪽의 실제 내용을 확인 |
| 종료 | 하단 분석 방법·시험장비(방법) 영역을 경계로 결과표 종료. 시료수·성분수·서명·결재·기관명·양식번호·하단 안내를 결과로 읽지 않음 |
| 불명확 영역 | 물질 헤더 없는 값, 시료명 없는 결과, 주석·별도 표의 혼입은 임의 연결·제외하지 않고 확인. 일부 결과만 읽고 정상 완료로 확정하지 않음 |
| 반복·복수 표 | 동일 시료명·물질명이 반복되어도 원본 위치·순서를 보존. 별도 표는 라벨·범위가 독립적으로 식별될 때 각각 처리하며 공통 항목을 표 사이에 복제하지 않음 |

### 빈 양식 및 작성 안내 구분

| 구분 | 처리 기준 |
| --- | --- |
| 빈 표준 양식 | 양식 라벨은 식별되지만 실제 시료·물질 헤더·결과가 없는 경우 결과 0건. 이를 구조 미지원과 구분하여 반환 |
| 작성안 자리표시 | 빈 양식의 `##.##.##`, 안내용 `Sample`, `서명`, `생략`은 실제 날짜·시료·담당자 값으로 만들지 않음 |
| 이하 여백 | 연속 셀에 나뉜 `이`, `하`, `여`, `백`도 안내 영역으로 확인. 물질명·결과로 해석하지 않음 |
| 실데이터와 구분 | 위 문자열만으로 일괄 삭제하지 않고 빈 양식·안내의 위치와 물질 헤더·결과 유무를 함께 확인. 실제 값인지 불명확하면 확인 대상으로 유지 |
| 빈 양식 반환 | 실제 시료·물질에 연결된 기록·결과를 만들지 않으며 시트의 양식 식별·결과 0건 사유는 진단에 보존. 성공적으로 읽었다는 이유로 실제 결과 추출 완료로 표시하지 않음 |
| 검증 범위 | 표준 샘플 2개 시트에는 물질 헤더·실제 결과가 없어 실결과 추출 검증은 불가. 값이 채워진 파일은 동일한 라벨·표 구조와 교차 관계를 확인한 뒤 적용 |

### 시료·담당자·날짜

| 항목 | 처리 기준 |
| --- | --- |
| 시료명 | 시료명 헤더 아래 값 전체 보존. 표시값의 앞뒤 공백만 정리하고 내부 문자·번호·공백 유지. 숫자 셀의 원래 유형·저장값·표시 형식도 보존 |
| 담당자 | 해당 표 하단 분석자 / 시험자 라벨 뒤의 전체 이름을 추출. `구경민,전영태`를 그대로 모든 결과에 적용. 쉼표로 분리하여 물질별 담당자를 배정하지 않음 |
| 담당자 제외 | 의뢰처·의뢰자, 상단 결재·서명, 파일명의 이름을 담당자로 대신 사용하지 않음 |
| 분석 날짜 | 보고일자 우측 유효 날짜를 `analyzed_date`에 매핑. 원문 라벨 `보고일자`와 원문값 보존. 실제 시험 수행일과 동일하다는 추정을 추가하지 않음 |
| 날짜 해석 | `2026.3.9` 등 유효 날짜 문자열 또는 날짜 셀을 해석. Excel 날짜 셀은 워크북 날짜 체계와 형식 함께 확인. 자리표시·불명확 날짜는 NULL·확인 |
| 시간·기간 | 날짜만 있는 샘플은 `analyzed_precision=DATE`, `analyzed_at=NULL`. 자정·시간대를 생성하지 않음. 유효 시작 날짜만 있으면 공통 스키마 기준 분석 기간 1일, 날짜 미확정이면 NULL |
| 채취일자 | 파일 추출 없음. 시료명에 날짜가 포함되어도 자동 해석하지 않고 인터페이스에서 직접 입력 |

| 분석 기간 | `analysis_duration_days` | 유효 분석 시작 날짜 | `1` | SYSTEM. 시작일만 있는 공통 처리 |

## 물질별 결과 추출

### 물질·결과·단위 해석

| 항목 | 처리 기준 |
| --- | --- |
| 분석물질 | 실제 물질 헤더 전체 보존. 헤더가 비어 있는 표준 양식에 예시의 물질명·순서를 복사하지 않음 |
| 결과 연결 | 각 시료 행의 물질 헤더 열과 교차하는 셀 하나를 결과 1건으로 생성. 시료 행 순서→물질 열의 왼쪽에서 오른쪽 순서 유지 |
| 숫자 원문 | XLSX XML 숫자 `<v>` 문자열을 `result_raw`로 보존하고 Decimal로 해석. 라이브러리 이진 부동소수점 변환값으로 원문을 대체하지 않음 |
| 표시 보존 | 최초 `result_text`는 원문 정밀도를 유지. 원본 셀의 표시 형식과 그 형식으로 표시되는 문자열도 `source_snapshot`에 별도 보존하여 저장 숫자와 구분 |
| 정밀도 | 임의 반올림·절삭 금지. 정밀 소수 전송은 문자열 사용. 저장 정밀도를 초과하면 원문 보존·검증 오류 반환 |
| 부등호·비수치 | `< 0.005` 등은 공백·부등호를 포함한 원문과 표시값 유지, `result_value=NULL`. 0·0.005·검출한계 확정값으로 대체하지 않음 |
| 0·빈 값 | 실제 0은 정상 수치. 유효 교차칸의 빈 결과는 NULL이며 빈 여유 행과 구분 |
| 단위 | 해당 표의 단위 라벨 뒤 값 또는 대응 입력칸에서 추출하여 그 표의 결과에 적용. `%`는 샘플값이며 고정하지 않음. 공란은 NULL·인터페이스 보완 |
| 단위 변환 | `%`가 명시되어도 숫자를 100으로 나누거나 정규화하지 않음. 원문 수치와 단위를 각각 보존 |
| 오류·수식 | 오류 원문·수식·캐시를 구분해 보존. 유효 캐시만 해석하고 캐시 부재·오류는 확인. 다른 셀·시트 값이나 외부 실행으로 보완하지 않음 |

### 물질별 추출 예시 및 컬럼 매핑

| 항목 | 매핑 컬럼 | 샘플 원본 위치·값 | 실제 추출 예시 | 추출 규칙 |
| --- | --- | --- | --- | --- |
| 분석물질 | `substance_name` | 예시 D7 `Cu` | `Cu` | EXTRACTED. 해당 물질 열의 시료별 결과 연결 |
| 부등호 결과 | `result_raw`, `result_text`, `result_value` | D8 `< 0.005` | 원문·표시 `< 0.005`, 수치 `NULL` | 한계값을 확정 수치로 바꾸지 않음 |
| 숫자 결과 | `result_raw`, `result_text`, `result_value` | F8 저장 문자열 `29.115000000000002` | 원문·표시 `29.115000000000002`, 같은 값의 Decimal | 원본 표시 `29.12`·형식 `0.00`은 스냅샷에 별도 보존 |
| 지수 표기 | `result_raw`, `result_value` | D9 저장 문자열 `4.3750000000000004E-3` | 원문 동일, Decimal `0.0043750000000000004` | 라이브러리 변환값 `0.004375`로 정밀도 축소 금지 |
| 단위 | `unit` | N6 `단위:%` | `%` | EXTRACTED. 해당 표 전체에 적용 |
| 분석법 | 분석법 표시값 | B24 `분석 방법: ICP 분석 및 Fe 적정` | `ICP 분석 및 Fe 적정` | EXTRACTED. 복합 방법 전체를 모든 결과에 적용 |

### 분석법 원문 및 DB 매칭

| 구분 | 처리 기준 |
| --- | --- |
| 명확한 파일 분석법 | 분석 방법 / 시험장비(방법) 라벨 뒤 전체 원문을 우선. `ICP 분석 및 Fe 적정`을 모든 결과에 적용하며 Fe만 적정, 나머지 ICP로 임의 분배하지 않음 |
| DB 보완 | 명확한 파일값이 없을 때만 분석물질을 [분석법 매칭](<../../matching-rules/analysis-method.md>)·[분석법 DB](<../../db-lists/analysis-method.md>)에 연결. 미매칭·불명확하면 NULL·인터페이스 입력 |
| 불명확 원문 | 원문과 확인 사유는 보존하되 확정 추출값으로 사용하지 않음. 빈 표준 양식에 예시 파일의 방법·담당자를 복사하지 않음 |
| 표시값·ID | DB 값이 다르거나 미매칭이어도 명확한 파일 분석법을 덮어쓰거나 NULL로 지우지 않음. 실제 적용한 같은 방법의 항목만 ID 연결. 복합 방법에 개별 방법 하나의 ID를 임의 연결하지 않음 |
| 코드·고시번호 | 파일 또는 실제 적용 DB 항목에서 확인된 값만 사용. ICP라는 표현에서 ES 코드·고시번호를 생성하지 않음 |
| 출처·예외 | 직접 추출은 EXTRACTED, DB 보완은 MATCHED. 다른 유형의 별도 DB 우선 예외를 이 유형에 확대하지 않음 |

## 미추출 항목 및 사용자 보완

| 항목 | 처리 기준 |
| --- | --- |
| 구분·매체·분석기관 | 초기 NULL. 인터페이스 입력·선택값 적용. 기관명·파일명·입력 예시로 자동 확정하지 않음 |
| 채취일자 | 직접 입력한 유효 날짜 적용. 미입력은 NULL·UNKNOWN. 시료명이나 보고일자로 대체하지 않음 |
| BASE | 미입력은 NULL. `없음`이라는 문자값을 저장하지 않음 |
| 채취법 | 초기 NULL. 인터페이스 입력값 적용. 가이드의 입력 예시를 고정값으로 생성하지 않음 |
| 공장 위치·좌표 | 확인된 공장 위치 선택 또는 직접 입력값 적용. 같은 공장의 위도·경도를 쌍으로 사용. 공장별 좌표 목록 미정 상태에서는 NULL, 기관·의뢰처·시료명에서 추정하지 않음 |
| 단위·분석법 | 파일 추출 또는 허용된 분석법 DB 매칭 후에도 비면 NULL·인터페이스 보완 |
| 목록 ID | 실제 연결 근거가 있을 때만 설정. 복수 담당자 원문을 임의의 한 사람 ID에 연결하지 않으며 명확한 추출 표시값은 미매칭이어도 보존 |

## 원본 보존·오류 처리

| 항목 | 처리 기준 |
| --- | --- |
| 위치·범위 | 파일·시트·시트 순서·표 범위·시료 셀·물질 헤더 셀·교차 결과 셀·공통 라벨/값 셀·병합 범위 보존 |
| 스냅샷 | 원문 라벨·추출 전 문자열·셀 유형·숫자 XML 원문·표시 형식/표시 문자열·날짜 체계·수식/캐시·매칭 근거 보존 |
| 필드 출처 | 직접 추출은 `was_extracted=true`, `value_source=EXTRACTED`. DB 보완은 MATCHED, 입력은 MANUAL, 순서·기간은 SYSTEM. 최초 미추출 여부는 이후 입력·매칭과 구분 |
| 최초 상태 | 최초 `is_modified=false`. 정상 값은 `validation_issues=[]`. 라벨·범위·값의 불명확성은 원문과 확인 사유 반환 |
| 처리 결과 구분 | 미지원 구조, 지원 양식의 결과 0건, 실제 결과 추출, 확인 필요 상태를 구분. 빈 양식에 가상 시료·결과를 만들지 않고 확인된 다른 시트 결과도 삭제하지 않음 |

## 공통 처리 연결

| 대상 | 처리 기준 |
| --- | --- |
| 파서 반환 | 시료 행별 `records[].basic` + `records[].results[]` 1:N. 예시 기본 기록 6건·결과 66건, 표준 두 시트는 실제 결과 0건 |
| 공통 계층 | 분석법·목록 매칭은 공통 계층에서 수행. 파서는 원문·위치·표/시료/물질 관계를 반환하며 DB 조회·ID 발급을 수행하지 않음 |
| 저장 변환 | 결과마다 basic을 복사한 독립 `review_record`·`review_result` 1:1 쌍 생성. 예시는 66쌍 |
| 원본 순서 | 시트·표·시료 행 순서를 `source_record_order`, 물질 열 순서를 결과 순서로 보존. 결과 행별 저장 시 임의 재정렬하지 않음 |
| 최종 저장 | 검토·검증 후 `analysis_record`·`analysis_result` 반영. 원문 정밀도·원본 스냅샷 유지 |
