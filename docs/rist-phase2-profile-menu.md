## 프로필 메뉴 정책

| 항목 | 내용 |
| --- | --- |
| 화면 ID | rist-phase2-profile-menu |
| 기반 | 기존 프로필 메뉴 화면의 별도 복사본 |
| 메뉴 순서 | 파일 업로드로 돌아가기 → 업로드 이력 → 로그아웃 |

## 파일 업로드로 돌아가기

| 현재 상태 | 동작 |
| --- | --- |
| 작업 없음 | 별도 종료 확인 없이 업로드 화면으로 이동 |
| 최종 저장 완료 | 별도 종료 확인 없이 업로드 화면으로 이동. 저장된 결과 보존 |
| 업로드·추출·검토 중 | 작업 종료 확인창 표시 |

확인 문구는 “현재 작업을 종료하고 파일 업로드 화면으로 돌아가시겠습니까?”입니다. “최종 저장하지 않은 검토 내용은 결과 데이터로 등록되지 않습니다.”를 함께 표시합니다.

- 계속 작업: 확인창만 닫고 현재 작업·입력 상태 유지
- 작업 종료 후 돌아가기: 현재 작업을 종료하고 파일 업로드 화면으로 복귀
- 이미 최종 저장된 결과는 복귀·작업 종료로 제거하지 않음

## 목업 동작

상단의 기획용 상태 선택은 작업 없음·업로드 중·추출 중·검토 중·최종 저장 완료를 보여줍니다. 제품 메뉴와 구분하며 실제 서버 작업 상태를 조회하지 않습니다. 복귀 예시는 같은 페이지에서 메뉴를 닫고 기존 업로드 기본 화면을 표시합니다. 업로드 이력과 로그아웃은 기존 예시 페이지 연결을 유지합니다.

## 처리 중 작업과 확인 필요사항

처리 중 서버 작업을 실제로 중단할 수 있는지 확인해야 합니다. 늦게 도착한 이전 작업 결과가 새 작업에 섞이지 않도록 종료 작업과 새 작업을 구분해야 합니다. 실제 취소 API·서버 중단·백엔드 작업 종료는 이번 목업에 구현하지 않습니다.

임시 데이터와 원본 파일의 보관·정리 시점·정리 범위는 미확정입니다. 화면 복귀를 이유로 파일이나 DB를 임의 삭제하지 않습니다.
