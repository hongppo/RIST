파일 읽기 및 유형 판별

항목처리 기준
파일 읽기XLSX의 시트·셀 주소·셀 유형·공유 문자열·숫자 원문·표시 형식을 함께 읽음. 원본 파일은 수정하지 않음
결과표 구성상단의 여러 시료명 열, 왼쪽의 여러 물질명 행, 각 교차 셀의 숫자 또는 결과 표기가 연결된 행렬 탐색
물질 축Benzene·Toluene 등 VOCs 물질명이 세로로 이어지는지 확인. 물질 이름 하나만으로 유형을 확정하지 않음
유형 확정시료 열·물질 행의 대응과 결과 영역이 함께 확인될 때 확정. 다른 규칙 후보와 중복되거나 축 대응이 불명확하면 확인 대상으로 반환
가변 구조파일명·시트명·셀 주소·시료 및 물질 수·빈 열 개수는 판별·종료의 고정 조건으로 사용하지 않음
시트·블록각 시트에서 결과표 블록을 독립 탐색. 시트 순서와 블록의 원본 위치를 보존하며 다른 블록의 헤더를 임의 상속하지 않음
병합 셀헤더가 병합된 경우 실제 병합 범위와 하위 열의 역할을 확인. 시료 대응이 유일하지 않으면 임의 복제하지 않고 확인 처리

추출 구간 및 빈 양식 열 구분

구분판정 및 처리
시작시료명 헤더와 분석물질명 축을 찾고 교차 결과 영역을 구성
유효 시료 열비어 있지 않은 시료명과 결과 행렬의 연결이 확인된 열. 시료명 자체를 DB 식별키로 사용하지 않음
물질 행물질명이 기재되고 시료 열의 결과와 대응하는 행. 제목·주석·빈 행을 물질로 포함하지 않음
빈 양식 열시료명 헤더가 숫자 0이고 물질 행의 결과도 모두 숫자 0인 열은 제외
실제 0유효한 시료명 아래의 0은 정상 결과. 해당 열의 결과가 모두 0이어도 포함
이름 없는 값시료명 없이 0 이외의 값이 있거나 축 대응이 불분명하면 원문·위치를 보존하고 확인 처리. 빈 양식으로 일괄 삭제하지 않음
빈 셀·간격중간의 빈 셀·빈 열만으로 결과표 종료를 단정하지 않음. 다음 유효 헤더·물질·결과의 연결을 확인
종료해당 시료·물질 축에 대응하는 결과가 끝나거나 별도 표·주석 영역으로 전환되는 지점
반복 시료같은 이름의 별도 열은 위치·출현 순서를 보존. 임의 병합·평균·중복 제거하지 않음

시료명이나 지역에 지역 매칭의 매칭 단어가 포함되면 해당 관측 지점에 연결하고 지역 DB의 위도·경도를 사용한다. 매칭 단어가 시료명 앞부분에 있어야 한다는 조건은 두지 않는다.

원문 정밀도 및 셀 유형

구분처리 기준
저장 숫자XLSX worksheet XML의 숫자 <v> 문자열을 원문으로 확보하고 Decimal로 해석. 셀 표시 형식·화면의 반올림값·이진 부동소수점 변환값으로 원문을 대체하지 않음
정밀도 전달JSON 등에서 정밀 소수를 문자열로 전달. 저장 컬럼이 원문 정밀도를 수용하지 못하면 원문을 보존하고 검증 오류로 반환하며 자동 절삭·반올림하지 않음
문자형 숫자부호·소수·지수 표기를 포함한 전체 문자열이 유효한 숫자인지 검증 후 Decimal 변환. 원래 셀 유형·문자열은 보존
비수치ND, n.d, 부등호 등을 원문·표시값에 보존하고 result_value는 NULL. 0이나 검출한계로 대체하지 않음
빈 셀식별한 빈 셀의 원문은 빈 문자열, 업무값은 NULL. 위치 자체를 식별하지 못하면 원문도 NULL과 확인 정보 기록
오류·수식오류값은 원문 보존 후 수치 NULL. 수식은 수식과 캐시 결과를 구분해 보존하고 유효한 캐시만 해석. 캐시가 없거나 오류이면 확인 처리하며 외부 연결·매크로 실행으로 보완하지 않음

분석법 DB 매칭

분석물질이 분석법 매칭의 항목에 대응하면 파일 유형과 관계없이 해당 분석법 DB를 연결한다. 매칭값은 파일 직접 추출값과 구분한다.

분석물질시험방법 코드분석법 표시값
TolueneES 09307.bES 09307.b 휘발성유기화합물 - 저온 농축 - 기체크로마토그래피
StyreneES 09306.1bES 09306.1b 스타이렌 - 저온 농축 - 기체크로마토그래피
  • 매칭표에 없는 물질은 분석법 NULL로 유지하고 검토 화면에서 보완한다. VOCs 파일이라는 이유만으로 전체 물질에 ES 01804.2a를 일괄 적용하지 않는다.
  • M,P-Xylene, O-Xylene을 Xylene과 연결하는 별도 대응이 없으면 임의로 동일시하지 않는다. 명백한 오타도 대응이 유일할 때만 연결한다.
  • 표시값은 제공된 고시번호·시험방법 코드·분석법명을 연결한다. 비어 있는 고시번호를 ES 코드로 채우지 않으며 분석법 ID는 실제 목록 연결이 확인될 때만 설정한다.
  • 같은 시험방법 코드의 DB 행이 중복되면 분석물질 대응과 실제 항목을 확인한다. 코드만 보고 임의의 행 ID를 선택하지 않는다.

원본 보존·오류 처리

항목처리 기준
원본 위치시트명·블록 식별·시료 헤더 주소·물질 헤더 주소·결과 셀 주소를 보존
원본 스냅샷셀 유형·원문 문자열·숫자 저장 문자열·표시 형식·수식/캐시 구분과 매칭 근거를 보존
직접 추출시료명·분석물질·결과는 was_extracted=true, value_source=EXTRACTED
매칭·계산DB에서 보완한 지역·좌표·분석법은 MATCHED, 순서는 SYSTEM. 미추출 필드를 매칭해도 was_extracted=false 유지
최초 상태최초 is_modified=false. 정상 값은 validation_issues=[], 오류 범위는 원문과 확인 사유를 함께 반환
파일·구조 오류암호화·손상·필수 축 식별 실패는 정상 완료로 처리하지 않음. 오류 영역 때문에 확인된 다른 결과를 삭제하지 않음

공통 처리 연결

대상처리 기준
파서 반환시료별 records[].basic + records[].results[] 1:N. 샘플은 기본 기록 100건, 각 결과 18건
매칭 계층지역·분석법·목록 연결은 공통 계층에서 수행. 파서는 원문·위치·관계를 반환하며 DB 조회·ID 발급을 수행하지 않음
저장 변환결과마다 basic을 복사한 독립 review_record·review_result 1:1 쌍 생성. 샘플은 1,800쌍
순서파서 순서를 source_record_order에 보존하고 시료 열 순서→물질 행 순서로 펼쳐 DB record_order 부여
최종 저장검토·검증 후 analysis_record·analysis_result 반영. 원문 정밀도와 원본 스냅샷 유지
