저장 및 원본 다운로드 정책.md

목적 및 적용 범위

미완료 작업의 보관, 작업 재개, 원본 다운로드 및 NAS 보관에 적용한다. 아래 내용은 적용할 정책이며 구현 완료 여부를 나타내지 않는다.

소유자 기준

업로드한 사람은 업로드 당시 로그인한 계정을 의미한다. SSO 도입 전 공용 계정을 사용하는 동안에는 같은 계정 사용자끼리 미완료 작업을 조회하고 수정할 수 있다. SSO 도입 시 개인별 계정을 기준으로 구분한다.

보관 기간 기준

미완료 작업은 마지막으로 값을 수정하고 적용한 날부터 30일간 운영 서버에 보관한다. 한 번도 수정하지 않았다면 업로드한 날부터 계산한다.

만료일은 한국 시간 기준으로 기준일에 30일을 더한 날짜로 계산하며, 만료일이 끝날 때까지 사용할 수 있다. 예를 들어 2026/10/25에 값을 수정하고 적용했다면 2026/11/24까지 사용할 수 있고, 2026/11/25 정기 정리 작업에서 삭제한다.

보관 기간 갱신

실제 값이 변경된 경우에만 30일로 갱신한다. 단순 조회, 다운로드, 변경 없는 저장은 기간을 연장하지 않는다.

추출 실패, 미지원 파일 및 추출 중 취소한 작업

추출 실패, 미지원 파일 및 추출 중 취소한 작업은 업로드일부터 30일간 운영 서버에 보관한 뒤 삭제한다. NAS로 전송하지 않는다.

검토 도중 화면을 나가거나 프로필 메뉴의 작업 종료로 업로드 화면에 돌아가는 것은 추출 중 취소와 구분한다. 해당 작업은 ‘검토 중’ 상태로 유지하며, 서버에 적용된 데이터는 보존한다. 보관 기간은 마지막 실제 값 변경일을 기준으로 계산하고, 변경 이력이 없으면 업로드일을 기준으로 계산한다. 화면을 나가는 행위만으로 보관 기간을 갱신하지 않는다.

만료 시 삭제 범위

원본 파일과 검토 데이터를 삭제하고, 업로드 기록은 유지한다. 기록에는 파일명, 업로드한 사람, 업로드 시각과 ‘보관 기간 만료’ 상태를 남긴다. 만료 삭제는 대상 작업, 파일명, 업로드 계정, 만료일, 삭제 시각 및 처리 결과를 감사 로그에 기록한다.

삭제 실행 시점

만료일까지 사용할 수 있도록 하고, 만료일 다음 날 정기 정리 작업에서 삭제한다. 정기 정리는 매일 03:00(한국 시간)에 실행하며, 해당 시각에 서버가 꺼져 있으면 다음 기동 시 실행한다.

만료일이 지난 시점부터 작업 재개, 값 수정 및 원본 다운로드를 차단한다. 정기 정리 작업이 아직 실행되지 않아 데이터가 남아 있더라도 접근을 허용하지 않는다. 화면뿐 아니라 직접 주소와 API 접근에도 동일한 기준을 적용한다.

삭제 직전에 같은 트랜잭션에서 최근 수정 여부와 최종 저장 여부를 다시 확인한다. 최종 저장과 실제 원본 파일 삭제가 동시에 진행되어 완료 원본이 유실되지 않도록 처리한다. 구체적인 동시 처리 방지 방식은 개발에서 정한다. 최종 저장을 완료한 작업은 NAS 전송 대기 또는 실패 상태라도 임시 저장 만료 대상에서 제외한다.

미완료 원본의 NAS 전송 제외

미완료 작업의 원본은 운영 서버에만 보관하고 NAS로 전송하지 않는다. 최종 저장을 완료한 작업의 원본과 최종 데이터만 NAS 보관 대상으로 한다.

NAS 원본과 최종 데이터는 무기한 보관한다. 원본은 업로드 월, 최종 CSV는 최종 저장 월을 기준으로 연도 및 월별 폴더에 분류한다. 원본 복사 후 크기와 SHA-256을 확인한 뒤 서버 사본을 삭제한다. 전송 실패 시 서버 원본을 유지하고 다음 날 재시도한다.

NAS 원본 전송 조건은 최종 저장 완료로 제한한다.

실사용 전 테스트 데이터를 초기화하는 것을 전제로 하므로, 기존 NAS 미완료 원본에 별도 30일 유예 정책은 적용하지 않는다. 초기화 범위는 서버 DB, 운영 서버 원본, NAS 원본, NAS 최종 데이터와 중복 판정 목록 및 기록, NAS DB 백업, 설치 시 보관한 DB를 포함한다. 감사 로그는 유지한다. 실제 초기화는 별도 실행 요청 후 진행한다.

DB 전체 백업에 검토 데이터가 포함되는 것은 DB 백업 보관 정책의 별도 예외이다.

업로드 이력 화면 정책

목록

완료된 작업과 본인이 업로드한 검토 중 작업을 함께 표시한다. 미완료 작업은 업로드한 사람의 목록과 상세 화면에서만 조회할 수 있으며, 다른 사용자의 미완료 작업은 표시하지 않는다. 완료된 작업은 기존 조회 범위인 로그인 사용자 전체에게 표시한다.

파일명, 업로드한 사람, 업로드 시각, 작업 상태를 표시하고, 검토 중인 작업에는 보관 만료일을 추가한다. 완료된 작업에는 만료일을 표시하지 않는다.

보관 기간이 있는 미완료 작업은 만료일 7일 전 한국 시간 00:00부터 ‘만료 예정’ 안내와 만료일을 표시한다. 예를 들어 만료일이 2026/11/24이면 2026/11/17 00:00부터 안내한다. 만료된 미완료 작업은 업로드한 사람의 이력에서 제거하지 않고 ‘보관 기간 만료’ 상태로 표시한다.

상세 및 작업 재개

검토 중인 작업의 상세 화면에 ‘이어서 검토’를 제공한다. 마지막으로 사용한 1단계 또는 2단계를 서버에 저장하고 해당 단계로 복귀한다. 3단계에서 나간 작업은 2단계로 복귀하며, 다시 검사한 뒤 3단계를 표시한다. 서버에 적용된 입력값은 유지한다. 변경 버튼, 확인 버튼 또는 일괄 변경 등으로 서버에 적용하지 않은 입력칸의 값은 복원 대상에서 제외한다. 업로드한 사람에게만 작업 재개를 허용한다.

만료된 작업은 이어서 검토와 원본 다운로드를 사용할 수 없다.

실패 및 취소 작업

추출 실패, 미지원, 추출 중 취소한 작업도 업로드한 사람의 이력에 상태와 만료일을 표시한다. 검토 데이터가 없는 작업에는 ‘이어서 검토’를 제공하지 않는다. 원본 다운로드는 업로드한 사람에게 보관 기간 내 허용한다.

상태 명칭

기본 상태는 ‘최종 저장 완료’, ‘검토 중’, ‘보관 기간 만료’, ‘추출 실패’, ‘지원하지 않는 파일’, ‘취소됨’으로 표시한다. ‘취소됨’은 추출 중 취소에 사용한다.

‘만료 예정’은 기본 상태를 대체하지 않는 보조 표시로 제공한다. 예: ‘검토 중 / 만료 예정’, ‘추출 실패 / 만료 예정’.

동일 파일명 확인 팝업

본인 계정의 작업과 최종 저장 완료 작업은 기존 기준으로 표시한다. 다른 계정의 검토 중 작업은 중복 확인 건수에 포함하되, 목록에는 ‘다른 사용자 검토 중 N건’으로만 표시한다. 해당 작업의 업로드 계정, 업로드 시각 등 상세 정보와 접근 링크는 제공하지 않는다.

이 건수 안내는 다른 계정의 미완료 작업 비공개 원칙에 대한 예외이며, 작업 조회나 수정 및 다운로드 권한을 부여하지 않는다.

검토 중 작업의 수정 권한

미완료 작업은 업로드한 사람만 조회할 수 있다. 검토 중이며 보관 기간이 지나지 않은 작업은 업로드한 사람만 이어서 수정할 수 있다. 목록과 버튼 표시뿐 아니라 직접 주소와 API로 접근하는 경우에도 동일한 권한 및 만료 기준을 적용한다.

작업 저장 버튼

버튼 명칭은 ‘작업 저장’으로 유지한다. 되돌리기 기준점을 기록하는 기능이며, 별도의 임시 저장 버튼은 제공하지 않는다.

원본 다운로드 권한

미완료 작업의 원본은 업로드한 사람만 다운로드할 수 있다. 완료된 작업의 원본은 해당 업로드 이력을 조회할 권한이 있는 사용자에게 제공한다. 완료 이력 조회 권한은 로그인 사용자 전체에게 부여한다.

원본 다운로드 위치와 제공 방식

업로드 이력 상세 화면에 원본 다운로드를 제공한다. ‘원본 파일 다운로드’ 버튼 위치에서 원본 다운로드를 제공하며 엑셀 내보내기는 제공하지 않는다.

미완료 작업은 운영 서버의 원본을 제공한다. 완료된 작업은 원본의 현재 위치에 따라 운영 서버 또는 NAS에서 제공한다.

다운로드 파일명은 업로드 당시 파일명과 확장자로 제공한다. 운영 서버와 NAS에서는 파일 ID 기반 저장 방식을 유지한다.

완료된 원본은 NAS 저장 성공이 확인되기 전까지 운영 서버에서 삭제하지 않는다. 전송 실패 시 서버 원본을 유지한다. 미완료 원본은 NAS 전송 없이 30일 만료 기준으로 삭제한다.

다운로드 실패 안내

  • 권한 없음: ‘이 작업을 볼 수 있는 권한이 없습니다.’
  • 만료된 작업 재개: ‘보관 기간이 만료되어 이어서 검토할 수 없습니다.’
  • NAS 연결 장애: ‘원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요.’
  • 파일 부재: ‘원본 파일을 찾을 수 없습니다.’
  • 보관 기간 만료: ‘보관 기간이 만료되어 원본을 다운로드할 수 없습니다.’

NAS 응답 대기 시간은 10초를 기준으로 검토하되, 실제 운영 환경에 맞춰 개발에서 조정한다.

엑셀 내보내기와 다운로드 기록

엑셀 내보내기를 제공하지 않는다. 추출 데이터 저장과 원본 다운로드를 우선하며, SQL 추출은 별도 추가 개발 대상으로 둔다. NAS 보관용 CSV(UTF-8)는 DB 전체 48열을 유지하며 사용자용 엑셀 내보내기와 구분한다.

원본 다운로드 시 사용자, 다운로드 시각, 대상 파일을 감사 로그에 기록한다.

DB 백업 보관

DB 백업은 기존처럼 7일간 유지한다. 미완료 작업을 삭제한 뒤에도 이전 백업에 검토 데이터가 최대 7일 더 남을 수 있으며, 복구 목적의 예외로 허용한다.

백업 복원 시 만료된 작업이 다시 활성화되지 않도록 처리한다. 미완료 원본 파일을 NAS에 별도 보관하는 것은 허용하지 않는다.

최종 데이터 NAS 보관 시작일

RIST의 실사용 시작일을 기준으로 NAS_FINAL_SINCE를 설정한다. 최종 데이터 NAS 보관 기능은 실사용 전에 활성화해야 한다.

테스트 데이터 초기화 후 시작하는 구조이며, 정확한 실사용 시작일은 별도 확정이 필요하다.
