상황판정 및 처리

헤더 없는 다음 페이지같은 보고서, 직전 미종료 블록과 일치하는 열 개수·정렬, 이어지는 시료 행이 확인되면 직전 물질명·단위를 상속. 새 헤더 또는 보고서가 시작되면 상속 중단
연속 근거 부족직전 블록의 물질 열과 다음 페이지 값의 대응이 유일하지 않으면 결과 원문·위치를 보존하고 확인 필요. 숫자 개수만으로 상속하지 않음
표 하단 가로선해당 블록의 경계로 사용하되 보고서 종료로 단정하지 않음. 뒤에 새 물질 헤더·연속 시료 행이 있는지 확인

제외반복 머리글·주소·연락처·양식번호·서명·발행일·직인은 결과에서 제외. 인쇄 총 페이지 수는 추출 종료 기준으로 사용하지 않음

열·행 경계헤더 중심·주변 열 간격·글자 좌표로 경계 계산. 숫자가 시료명에 붙어 보이더라도 전체 줄의 공백 개수로 분리하지 않음

페이지 상속헤더 없는 연속 행은 확인된 직전 블록의 물질·단위에 연결. 원본 위치에 상속한 헤더의 페이지·범위도 함께 보존

분석법명확한 파일 추출 분석법을 우선하고, 없을 때 분석물질에 대응하는 분석법 매칭을 적용한다. 샘플에는 명확한 분석법 기재가 없고 금속 원소는 현재 매칭표에 대응하지 않으므로 분석법 표시값·ID·시험방법 코드는 NULL로 두고 검토 화면에서 보완한다. 고시번호는 시험방법 코드로 대체하지 않음
다른 파일의 시험방법명확하게 추출한 분석법을 우선 적용하고, 없을 때 분석물질의 DB 매칭값으로 보완한다. 명확한 추출값은 DB 값이 다르거나 매칭되지 않아도 덮어쓰거나 NULL로 바꾸지 않는다. 불명확한 원문은 스냅샷과 확인 사유를 보존하되 확정 추출값으로 사용하지 않는다. DB 보완도 대응이 없거나 불명확하면 미확정 업무값은 NULL로 유지한다. 분석법 표시값·시험방법 코드는 같은 방법에 대응해야 하며, 분석법 ID는 실제 적용한 방법과 일치하는 DB 항목에만 연결한다. 다른 방법의 ID를 붙이지 않는다. 직접 추출은 EXTRACTED, DB 보완은 MATCHED로 구분하고 원문·위치·매칭 근거를 보존한다.
목록 ID기관·물질·단위·지점 등 실제 목록 항목에 연결된 근거가 있을 때만 설정. 표시값을 확보했다고 ID를 만들지 않음
