화면 목업 뷰어사용 안내

화면 탐색부터 코드 복사까지

화면을 살펴보고, 필요한 내용을 복사하세요.

목업과 설명을 함께 확인하고, 텍스트나 화면 코드를 가져갈 수 있습니다.

01

페이지와 패널

왼쪽 목록에서 화면을 선택합니다.
하단 화살표는 현재 목록 안에서만 이동합니다.

왼쪽 패널은 <, 오른쪽 패널은 >로 숨깁니다.
가장자리에 남은 반대 방향 화살표로 다시 엽니다.

02

확대와 화면 이동

핀치로 목업만 확대하고, 스크롤 또는
Space + 드래그로 긴 화면을 이동합니다.

너비 맞춤을 누르면 너비에 맞춰 맨 위로 이동합니다.

03

설명과 텍스트 복사

번호 표시로 화면 번호를 켜고 끕니다.
번호를 누르면 오른쪽 설명이 강조되고,
숨겨진 설명 패널도 열립니다.

텍스트를 드래그해 선택하고 ⌘C 또는 Ctrl+C로 복사합니다.

04

화면 코드 복사

코드 보기 → 복사 대상 선택 → 코드 복사
페이지 전체 또는 등록된 컴포넌트의 HTML과 CSS를 복사합니다.

컴포넌트 선택으로 화면의 영역을 직접 지정할 수 있습니다.
