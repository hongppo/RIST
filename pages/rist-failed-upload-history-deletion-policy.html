실패 파일 업로드 이력 삭제 정책

적용 범위와 권한

단일 파일과 여러 파일 업로드에 동일하게 적용한다. 삭제 대상은 ‘추출 실패’ 또는 ‘지원하지 않는 파일’ 상태의 개별 파일 이력이며 업로드 당시 로그인한 계정만 삭제할 수 있다.

상태이력 삭제 제공
추출 실패업로드 계정에 제공
지원하지 않는 파일업로드 계정에 제공
검토 중제공하지 않음
최종 저장 완료제공하지 않음
보관 기간 만료제공하지 않음
취소됨제공하지 않음

삭제 동작

항목동작
진입대상 파일의 이력 상세 하단에 ‘이력 삭제’ 제공
확인 문구이 이력을 삭제하시겠습니까? 삭제하면 목록에서 다시 확인할 수 없습니다.
확인 팝업 버튼‘취소’, ‘이력 삭제’
취소삭제하지 않고 이력 상세 유지
이력 삭제해당 이력을 사용자 목록과 상세에서 숨김
직접 접근삭제한 이력의 직접 주소로 재진입해도 상세를 노출하지 않음
원본 다운로드삭제 후 일반 사용자에게 해당 원본의 다운로드 경로를 제공하지 않음

삭제 권한과 대상 상태는 직접 주소 및 API 접근에도 동일하게 적용한다.

여러 파일 업로드의 삭제 범위

해당 실패 또는 미지원 개별 파일의 이력만 숨긴다. 정상 파일, 유형 그룹 및 업로드 묶음 전체를 삭제하지 않는다.

혼합 묶음의 사용자 표시 목록에서는 숨긴 파일과 해당 파일의 상세 링크를 제거한다. 실제 업로드 총수 기록은 변경하지 않는다. 원래 업로드 총수와 표시 목록 수가 다르면 ‘삭제된 이력을 제외한 목록입니다.’로 안내할 수 있다.

원본 보관과 내부 기록

이력 삭제는 사용자 화면에서 숨기는 동작이며 물리 데이터 삭제가 아니다. 내부 처리 기록은 유지한다.

항목정책
운영 서버 원본기존 업로드일부터 30일 보관 및 만료 정리 기준 유지
보관 기간이력 삭제로 갱신하지 않음
NAS미완료 원본 전송 금지 유지
만료 정리사용자 화면에서 숨겨진 이력도 원본 만료 정리 대상에서 제외하지 않음
내부 기록사용자 목록에서 숨겨도 시스템의 업로드 및 처리 기록 유지

보관 및 정리 기준은 저장 및 원본 다운로드 정책과 그룹 저장 및 원본 다운로드 정책을 따른다.
