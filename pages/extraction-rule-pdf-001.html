표 연결 및 행 처리

순서대상처리
1상세 시험표시험방법 열의 셀을 식별. 판정요원의 개별 감지값·O/X 판정·최대·최소 제외값은 최종 결과로 생성하지 않음
2시험방법 병합 셀셀의 실제 병합 범위와 같은 보고서 내 적용 범위를 확인해 한 번 읽음. 파서가 반환한 후속 null을 다른 보고서의 값으로 채우지 않음
3최종 요약표Sample No.와 Dilution multiple을 포함한 제목 조합으로 열 식별. 헤더·주석·빈 행 제외
4시료 연결요약표의 시료 식별값을 기본 정보 시료명과 정규화 비교. 일치하거나 표 구조상 같은 시료를 가리키는 병합 셀인 경우 연결. 불일치·모호함은 연결 오류
5결과 행 생성소속 시료가 확정된 데이터 행마다 결과 1건. 결과 셀이 비어 있거나 비수치여도 행 유지. result_order는 보고서 안에서 1부터 연속 부여
대상처리 기준
여러 결과 행같은 보고서·시료에 속한 별도 원본 행은 각각 유지. 값이 같다는 이유로 합산·중복 삭제하지 않음
여러 시료 행기본 정보에 대응하는 시료를 유일하게 결정할 수 없는 행을 현재 기록에 붙이지 않음. 별도 기본 정보를 추정 생성하지 않고 확인 필요로 반환
페이지에 걸친 표보고서 연결이 확정되고 열 제목·정렬이 이어질 때만 연결. 반복 제목은 결과 행에서 제외
시험방법 연결보고서 안에 시험방법 영역이 하나이고 최종 요약표 전체에 대응하면 공통 적용. 영역이 여러 개면 시료·표 묶음으로 유일하게 연결되는 경우만 적용
결과 선택최종 값은 Dilution multiple의 셀에서만 추출. 허용기준·판정결과·개별 감지값으로 대체하거나 재계산하지 않음

분석법 적용 우선순위

명확하게 추출한 분석법을 우선 적용하고, 없을 때 분석물질의 DB 매칭값으로 보완한다. 명확한 추출값은 DB 값이 다르거나 매칭되지 않아도 덮어쓰거나 NULL로 바꾸지 않는다. 불명확한 원문은 스냅샷과 확인 사유를 보존하되 확정 추출값으로 사용하지 않는다. DB 보완도 대응이 없거나 불명확하면 미확정 업무값은 NULL로 유지한다. 분석법 표시값·시험방법 코드는 같은 방법에 대응해야 하며, 분석법 ID는 실제 적용한 방법과 일치하는 DB 항목에만 연결한다. 다른 방법의 ID를 붙이지 않는다. 직접 추출은 EXTRACTED, DB 보완은 MATCHED로 구분하고 원문·위치·매칭 근거를 보존한다.
