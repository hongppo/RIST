유형별 채취법 매칭

명확하게 직접 추출한 채취법은 우선 유지한다. 파일 유형 판별 후 아래 채취법 매칭으로 보완한다.

파일 유형추가 조건시험방법 코드채취법명처리
CSV-001없음-테들러백 채취동일 명칭의 DB 항목 연결
CSV-002없음-고정측정동일 명칭의 DB 항목 연결
PDF-001없음-테들러백 채취동일 명칭의 DB 항목 연결
PDF-001-a없음-테들러백 채취동일 명칭의 DB 항목 연결
PDF-002없음-테들러백 채취동일 명칭의 DB 항목 연결

그 외 유형없음추가 매칭 없음. 기존 값 유지

추가 매칭이 없다는 것은 기존 값을 삭제하거나 공란으로 변경한다는 의미가 아니다.

EXCEL-001 파일명 조건

EXCEL-001로 판별된 파일에 한해 원본 파일명에 VOCs 또는 PAHs 문자열이 포함되는지 확인한다. 지정 문자열 그대로 비교하며 대소문자 변형이나 유사어로 확대하지 않는다. 파일명으로 파일 유형을 판별하지 않으며 CSV 등 다른 유형에는 적용하지 않는다.

원본 파일명 조건처리
VOCs만 포함유형별 표의 VOCs 규칙 적용
PAHs만 포함유형별 표의 PAHs 규칙 적용
VOCs와 PAHs 모두 포함이 추가 규칙으로 유일값 확정 불가. 임의 선택하지 않고 기존 값 유지 및 확인 대상
둘 다 미포함이 추가 규칙으로 유일값 확정 불가. 기존 값 유지 및 확인 대상

DB 연결

  • 기준 목록은 채취법 DB이다.
  • 시험방법 코드·표시명과 실제 DB ID는 구분한다. 동일 항목에 연결되는 경우에만 실제 ID를 사용한다.
  • 테들러백 채취와 고정측정의 코드 -는 DB 원문 문자이다. 공통 코드 -만으로 두 항목을 동일시하지 않으며 명칭이 일치하는 항목에 연결한다.
