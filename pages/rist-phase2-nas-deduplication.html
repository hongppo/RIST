보관 대상과 범위

구분정책
비교 대상최종 저장이 완료된 업로드 건의 최종 검토 데이터 전체
별도 대상DB 파일 전체를 보관하는 복구용 백업과 분리
기존 백업기존 전체 DB 복구 백업은 계속 유지
동일 판단 단위일부 셀·일부 행이 아닌 업로드 건의 전체 데이터
생략 범위신규 중복 데이터의 NAS 보관만 생략
보존업무 DB 삭제·병합, 원본 파일 삭제를 의미하지 않음

검사 흐름

순서판단
1최종 저장 완료 건을 대상으로 확인
2전체 행 수가 같은 기존 보관본·배치 내 신규 후보 선별
3행별 분석물질·결과 쌍을 우선 비교
4분석물질·결과·단위·채취일자·위도·경도 6개 필수 항목의 전체 행 배열 비교
5필수값 전체가 같아도 선택값이 다르면 자동 생략하지 않고 별도 확인
6동일한 기존 보관본이 있으면 기존 보관본 유지, 신규 중복 NAS 보관 생략
7배치 내 신규끼리 같으면 먼저 최종 저장된 건을 유지
8처리건·유지건·비교 기준·처리 일시·판정 결과를 기록

행 순서는 무시하지만 동일한 행이 반복된 횟수는 보존합니다. 단순 집합으로 중복 행을 제거한 뒤 비교하지 않습니다. 필수 항목 일부가 다르거나 일부 행만 겹치는 경우는 전체 중복이 아닙니다.

비교 사례

사례비교 내용결과
기존 보관본 동일기존 A와 신규 B가 각각 171행. 필수 전체 배열·선택값 동일A 유지, B의 신규 NAS 보관 생략
신규 배치끼리 동일신규 C·D가 전체 동일. C가 먼저 최종 저장됨C 유지, D의 신규 NAS 보관 생략
전체 행 수 다름A 171행, E 170행전체 중복 아님
필수값 일부 다름같은 171행에서 한 행의 단위 또는 좌표가 다름전체 중복 아님
일부 행만 겹침171행 중 85행만 동일전체 중복 아님
반복 횟수 다름각 3행: X·X·Y와 X·Y·Y전체 중복 아님
선택값 다름필수 6개 전체는 같으나 담당자 등 선택값이 다름자동 생략하지 않고 별도 확인
비교 실패후보를 읽지 못하거나 비교 처리가 실패중복으로 확정하지 않음. 기록 후 재처리 대상으로 관리

기록과 실패 처리

기록내용
처리건보관 판단 대상 업로드 건
유지건동일 판단 시 보존할 기존 또는 신규 건
기준비교한 전체 행 수·필수 항목·선택값 확인 기준
일시비교·판정 처리 일시
결과신규 보관, 중복 보관 생략, 별도 확인, 비교 실패와 사유

비교 실패는 중복의 증거가 아닙니다. 실패한 건을 중복으로 처리하거나 원본·업무 DB를 삭제하지 않습니다. 재처리 대상과 실패 내용을 남깁니다.

확정 전 확인 필요

  • 동시에 최종 저장되어 순서가 같은 건의 유지 기준
  • 값 표준화·표현 차이를 동일하게 볼지에 대한 기준
  • 선택값 차이가 있는 건의 별도 확인 절차
  • 비교 실패의 재처리 주기·재시도 운영 기준
