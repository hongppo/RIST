적용 범위

총괄표는 분석물질, 단위, 분석법, 채취법, 지역과 좌표의 값 확보 및 매칭 기준을 정의한다. 셀, 행, 시트의 구조와 결과 해석, BASE 및 날짜는 유형별 상세 규칙을 따른다.

유형별 세부 기준

유형추출 및 매칭 범위
CSV-001결과 구간 물질명 전체와 CAS 원문 유지. 선택한 시작 구간명 마지막 괄호에서 단위 추출. RIST-E-001은 SIFT-MS 테들러백 분석
CSV-002물질 헤더 직접 추출. Total Concentration과 기상 항목 제외. RIST-E-003은 SIFT-MS 고정형 측정. 유지한 측정행 좌표를 같은 행 결과에만 연결
CSV-003해당 배치의 분석물질 열 직접 추출. 시료 열별 지역 매칭. 파일명 조건 불충족 시 분석법을 임의 확정하지 않고 사용자 선택으로 보완 가능
PDF-001시험방법 셀의 코드와 방법명 직접 추출. 불명확한 부분은 확인 사유 유지 및 사용자 보완
PDF-001-a시험방법 셀에서 코드만 확인되면 코드만 유지. 없는 방법명 추정 금지
PDF-002시험항목 물질명과 결과행에 대응하는 단위 병합 셀 직접 추출. 괄호 표기 유지. 지정악취 매칭 미대응 또는 불명확은 사용자 보완
PDF-003결과 블록의 물질 헤더와 같은 열 단위 직접 추출. mg 유지, ug는 μg로 표기 정규화. KBSI 내부시험법은 동일 명칭 목록 항목 연결 대상
EXCEL-001결과 행렬의 물질명 열 직접 추출. 시료 열별 지역 매칭. VOCs만 포함하거나 파일명 조건이 불충족이면 채취법 자동 보완 없음
EXCEL-002Component 물질명 전체와 같은 행 Unit 직접 추출. 산화물의 원소 변환 및 wt% 고정 금지. XRF 분석은 동일 명칭 목록 항목 연결 대상
EXCEL-003실제 물질 헤더와 결과표 단위 라벨 또는 입력칸 직접 추출. 분석 방법 전체 유지. ICP 분석은 동일 명칭 목록 항목 연결 대상. 공장명만으로 임의 좌표 생성 금지
EXCEL-003-a실제 물질 헤더와 결과표의 명시 단위 직접 추출. Cr6+ 고정 생성 금지. 시험장비(방법) 전체 유지. RIST-E-004는 대기 중 6가 크롬 시료채취 및 분석
EXCEL-003-b실제 물질 결과 헤더와 결과표 명시 단위 직접 추출. 참고 열과 구분. 시험장비(방법) 전체 유지. ES 01803.1은 환경대기 중 알데하이드류 - 고성능액체크로마토그래피법

공통 지역 매칭은 각 시료에만 적용한다. 미대응 항목은 자동 보완하지 않으며 필요한 경우 목록 선택 또는 입력으로 보완한다.

규칙 선택 순서와 3차 적용 기준

  1. 기본 유형과 하위유형의 구체적인 구조 조건을 모두 확인하여 최종 유형 후보를 판별한다.
  2. 해당 유형의 추출 위치와 적용 범위에서 명확한 값을 읽는다.
  3. 유형 고정값, 미추출 시 기본값 및 조건부 매칭을 아래 적용 기준에 따라 구분한다.
  4. 실제 동일한 DB 항목이 유일하게 확인되는 값만 해당 ID에 연결한다.
  5. 남은 값과 확인 사유를 표시하고 필수 여부에 따라 사용자 선택 또는 입력으로 보완한다.
항목적용 기준
최종 유형 후보기본 유형과 하위유형의 구체적인 판별 조건으로 유일한 후보를 확정. 판별 완료 후 독립적인 최종 후보가 2개 이상이면 중단하고 판별 불가 안내. 첫 매치 선택이나 하위유형 무조건 우선 적용 금지
일반 우선순위명확한 직접 추출값 우선. 유형별 보완은 직접 추출값이 없는 항목에만 적용. 매칭 실패로 유효한 추출값을 지우지 않음
PDF-001과 PDF-001-a유형 판별 후 물질명 복합악취와 단위 OU를 각각의 유형 고정값으로 적용. 직접 추출로 표시하지 않음
PDF-002 지정악취지정악취 22종 표의 시험방법 코드를 PDF 기재 여부와 개정판 차이에 관계없이 적용. 시험방법 전체 원문과 고시정보 별도 유지
지정악취 적용 한계PDF-002 지정악취 이외에는 물질명이 같아도 해당 표를 적용하지 않음. Toluene이라는 이유로 대기 VOCs에 ES 09307.b 적용 금지
유형별 분석법지정악취 범위 밖에서는 총괄표의 유형별 기본값과 파일명 조건 적용. 포괄적인 ‘분석법 매칭’ 링크를 지정악취 표의 전 유형 적용 근거로 사용하지 않음
CSV-001과 CSV-002각각 RIST-E-001과 RIST-E-003 보완. 추출 단계의 초기 NULL은 유형별 매칭 후에도 반드시 NULL을 유지하라는 의미가 아님
PDF-003과 EXCEL-002 및 EXCEL-003명확한 직접 분석법이 없으면 각각 KBSI 내부시험법, XRF 분석, ICP 분석으로 보완. 물질명이나 장비명에서 임의 유추하는 규칙이 아닌 판별 유형의 지정 기본값
EXCEL-003 복합 분석법‘ICP 분석 및 Fe 적정’처럼 명확한 직접 추출값은 전체 유지. ICP 분석 기본값으로 축약하거나 대체하지 않음
EXCEL-001구조 판별과 파일명 보완은 별개. 지정 파일명 조건이 맞으면 해당 결과의 분석법을 보완하며 물질별 지정악취 표를 적용하지 않음

이 총괄표의 3차 적용 기준과 상세 문서의 포괄적인 매칭 설명이 다른 경우, 위 항목별 범위와 우선순위를 적용한다. 추출 셀, 행과 시트의 구조, 결과 해석은 각 유형 상세 규칙을 따른다.

지역과 좌표

조건적용 기준
명확한 원본 좌표직접 추출값 우선. 이름이 DB 지점과 일치해도 추출 좌표를 DB 값으로 덮어쓰지 않음
직접 좌표가 없는 시료지역 매칭의 정식명, 지역 부분 명칭, 괄호 명칭 및 등록 약자 형식으로 DB 후보 확인
유일한 DB 지점같은 DB 행의 지점명과 좌표를 해당 시료의 결과에만 MATCHED로 연결
미대응 또는 서로 다른 후보임의 지점 선택이나 좌표 생성 없이 미확정 항목 NULL 및 사용자 보완. 유효한 직접 추출값은 유지
EXCEL-003 공장 위치공통 규칙으로 등록 지점이 유일하게 확인되면 DB 좌표 연결 가능. ‘시료명에서 좌표를 만들지 않음’은 임의 좌표 생성 금지이며 등록 DB 매칭 금지가 아님. 미등록 공장 위치는 선택 또는 직접 입력
CSV-002유지한 측정행의 좌표를 해당 행 결과에만 연결. 첫 행 좌표 복제 및 제외한 행의 좌표 보완 금지

구분조건 예시처리 범위
파일구조 판별 불가, 기본 유형과 하위유형 판별 완료 후 독립적인 최종 후보 2개 이상, 시료와 물질 축 미확정먼저 맞은 유형 선택 금지. 판별 불가 사유를 안내하고 정상 유형으로 추출 진행하지 않음. 파일명 보완 실패와 구분

시트 및 보고서 일부 실패의 공통 처리

지원되는 Excel 유형의 시트와 PDF 유형의 개별 보고서를 처리 단위로 한다. 여러 보고서가 포함된 PDF는 지원되는 유형에서 독립 보고서의 경계와 결과 소속을 명확하게 식별할 수 있는 경우에 적용한다.

조건처리 기준
정상 단위 분리 가능단위의 독립성, 경계와 결과 소속이 명확하고 실패 단위에 대한 데이터 의존성이 없으면 정상 시트 또는 보고서의 추출 결과 유지
일부 단위 실패실패 시트명 또는 보고서 식별명과 사유 안내. 보고서 식별명이 없으면 페이지 범위 등 확인 가능한 식별값 사용
파일 결과 표시정상 결과가 있어도 일부 실패를 구분하여 안내하고 파일 전체를 정상 완료로 표시하지 않음. 실패 단위를 조용히 제외하지 않음
분리 불가경계, 결과 소속 또는 데이터 의존성 때문에 정상 부분을 확실하게 분리할 수 없으면 파일 전체 추출 중단
모든 단위 실패성공 결과가 없는 것으로 처리하고 각 실패 단위와 사유 안내
행, 셀 또는 보완 실패개별 행, 셀이나 매칭 보완 실패만으로 시트 또는 보고서 전체 실패로 확대하지 않음. 해당 위치의 원문과 확인 사유 및 유형별 세부 처리 기준 유지
원본 연결유지한 결과의 원본 시트 또는 보고서와 페이지, 행, 셀 등 출처 연결 유지. 실패 단위의 값을 정상 단위에 전파하지 않음

유형별로 명시된 추출 제외 범위와 고유한 행 및 셀 처리 예외는 해당 상세 규칙을 따른다.
