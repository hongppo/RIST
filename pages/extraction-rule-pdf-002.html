시작·연속·종료 판정

단계판정 근거처리
시작보고서 제목·기본 정보와 시험결과표 구조가 함께 확인됨기본 정보와 보고서 식별값을 보존하고 결과표 읽기 시작
다음 결과 페이지같은 열 구조, 결과값 하위 시료명, 앞 페이지와 이어지는 항목 연번·배치가 확인됨기존 보고서의 결과표로 연결. 페이지가 바뀌어도 result_order를 초기화하지 않음
식별값 대조반복되는 성적서번호·시료명·채취일자·시험기간이 있으면 앞 보고서와 대조충돌 시 자동 연결 금지. 누락을 일치나 변경으로 간주하지 않음
연속 근거다음 페이지에 기본 정보가 반복되지 않아도 결과값 하위 시료명 일치와 동일 표 구조·연번 연속으로 연결 가능머리글·제목·전체 페이지 수만으로 연결하지 않음. 연번의 누락·중복·역행은 원문을 보존하고 검증 항목 기록
결과표 끝결과표 뒤 비고, 확인, 시험자·기술책임자, 발행일·발행기관 등 마감 영역으로 전환마감 영역의 숫자·성명을 결과 행으로 만들지 않음. 서명 유무만으로 종료를 단정하지 않고 다음 영역 확인
종료 확정마감 영역 뒤 연속 결과표가 없고 파일 끝이거나, 다음 영역이 시험조건 제목과 장비·조건표로 전환직전 연속 결과표까지 추출. 이후 페이지의 시험조건·첨부 자료는 추출 대상에서 제외
종료 근거 부족다음 영역이 결과표인지 첨부인지 식별되지 않거나 서로 충돌하는 보고서가 등장확정된 행과 불명확 구간을 구분해 반환. 임의의 페이지 번호·행 개수로 자르지 않음
  • 시험조건표의 GC/MS, HPLC, GC/FPD, UV-vis, GC/NPD, GC/FID, Column, Temperature, Flow Rate 등은 장비·조건 구조를 확인하는 보조 근거다. 키워드 하나가 결과표 안에 있다고 종료하지 않는다.
  • 같은 성적서번호·시험성적서 제목이 반복되어도 시험조건 영역이면 결과 연속 페이지로 연결하지 않는다.
  • 인쇄된 페이지 (p) / (총 n)은 첨부까지 포함할 수 있다. 총 n을 결과 페이지 수로 사용하지 않는다.
  • 표가 페이지 하단에서 끝났거나 특정 연번에 도달했다는 이유만으로 종료하지 않는다. 결과 영역 뒤 제외 영역이 확인되면 이후 페이지에서 결과 수치를 다시 찾지 않는다.
  • 별도 보고서의 시작처럼 보이는 영역을 앞 보고서에 합치지 않는다. 소속·경계가 불명확한 구간은 확인 대상으로 보존한다.

분석법 매칭 가이드

PDF-002 지정악취 22종은 아래 확정 시험방법 코드를 적용한다. 이 유형은 명확한 파일 추출값을 우선하는 공통 원칙의 예외로, 아래 DB 매칭값을 우선 적용한다. 실제 적용한 방법과 일치하는 DB ID만 연결하며 다른 방법의 ID를 붙이지 않는다. 분석법 표시값은 코드 + 공백 + 확정 분석법명으로 작성하며, 표에 매칭되지 않거나 대응이 불명확한 항목만 NULL로 처리한다.

명백한 오타는 대응이 유일할 때 매칭한다. 이 표의 코드는 PDF 기재 여부·개정판 차이와 관계없이 적용하되, PDF 원문과 구분한 매칭값으로 기록한다. 고시번호는 시험방법 코드로 대체하지 않으며 원문·적용 범위가 확인된 값만 별도로 보존한다.
