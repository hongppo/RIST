파일 읽기 및 유형 판별

항목처리 기준
시트 순회이 유형으로 판별된 워크북은 첫 번째 시트를 시트명과 관계없이 추출에서 제외하고 제외 상태를 기록. 두 번째 시트부터 대상 구조를 확인. 나머지 시트 수와 이름은 고정하지 않음
헤더 탐지시료명과 채취일 등 시간 하위 헤더, 물질 헤더와 농도 단위의 상하 관계를 함께 확인. VOCs처럼 헤더가 한 행 아래인 배치도 허용
결과 블록지정 최종 농도 블록을 식별. 단순히 가장 오른쪽 숫자 열이나 마지막 단위 블록을 선택하지 않음
병합병합 헤더는 좌상단 값과 실제 적용 물질 범위를 함께 해석. 병합 끝을 곧바로 결과 끝으로 사용하지 않음
참고자료 범례항목구분 참고자료에만 해당. 주황은 시료명, 초록은 채취일, 진한 남색은 물질, 연한 파랑은 결과, 연한 주황은 단위. 참고자료 해석 시 RGB 또는 테마색과 tint를 구분하며 원본에 범례가 있다고 간주하지 않음
유형 판별 근거헤더 역할, 시료 축, 물질 축과 최종 농도 블록의 관계로 판별. 참고자료의 색상 범례는 원본 판별 조건이 아니며 색상이나 특정 셀 주소를 필수 조건으로 삼지 않음. 관계가 불명확하면 확인 처리
판별 불가시료 축과 물질 축 또는 최종 결과 블록을 유일하게 식별하지 못하면 추측 추출하지 않음

  • Excel 날짜 직렬값은 워크북 날짜 체계와 표시 형식으로 해석한다. 월일만 표시되어도 내부 날짜의 연도가 확인되면 사용한다.

  • 분석일은 채취일이나 채취종료일로 생성하지 않는다.

결과 행과 값 처리

항목규칙
데이터 행왼쪽 시료명과 채취일 아래의 시료 행을 최종 농도에 연결. 동일 이름의 별도 행도 출처를 유지
미측정 입력미측정 결과는 최종 농도 셀을 빈칸으로 제공. 빈 교차 셀은 결과를 생성하지 않음. 모든 최종 결과가 빈 행은 결과 기록을 생성하지 않음
실제 0측정 결과 0은 정상 결과로 유지. 0의 개수나 크기로 행을 제외하지 않음
수식 0 예외원측정 입력이 비어 있으나 계산식이 0을 반환하는 미정비 파일은 실제 0 또는 미측정으로 단정하지 않음. 원문, 수식, 캐시와 확인 사유를 남기며 정상 측정 결과로 확정하지 않음
오류#DIV/0!, #VALUE! 등은 오류 상태와 원문을 유지하고 숫자 결과는 NULL. 오류가 있는 시료를 정상 완료로 표시하지 않음
비수치n.d, N.D 및 부등호는 원문과 의미 유지, 수치 NULL. 결과 없음으로 오인하거나 검출한계 또는 0으로 대체하지 않음
종료시료 데이터 영역과 AM, Min, Max, GM, 월별 통계 영역을 구분. 첫 빈 행만으로 종료하지 않으며 집계행을 시료로 생성하지 않음
수식저장된 유효 계산 결과와 표시 형식을 사용. 수식과 캐시를 별도 보존. 캐시 부재 또는 오류는 확인 처리. 외부 연결 및 재계산으로 보완하지 않음
결과 표시엑셀 표시값을 결과로 사용. clean_number는 지수 대신 일반 소수 표기로 출력. 추가 고정 소수 자릿수나 반올림 기준 없음
원문내부 숫자 문자열, 수식, 캐시, 셀 유형, 원래 표시 문자열과 서식을 원본 정보에 보존. 결과 표시값으로 덮어쓰지 않음
단위ug/m3 등 복합단위는 단위 목록과 공통 단위 정규화 정책을 적용. ug 단독 표기와 혼동하지 않음. 원문 보존, 미확정 동등성이나 ID 추정 금지. 임의 수치 환산 금지

미추출 항목 및 매칭

항목처리
구분, 매체, 담당자, 분석기관파일 직접 추출값 없음. 목록 선택 또는 입력
분석일자직접 추출값 없음. 필요한 경우 입력
위치와 좌표파일 직접 추출값 없음. 지역 매칭의 실제 대응 근거가 있을 때만 매칭하고 그 외 목록 선택 또는 입력
BASE, 채취법목록 선택 또는 입력. 안내에 적힌 값이나 공란, x를 고정 업무값으로 사용하지 않음
분석법명확한 직접 추출값 우선. 없으면 VOCs 시트 결과에 ES 01804.2a, PAHs 시트 결과에 ES 01802.1a를 MATCHED로 보완. 파일 전체 적용 및 지정악취 물질별 매칭 금지. 다른 계열 또는 불명확한 시트는 자동 매칭하지 않음
목록 ID실제 목록 항목이 유일하게 확인될 때만 연결. 임의 ID 생성 금지

분석법은 파일 유형별 분석법 매칭을 따른다. 첫 시트 제외 기준을 유지하며 원문을 보존한다. 실제 동일한 DB 항목이 확인될 때만 ID를 연결하고 코드와 DB 분석법명을 함께 표시한다. 자동추출 불가 안내의 예시 코드는 직접 추출값으로 간주하지 않는다.

출처와 저장

항목규칙
파서 반환시트와 시료 행별 records[].basic 및 results[], issues 반환. 최종 농도 빈칸은 결과 제외
출처직접 읽은 값 EXTRACTED, 실제 규칙 또는 DB 매칭값 MATCHED, 순서 및 정밀도 SYSTEM으로 구분
원본 위치파일, 시트, 시료 행, 헤더 셀, 결과 셀, 병합 범위와 예외 적용 근거 기록
저장결과마다 기본 정보와 결과의 독립 저장 쌍 구성. 시트 순서, 시료 행 순서, 물질 열 순서 유지
검증 범위기준 원본에도 청림중금속 BU3의 #DIV/0!, 청림PAHs G3 공란과 AA3 수식 0, Aldehyde B3의 연도 없는 문자열이 존재. 기존 오류, 수식 0 및 날짜 규칙으로 개별 확인하고 유효 결과 건수와 정상 저장 여부를 확정. 미측정 빈칸 제공 정책을 원본이 이미 충족한 것으로 간주하지 않음
