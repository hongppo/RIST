라벨·병합 셀 읽기

항목처리 기준
시트 순회전체 워크시트를 원래 순서로 확인하고 시트별 유형·결과 유무·확인 사항 기록. 첫 시트만 처리하거나 특정 시트명으로 제한하지 않음
비교용 라벨공백·줄바꿈·콜론 차이를 정규화하여 비교. 원문 라벨과 추출값은 별도로 보존하고 이름·분석법 내부 공백·기호를 비교 규칙으로 훼손하지 않음
같은 셀의 값라벨 뒤의 전체 값을 읽음. 예: 분석 방법: ICP 분석 및 Fe 적정에서 라벨만 분리
분리된 입력칸라벨 뒤 값이 비면 동일 항목의 대응 입력칸만 확인. 임의로 다음 비어 있지 않은 셀을 가져오지 않음
병합 영역좌상단 실제 값과 병합 범위를 읽어 해당 라벨·입력칸·표 제목의 영역으로 해석. 병합을 해제해 모든 결과 셀에 값을 채우지 않음
중복·누락중복 라벨은 같은 결과표의 적용 범위로 구분. 후보·입력칸·범위가 불명확하면 원문과 확인 사유 반환. 인접 표의 값을 대신 사용하지 않음
유형 확정양식 라벨과 시료 행·물질 열 관계로 판별. 시트명·의뢰번호·물질 조합·예시의 행열 수로 유형을 분리하거나 고정하지 않음

추출 구간 및 표 범위

구분처리 기준
표 시작시료명 열과 분석 시험 결과 제목을 식별하고 그 아래의 실제 물질 헤더 행 확인. 물질 헤더 아래의 유효 시료 행부터 결과 연결
물질 열시료명 우측의 실제 물질명을 기준으로 구성. 시료 NO·비고·단위는 물질에서 제외. 예시의 N7 K처럼 병합 제목 폭 밖에 있어도 구조상 물질 헤더·결과에 해당하면 포함
시료 행시료명 아래의 식별자를 읽고 같은 행의 결과 연결. 시료 NO 순번이나 시료수로 시료명을 대체하지 않음
숫자 시료명2, 6, 7 등은 유효한 시료명. 문자열 식별자로 보존하며 순번·날짜·결과값으로 해석하지 않음
빈 결과유효한 시료·물질 교차칸이 비면 해당 결과를 NULL로 유지. 다음 행·열의 값을 당겨 채우지 않음
빈 여유 행시료명·결과가 없는 행은 생성하지 않음. 첫 빈 행에서 종료하지 않고 동일 표 뒤쪽의 실제 내용을 확인
종료하단 분석 방법·시험장비(방법) 영역을 경계로 결과표 종료. 시료수·성분수·서명·결재·기관명·양식번호·하단 안내를 결과로 읽지 않음
불명확 영역물질 헤더 없는 값, 시료명 없는 결과, 주석·별도 표의 혼입은 임의 연결·제외하지 않고 확인. 일부 결과만 읽고 정상 완료로 확정하지 않음
반복·복수 표동일 시료명·물질명이 반복되어도 원본 위치·순서를 보존. 별도 표는 라벨·범위가 독립적으로 식별될 때 각각 처리하며 공통 항목을 표 사이에 복제하지 않음

물질별 결과 추출

물질·결과·단위 해석

항목처리 기준
분석물질실제 물질 헤더 전체 보존. 헤더가 비어 있는 표준 양식에 예시의 물질명·순서를 복사하지 않음
결과 연결각 시료 행의 물질 헤더 열과 교차하는 셀 하나를 결과 1건으로 생성. 시료 행 순서→물질 열의 왼쪽에서 오른쪽 순서 유지
숫자 원문XLSX XML 숫자 <v> 문자열을 result_raw로 보존하고 Decimal로 해석. 라이브러리 이진 부동소수점 변환값으로 원문을 대체하지 않음
표시 보존최초 result_text는 원문 정밀도를 유지. 원본 셀의 표시 형식과 그 형식으로 표시되는 문자열도 source_snapshot에 별도 보존하여 저장 숫자와 구분
정밀도임의 반올림·절삭 금지. 정밀 소수 전송은 문자열 사용. 저장 정밀도를 초과하면 원문 보존·검증 오류 반환

0·빈 값실제 0은 정상 수치. 유효 교차칸의 빈 결과는 NULL이며 빈 여유 행과 구분

단위 변환%가 명시되어도 숫자를 100으로 나누거나 정규화하지 않음. 원문 수치와 단위를 각각 보존
오류·수식오류 원문·수식·캐시를 구분해 보존. 유효 캐시만 해석하고 캐시 부재·오류는 확인. 다른 셀·시트 값이나 외부 실행으로 보완하지 않음
