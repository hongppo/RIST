그룹 저장 및 원본 다운로드 정책

적용 범위

여러 파일 업로드의 미완료 그룹 보관, 작업 재개, 이력 및 파일별 원본 다운로드에 적용한다. 그룹 구성과 최종 저장은 여러 파일 업로드 정책을 따른다.

그룹별 임시 보관

항목정책
보관 단위미완료 유형 그룹별 30일
기준일해당 그룹에서 마지막으로 실제 값을 변경하고 서버에 적용한 날. 변경이 없으면 업로드일
갱신 조건그룹 안 파일의 실제 값 변경과 서버 적용. 해당 미완료 그룹만 기간 갱신
갱신 제외단순 조회, 파일 이동, 다운로드, 변경 없는 저장 및 업로드 화면 복귀
완료 그룹미완료 보관 만료 대상에서 제외. NAS 전송 대기 및 실패 상태도 동일
그룹 없는 파일유형 판별 실패, 미지원 및 추출 중 취소 파일의 원본은 업로드일부터 30일 보관. NAS 전송 금지

‘작업 저장’과 값 적용 동작을 유지하며 별도 임시 저장 버튼은 제공하지 않는다. ‘작업 저장’은 되돌리기 기준점을 기록하며, 변경 없는 저장으로 기간을 연장하지 않는다.

만료일은 한국 시간 기준으로 기준일에 30일을 더한 날짜이며 해당 날짜가 끝날 때까지 사용할 수 있다. 만료일 7일 전 00:00부터 ‘만료 예정’을 기본 상태와 함께 보조 표시한다. 예를 들어 기준일이 2026/10/27이면 만료일은 2026/11/26이며 2026/11/19 00:00부터 안내한다.

만료와 정리

만료일이 지나면 재개, 수정 및 원본 다운로드를 차단한다. 정리 전 데이터가 남아 있어도 직접 주소와 API를 포함해 접근을 허용하지 않는다.

공통 정리 기준에 따라 만료일 다음 날 03:00(한국 시간)에 미완료 그룹의 원본과 검토 데이터를 삭제한다. 서버가 꺼져 있으면 다음 기동 시 실행한다. 업로드 이력은 유지하고 파일명, 업로드 계정, 업로드 시각 및 ‘보관 기간 만료’ 상태를 남긴다. 대상 그룹과 파일, 계정, 만료일, 삭제 시각 및 처리 결과를 감사 로그에 기록한다.

이력 유지란 시스템 기록의 유지를 의미하며, 사용자 목록과 상세의 표시는 실패 파일 업로드 이력 삭제 정책을 함께 적용한다.

삭제 직전 같은 트랜잭션에서 최근 수정 여부와 최종 저장 여부를 재확인한다. 최종 저장과 원본 삭제의 충돌로 완료 원본이 유실되지 않도록 처리하며 구체적인 동시 처리 방지 방식은 미확정이다.

작업 재개

검토 중단 또는 업로드 화면 복귀 후에도 서버에 적용된 내용과 묶음, 그룹, 파일의 연결 관계를 유지한다.

항목정책
재개 대상보관 기간 내 업로드 계정의 미완료 그룹
복귀 위치마지막 검토 파일과 마지막 1단계 또는 2단계
3단계 중단2단계로 복귀해 그룹 전체 재검사
복원 값서버에 적용된 값. 적용하지 않은 입력칸의 값은 제외
완료 그룹재개 대상으로 제공하지 않음
검토 데이터 없는 작업‘이어서 검토’ 제공하지 않음. 추출 실패 및 미지원 파일은 묶음 상세의 그룹 없는 파일 목록에서 개별 이력 상세로 진입. 추출 중 취소 파일의 묶음 표시 및 재진입은 미확정

여러 파일 업로드 이력

단일 파일 이력과 분리된 ‘업로드 이력(여러 파일)’ 메뉴 또는 진입 버튼을 제공한다.

화면표시 및 기능
묶음 목록업로드 일시, 업로드한 사람, 전체 파일 수, 유형 그룹 수, 완료 및 미완료 그룹 수
묶음 상세유형별 파일 수, 그룹별 진행 상태, 미완료 그룹 보관 만료일과 그룹 없는 실패 및 미지원 파일 목록
그룹 내부 목록개별 파일명과 상태, 선택 파일 결과 및 각 파일 행 우측 원본 개별 다운로드
미완료 그룹권한과 기간 충족 시 이어서 검토
만료 그룹이력 유지. 검토 데이터 접근, 재개 및 원본 다운로드 차단

완료와 미완료 그룹의 상태 및 만료 여부를 각각 표시한다. 일부 그룹 완료만으로 묶음 전체를 완료로 표시하지 않는다. 완료 그룹에는 미완료 보관 만료일을 표시하지 않는다.

계정 및 접근 권한

업로드한 사람은 업로드 당시 로그인 계정이다. 공용 계정 사용자끼리는 동일 계정의 미완료 작업에 접근할 수 있으며 개인 계정은 계정별로 구분한다.

미완료 그룹의 목록, 상세, 수정 및 다운로드는 업로드 계정에만 제공한다. 완료 데이터와 완료 원본은 기존 완료 이력 조회 범위인 로그인 사용자 전체에게 제공한다. 같은 묶음에 다른 계정의 미완료 파일이 있어도 상세 정보와 접근 링크를 노출하지 않는다. 중복 안내의 ‘다른 사용자 검토 중 N건’만 예외로 허용한다.

원본 다운로드와 NAS 보관

항목정책
제공 위치그룹 파일 목록의 각 행 우측 버튼으로 해당 원본을 개별 다운로드. 그룹 없는 실패 및 미지원 파일은 개별 이력 상세에서 제공. 그룹 전체 다운로드는 제공하지 않음
미완료 원본보관 기간 내 업로드 계정에 운영 서버 원본 제공. NAS 전송 금지
완료 원본이력 조회 권한에 따라 현재 보관 위치인 운영 서버 또는 NAS에서 제공
파일 구분그룹 저장 후에도 개별 원본과 결과 연결 유지
다운로드 이름업로드 당시 파일명과 확장자 유지. 저장소에서는 파일 ID 기준 관리
서버 사본 삭제완료 원본의 NAS 복사 후 크기와 SHA-256 검증 성공을 확인한 뒤 삭제
NAS 전송 실패운영 서버 원본 유지, 공통 NAS 정책에 따라 다음 날 전송 재시도. 그룹 최종 저장 재시도와 구분
NAS 보관완료 원본과 최종 데이터 무기한 보관. 원본은 업로드 월, 최종 CSV는 최종 저장 월 기준 분류
다운로드 기록사용자, 다운로드 시각 및 대상 파일을 감사 로그에 기록

최종 저장 성공 여부와 NAS 이관 상태를 별도로 관리한다. NAS 대기 또는 실패를 그룹 최종 저장 실패나 미완료 상태로 표시하지 않는다.

다운로드 오류

조건안내
권한 없음이 작업을 볼 수 있는 권한이 없습니다.
만료 후 재개보관 기간이 만료되어 이어서 검토할 수 없습니다.
NAS 연결 장애원본 저장소에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요.
파일 부재원본 파일을 찾을 수 없습니다.
만료 후 다운로드보관 기간이 만료되어 원본을 다운로드할 수 없습니다.

보관과 다운로드의 공통 기준은 저장 및 원본 다운로드 정책을 따른다. DB 백업은 7일 보관 예외를 적용하며 복원으로 만료 작업을 재활성화하지 않는다.

그룹 전체 최종 저장 성공 시 그룹 저장 완료에서 유형, 파일 수와 결과 행 수를 확인한다. 남은 그룹이 있으면 같은 완료 화면 아래에 다음 그룹 검토 여부와 다음 유형 및 파일 수를 표시하며, 사용자가 다음 그룹 검토를 선택하면 해당 그룹의 1단계로 이동한다. 나중에 검토를 선택하면 해당 업로드 묶음 상세로 이동한다. 단순 보류는 미완료 그룹의 보관 기간을 갱신하지 않으며 기존 권한 기준을 유지한다. 남은 그룹이 없으면 다음 그룹 질문을 표시하지 않고 완료 확인으로 모든 그룹 완료에 연결한다.

추출 실패 및 지원하지 않는 파일은 묶음 상세에 처음부터 그룹 없는 파일로 표시하고 개별 업로드 이력 상세로 연결한다. 업로드 계정만 해당 미완료 파일을 조회하며, 다른 계정에는 해당 파일의 정보와 링크를 표시하지 않는다. 이력을 삭제하면 사용자 목록과 상세에서 숨기되 원래 업로드 총수, 정상 파일과 유형 그룹은 유지한다. 내부 기록과 기존 원본 보관 기간은 변경하지 않는다.

미확정 사항

항목미확정 내용
제외 파일원본 보관 및 삭제 시점, 검토 시작 전 제외 취소 제공 여부
추출 중 취소 파일묶음 이력 표시와 재진입 상세 방식
그룹 저장 실패중복 저장 방지 재시도 및 부분 저장 복구 방식
운영 정보최종 저장과 삭제 동시 처리 방지 방식, 실사용 시작일 및 NAS_FINAL_SINCE, 환경별 NAS 응답 대기 시간

NAS 응답 대기 시간은 공통 정책의 10초 검토 기준을 따르며 운영 환경에 맞춘 확정값은 별도로 정한다.
