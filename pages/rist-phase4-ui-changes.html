화면기능 요구상세 화면
파일 업로드 변경 사항첫 화면의 업로드 영역을 같은 크기의 좌우 두 영역으로 제공합니다. 왼쪽은 파일 1개 선택 및 드래그, 오른쪽은 여러 파일 선택 및 드래그를 지원합니다. 두 영역 아래 맨 오른쪽에 공통 다음 단계로 버튼을 제공합니다. 선택 전에는 비활성화하며 파일 선택만으로 이동하지 않습니다. 버튼을 선택하면 왼쪽은 단일 업로드 및 추출, 오른쪽은 유형 분석으로 이동합니다. 오른쪽에서 파일 1개를 선택해도 여러 파일 경로를 유지합니다. 한 영역만 선택 상태로 관리하고 반대 영역의 실제 파일 선택은 이전 선택을 대체합니다. 선택을 취소하면 기존 선택을 유지합니다. 단일 파일과 여러 파일의 처리 흐름 및 이력은 분리합니다. 여러 파일은 접수 전 선택한 전체 파일 수를 기준으로 한 번에 최대 20개까지 업로드하며, 파일당 20MB 이하입니다. 유형 수는 제한하지 않으며 기존 등록 유형을 지원합니다. 미지원 파일은 유형 분석 후 처리 불가 목록에 표시합니다. 선택 또는 드롭한 파일이 20개를 초과하면 일부만 접수하지 않고 다음 단계로 진행을 차단합니다. 나중에 파일을 제외할 예정이어도 초과 접수할 수 없습니다. “파일은 한 번에 최대 20개까지 업로드할 수 있습니다. 20개 이하로 다시 선택해 주세요.”를 안내하고 20개 이하로 다시 선택하도록 합니다. 업로드 전 선택 상태에서는 단일 파일과 여러 파일 모두 “N개 파일 선택됨”으로 상태와 수량만 표시하며, 파일명과 파일명 툴팁은 표시하지 않습니다. 전체 업로드 용량은 최대 400MB를 기준으로 하며, 개발 검토 의견에 따라 조정할 수 있습니다. 파일당 용량과 전체 용량은 동일하게 1MB = 1,024 × 1,024바이트로 계산합니다. 전체 용량이 400MB를 초과하거나 파일당 용량이 20MB를 초과하면 접수 및 다음 단계 진행을 차단하고 기준 이하로 다시 선택하도록 안내합니다.파일 업로드 변경 사항
